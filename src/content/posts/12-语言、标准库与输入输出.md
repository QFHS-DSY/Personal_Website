#### 数组去重函数 unique

在使用前需要**先进行排序**。

其作用是，对于区间 `[开始位置, 结束位置)` ，**不停的把后面不重复的元素移到前面来**，也可以说是**用不重复的元素占领重复元素的位置**。并且返回**去重后容器中不重复序列的最后一个元素的下一个元素**。所以在进行操作后，数组、容器的大小并**没有发生改变**。

```c++
//将a数组[start,end)区间去重，返回迭代器
unique(a + start, a + end);

//与earse函数结合，达到去重+删除的目的
a.erase(unique(a.begin(), a.end()), a.end());
```

#### bit 库与位运算函数 \__builtin\_

GNU 内建函数不是 C++20 标准库。以下为无符号 32 位/64 位常用版本；ctz/clz 的参数不能为 0，ffs(0)=0。

```c++

pcntll(x); // ull：1 的数量
```

ll 后缀对应 long long 版本，没有通用的 ull 后缀。无符号整数的有效位数使用下面的函数，0 返回 0；必须先判零再调用 clz。

```c++
// GNU C++14 可用；依赖缺省源的 ull
int bitWidth(ull x) {
    return x ? 64 - __builtin_clzll(x) : 0;
}
// bitWidth(26u) == 5，bitWidth(0) == 0。
```

#### 全排列算法 next\_permutation、prev\_permutation

在提及这个函数时，我们先需要补充几点字典序相关的知识。

> 对于三个字符所组成的序列`{a,b,c}`，其按照字典序的6种排列分别为：
`{abc}`，`{acb}`，`{bac}`，`{bca}`，`{cab}`，`{cba}`
其排序原理是：先固定 `a` (序列内最小元素)，再对之后的元素排列。而 `b` < `c` ，所以 `abc` < `acb` 。同理，先固定 `b` (序列内次小元素)，再对之后的元素排列。即可得出以上序列。

$\tt{}next\_permutation$ 算法，即是按照**字典序顺序**输出的全排列；相对应的， $\tt{}prev\_permutation$ 则是按照**逆字典序顺序**输出的全排列。可以是数字，亦可以是其他类型元素。其直接在序列上进行更新，故直接输出序列即可。

```c++
int n;
cin >> n;
vector<int> a(n);
// iota(a.begin(), a.end(), 1);
for (auto &it : a) cin >> it;
sort(a.begin(), a.end());

do {
    for (auto it : a) cout << it << " ";
    cout << endl;
} while (next_permutation(a.begin(), a.end()));
```

#### map、multimap

默认按键升序，$\tt map$ 去重，$\tt mulitmap$ 不去重，$\mathcal O(logS)$ ，其中 $S$ 为元素数量。

```c++
map<int, int, greater<>> mp; //按 greater 比较（优先队列为小根堆，有序容器为降序）
size() / empty() / clear()
begin() / end()
++/ -- //返回前驱、后继

insert({x, y}); //插入二元组
[] //随机访问，multimap不支持
count(x); //返回x为下标的个数
lower_bound(x); //返回第一个下标>=x的迭代器
upper_bound(x); //返回第一个下标>x的迭代器
```

`erase(x);` 有两种删除方式：

- 当x为某一元素时，删除所有**以这个元素为下标的二元组**，复杂度为 $\mathcal O (num_x+logN)$ ；
- 当x为迭代器时，删除这个迭代器。

**慎用随机访问！**——当不确定某次查询是否存在于容器中时，不要直接使用下标查询，而是先使用 `count()` 或者 `find()` 方法检查key值，防止不必要的零值二元组被构造。

```c++
int q = 0;
if (mp.count(i)) q = mp[i];
```

map/set 可以直接使用 pair、tuple，它们默认按字典序比较。只有需要特殊比较顺序时才使用比较器或自定义结构体；unordered 容器另外需要哈希函数。

```c++
struct fff {
    ll x, y;
    friend bool operator<(const fff &a, const fff &b) {
        if (a.x != b.x) return a.x < b.x;
        return a.y < b.y;
    }
};
map<fff, int> mp;
```

### C++：程序标准化

#### 使用 Lambda 函数

- `function` 统一写法

需要注意的是，虽然 `function` 定义时已经声明了返回值类型了，但是有的时候会出错（例如，声明返回 `long long` 但是返回 `int` ，原因没去了解），所以推荐在后面使用 `->` 再行声明一遍。

```c++
function<void(int, int)> clac = [&](int x, int y) -> void {
};
clac(1, 2);

function<bool(int)> dfs = [&](int x) -> bool {
    if (x >= 10) return true; // 递归必须有终止条件
    return dfs(x + 1);
};
dfs(1);
```

- `auto` 非递归写法

不需要使用递归函数时，直接用 `auto` 替换 `function` 即可。

```c++
auto clac = [&](int x, int y) -> void {
};
```

- `auto` 递归写法

相较于 `function` 写法，需要额外引用一遍自身。

```c++
auto dfs = [&](auto self, int x) -> bool {
    if (x >= 10) return true; // 递归必须有终止条件
    return self(self, x + 1);
};
dfs(dfs, 1);
```

#### int128 输入输出流控制

`__int128` 是编译器扩展，是否支持取决于编译器和目标架构，并非 Linux 或 C++20 专属；本项目在 Windows GNU C++17 下验证。带符号范围为 $[-2^{127},2^{127}-1]$。以下流运算支持正负号、零及最小负数；非法或溢出输入设置 failbit，输出不带多余空格与换行。调用时用 `my128::operator>>/<<`，或通过 using 声明引入运算符。

```c++
namespace my128 {
u128 abs(const i128 &x) { // 最小负数的绝对值需要无符号类型
    return x < 0 ? u128(0) - u128(x) : u128(x);
}
istream &operator>>(istream &in, i128 &value) {
    string s;
    if (!(in >> s)) return in;
    size_t i = 0;
    bool neg = s[0] == '-';
    if (s[0] == '-' || s[0] == '+') ++i;
    u128 limit = (u128(1) << 127) - 1 + neg, x = 0;
    bool ok = i < s.size();
    for (; i < s.size(); ++i) {
        if (s[i] < '0' || s[i] > '9') {
            ok = false;
            break;
        }
        unsigned digit = s[i] - '0';
        if (x > (limit - digit) / 10) {
            ok = false;
            break;
        }
        x = x * 10 + digit;
    }
    if (!ok) {
        in.setstate(ios::failbit);
        return in;
    }
    value = neg && x ? -i128(x - 1) - 1 : i128(x);
    return in;
}
ostream &operator<<(ostream &out, const i128 &value) {
    u128 x = abs(value);
    string s;
    do {
        s += char('0' + x % 10);
        x /= 10;
    } while (x);
    if (value < 0) s += '-';
    reverse(s.begin(), s.end());
    return out << s;
}
} // namespace my128
```

### C++：哈希容器

#### 哈希系列 unordered

通常指代 unordered_map、unordered_set、unordered_multimap、unordered_multiset，与原版相比不进行排序。

如果将不支持哈希的类型作为 `key` 值代入，编译器就无法正常运行，这时需要我们为其手写哈希函数。哈希函数必须保证相等的 key 得到相同哈希值；冲突时容器仍用 key 的相等比较区分。分布差会使预期 $\mathcal{O}(1)$ 退化为最坏 $\mathcal{O}(n)$，应避免所有排列都产生相同哈希。[参考](https://finixlei.blog.csdn.net/article/details/110267430?spm=1001.2101.3001.6650.3&utm_medium=distribute.pc_relevant.none-task-blog-2%7Edefault%7EBlogCommendFromBaidu%7ERate-3-110267430-blog-101406104.topnsimilarv1&depth_1-utm_source=distribute.pc_relevant.none-task-blog-2%7Edefault%7EBlogCommendFromBaidu%7ERate-3-110267430-blog-101406104.topnsimilarv1&utm_relevant_index=4)

#### 对 pair、tuple 定义哈希

```c++
// hashMix：合并一个字段的哈希值
inline void hashMix(size_t &seed, size_t value) {
    seed ^= value + size_t(0x9e3779b97f4a7c15ULL) + (seed << 6) + (seed >> 2);
}
struct hash_pair {
    template <class T1, class T2> size_t operator()(const pair<T1, T2> &p) const {
        size_t seed = 0;
        hashMix(seed, hash<T1>{}(p.first));
        hashMix(seed, hash<T2>{}(p.second));
        return seed;
    }
};
struct hash_tuple {
    template <class Tup, size_t... I> static size_t calc(const Tup &p, index_sequence<I...>) {
        size_t seed = 0;
        int unused[] = {0, (hashMix(seed, hash<decay_t<decltype(get<I>(p))>>{}(get<I>(p))), 0)...};
        (void)unused;
        return seed;
    }
    template <class... T> size_t operator()(const tuple<T...> &p) const {
        return calc(p, index_sequence_for<T...>{});
    }
};
unordered_set<pair<int, int>, hash_pair> S;
unordered_map<tuple<int, int, int>, int, hash_tuple> M;
```

#### 对结构体定义哈希

需要两个条件，一个是在结构体中重载等于号（区别于非哈希容器需要重载小于号，如上所述，当冲突时编译器需要根据重载的等于号判断），第二是写一个哈希函数。注意 `hash<>()` 的尖括号中的类型匹配。

```c++
struct fff {
    string x, y;
    int z;
    friend bool operator==(const fff &a, const fff &b) {
        return a.x == b.x && a.y == b.y && a.z == b.z;
    }
};
struct hash_fff {
    size_t operator()(const fff &p) const {
        return hash<string>()(p.x) ^ hash<string>()(p.y) ^ hash<int>()(p.z);
    }
};
unordered_map<fff, int, hash_fff> mp;
```

#### 对 vector 定义哈希

使用自定义哈希器，并按元素顺序合并。不能为纯标准库类型 `vector<int>` 在 namespace std 中自行特化 hash；该做法不符合标准。以下片段依赖前面的 hashMix。

```c++
struct hash_vector {
    size_t operator()(const vector<int> &p) const {
        size_t seed = 0;
        for (auto it : p) hashMix(seed, hash<int>()(it));
        return seed;
    }
};
unordered_map<vector<int>, int, hash_vector> mp;
```

```c++
struct myhash {
    static ull hash(ull x) {
        x += 0x9e3779b97f4a7c15;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9;
        x = (x ^ (x >> 27)) * 0x94d049bb133111eb;
        return x ^ (x >> 31);
    }
    size_t operator()(ull x) const {
        static const ull SEED = chrono::steady_clock::now().time_since_epoch().count();
        return hash(x + SEED);
    }
    size_t operator()(pair<ull, ull> x) const {
        static const ull SEED = chrono::steady_clock::now().time_since_epoch().count();
        return hash(x.first + SEED) ^ (hash(x.second + SEED) >> 1);
    }
};
// unordered_map<int, int, myhash>
```
