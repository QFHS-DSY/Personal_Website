### 公共全局变量与建图

<a id="graph-base"></a>

默认复用第 01 章缺省源，GNU C++17，支持 `#define int long long`；MOD、MAXN 按需启用。除另有说明，顶点为 1..n，n≥1，权值、容量和答案用 ll。只复制所需的公共声明和函数；主程序已有同名全局变量时直接复用，不创建图对象。下方各组存储是**按题选择的替代方案**，不要把整章一次粘贴；普通邻接表与带编号邻接表都叫 e，二选一。

#### 普通邻接表

最短路、SCC、染色、DAG、普通环搜索、2-Sat 共用 `n,e`，无权边令 w=1。`add` 只加有向边，无向图使用 `add(u,v,w); add(v,u,w);`。初始化 O(n)，加边均摊 O(1)，存图 O(n+m)。多测先 initGraph，再加边，再运行所需算法；各算法入口重置其负责的辅助数组，旧结果在重新运行前不可使用。

```c++
int n;
vector<vector<pair<int, ll>>> e; // e[u] = {v,w}
void initGraph(int N) {
    n = N;
    e.assign(n + 1, {});
}
void add(int u, int v, ll w = 1) { e[u].push_back({v, w}); }
```

#### 带编号邻接表

割边、点双、最短路径树、带边编号的环和欧拉路径共用本组。`es[id]={u,v,w}` 保存原边，e 中保存 `{v,w,id}`；id 从 0 开始，无向边两端共用同一 id，自环保留两个邻接项。`addEdge(u,v,w,true)` 加无向边，末参为 false 加有向边；同一道题不混用两种方向。初始化 O(n)，加边均摊 O(1)，存图 O(n+m)。

```c++
int n;
vector<vector<tuple<int, ll, int>>> e;
vector<tuple<int, int, ll>> es;
void initGraph(int N) {
    n = N;
    e.assign(n + 1, {});
    es.clear();
}
int addEdge(int u, int v, ll w = 1, bool undirected = true) {
    int id = es.size();
    es.push_back({u, v, w});
    e[u].push_back({v, w, id});
    if (undirected) e[v].push_back({u, w, id});
    return id;
}
```

#### 邻接矩阵

Floyd、Prim、最小环和全局最小割按各节说明共用 `n,g`；无边哨兵和重边合并方式不同。`initMatrix(N,absent)` 用 O(n²) 时间 / 空间清空矩阵，对角置 0；本函数不负责读边。

```c++
int n;
vector<vector<ll>> g;
void initMatrix(int N, ll absent = LLINF) {
    n = N;
    g.assign(n + 1, vector<ll>(n + 1, absent));
    for (int u = 1; u <= n; ++u) g[u][u] = 0;
}
```

### 常见概念

<a id="concepts"></a>

> oriented graph：有向图
> 
> bidirectional edges：双向边

平面图：若能将无向图 $G=(V,E)$ 画在平面上使得任意两条无重合顶点的边不相交，则称 $G$ 是平面图。

无向正权图上某一点的偏心距：记为 $ecc(u) = \max \big\{ dist(u, v) \big\}$ ，即以这个点为源，到其他点的**所有最短路的最大值**。如下图 $A$ 点，$ecc(A)$ 即为 $12$ 。

图的直径：定义为 $d = \max \big\{ ecc(u) \big\}$ ，即**最大的偏心距**，亦可以简化为图中最远的一对点的距离。

图的中心：定义为 $arg=\min \big\{ ecc(u)\big\}$ ，即**偏心距最小的点**。如下图，图的中心即为 $B$ 点。

图的绝对中心：可以定义在边上的图的中心。

图的半径：图的半径不同于圆的半径，其不等于直径的一半（但对于绝对中心定义上的直径而言是一半）。定义为 $r = \min \big\{ ecc(u) \big\}$ ，即**中心的偏心距**。计算方式：使用全源最短路，计算出所有点的偏心距，再加以计算。

### 常见结论

<a id="facts"></a>

1. 要在有向图上求一个最大点集，使得任意两个点 $(i,j)$ 之间至少存在一条路径（可以是从 $i$ 到 $j$ ，也可以反过来，这两种有一个就行），**先 SCC 缩点，再以分量大小为点权求 DAG 最长路（原图最长简单路不是同一个问题）**；
2. 要求出连通图上的任意一棵生成树，只需要跑一遍 **bfs** ；
3. 给出一棵树，要求添加尽可能多的边，使得其是二分图：对树进行二分染色，显然，不同颜色的点之间连边不会破坏二分图的性质，故可添加的最多的边数即为 $cnt_{\tt Black}*cnt_{\tt White}-(n-1)$ ；
4. 当一棵树可以被黑白染色时，所有染黑节点的度之和等于所有染白节点的度之和；
5. 在竞赛图中，入度小的点，必定能到达出度小（入度大）的点 [See](https://codeforces.com/contest/1498/problem/E) 。
6. 在竞赛图中，将所有点按入度从小到大排序，随后依次遍历，若对于某一点 $i$ 满足前 $i$ 个点的入度之和恰好等于 $\left\lfloor \dfrac{i\cdot(i-1)}{2}\right\rfloor$ ，那么对于上一次满足这一条件的点 $p$ ，$p+1$ 到 $i$ 点构成一个新的强连通分量 [See](https://codeforces.com/contest/1498/problem/E) 。
   > 举例说明，设满足上方条件的点为 $p_1,p_2\ (p_1+1<p_2)$ ，那么点 $1$ 到 $p_1$ 构成一个强连通分量、点 $p_1+1$ 到 $p_2$ 构成一个强连通分量。
7. 选择图中最少数量的边删除，使得图不连通，即求最小割；如果是删除点，那么拆点后求最小割 [See](https://www.luogu.com.cn/problem/P1345)。
8. 如果一张图是**平面图**，那么在 n≥3 且无自环、无重边时，边数不超过 $3n-6$ [See](https://www.luogu.com.cn/problem/P3209) 。
9. 若一张有向完全图存在环，则一定存在三元环。
10. 竞赛图三元环计数：[See](https://ac.nowcoder.com/acm/contest/84244/F) 。
11. 有向图判是否存在环直接用 topsort；无向图判是否存在环直接用 dsu，也可以使用 topsort，条件变为 `deg[i] <= 1` 时入队。

### 单源最短路径（SSSP问题）

<a id="sssp"></a>

#### （非负权稀疏图）Dijkstra 算法


非负边权；依赖普通邻接表。时间 O((n+m)log(n+m))，额外空间 O(n+m)。有限距离及松弛候选须小于 LLINF；不可达为 LLINF，可更换源点重复调用。

```c++
vector<ll> dis;
void dijkstra(int s = 1) {
    dis.assign(n + 1, LLINF);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> q;
    q.push({dis[s] = 0, s});
    while (!q.empty()) {
        auto [d, u] = q.top(); q.pop();
        if (d != dis[u]) continue;
        for (auto [v, w] : e[u])
            if (dis[v] > d + w) q.push({dis[v] = d + w, v});
    }
}
```

例：`initGraph(3); add(1,2,4); add(2,3,2); dijkstra(1);`，dis[3]=6。

#### （负权图、判负环）Bellman-ford 算法


依赖普通邻接表，时间 O(n(n+m))（逐轮遍历邻接表），额外空间 O(n)。有负权也可用；`neg[u]` 表示源点可达的负环可以影响 u，此时距离为负无穷；dis[u]=BINF 且 !neg[u] 表示不可达。中间运算用 i128，要求其范围足够；有限答案转 ll 前须确认可表示。若改成扁平边表扫描，每轮 O(m)，总时间 O(nm+n)。

```c++
const i128 BINF = i128(1) << 120;
vector<i128> dis;
vector<int> neg;
void bellmanFord(int s = 1) {
    dis.assign(n + 1, BINF); neg.assign(n + 1, 0);
    dis[s] = 0;
    for (int k = 1; k < n; ++k) {
        bool changed = false;
        for (int u = 1; u <= n; ++u) if (dis[u] != BINF)
            for (auto [v, w] : e[u]) if (dis[v] > dis[u] + w) {
                dis[v] = dis[u] + w; changed = true;
            }
        if (!changed) break;
    }
    queue<int> q;
    for (int u = 1; u <= n; ++u) if (dis[u] != BINF)
        for (auto [v, w] : e[u]) if (dis[v] > dis[u] + w && !neg[v]) {
            neg[v] = 1; q.push(v);
        }
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (auto [v, w] : e[u]) if (!neg[v]) neg[v] = 1, q.push(v);
    }
}
```

例：`initGraph(3); add(1,2,-1); add(2,2,-1); add(2,3); bellmanFord();`，neg[2]=neg[3]=1，neg[1]=0。

#### （负权图）SPFA 算法


依赖普通邻接表。要求源点可达范围内没有负环；需要判负环时使用上节。最坏时间 O(nm+n)，额外空间 O(n)，不可达为 LLINF。有限距离绝对值小于 LLINF，加法不得溢出 ll。

```c++
vector<ll> dis;
vector<int> inq;
void spfa(int s = 1) {
    dis.assign(n + 1, LLINF); inq.assign(n + 1, 0);
    queue<int> q;
    dis[s] = 0; inq[s] = 1; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop(); inq[u] = 0;
        for (auto [v, w] : e[u]) if (dis[v] > dis[u] + w) {
            dis[v] = dis[u] + w;
            if (!inq[v]) inq[v] = 1, q.push(v);
        }
    }
}
```

例：`initGraph(2); add(1,2,-3); spfa();`，dis[2]=-3。

#### 单源最短/次短路计数


<a id="shortest-path-count"></a>

依赖普通邻接表和 MOD（2≤MOD≤INT_MAX），**严格正权**，统计按边区分、允许重复顶点的游走。d[u][0]<d[u][1] 是两个不同距离，cnt 是对应方案数；不存在的距离为 LLINF。时间 O((n+m)log(n+m))，额外空间 O(n+m)，有限距离及候选须小于 LLINF。可重复调用。

```c++
vector<array<ll, 2>> d, cnt;
void shortest2(int s = 1) {
    d.assign(n + 1, {LLINF, LLINF});
    cnt.assign(n + 1, {});
    using Q = tuple<ll, int, int>;
    priority_queue<Q, vector<Q>, greater<Q>> q;
    d[s][0] = 0;
    cnt[s][0] = 1;
    q.push({0, s, 0});
    while (!q.empty()) {
        auto [dist, u, k] = q.top();
        q.pop();
        if (dist != d[u][k]) continue;
        for (auto [v, w] : e[u]) {
            ll nd = dist + w;
            ll ways = cnt[u][k];
            if (nd < d[v][0]) {
                swap(nd, d[v][0]);
                swap(ways, cnt[v][0]);
                q.push({d[v][0], v, 0});
            } else if (nd == d[v][0]) {
                cnt[v][0] = (cnt[v][0] + ways) % MOD;
                continue;
            }
            if (nd < d[v][1]) {
                d[v][1] = nd;
                cnt[v][1] = ways;
                q.push({nd, v, 1});
            } else if (nd == d[v][1] && nd != LLINF) cnt[v][1] = (cnt[v][1] + ways) % MOD;
        }
    }
}
```

例：`initGraph(2); add(1,2,1); add(1,2,2); shortest2();`，d[2]={1,2}，cnt[2]={1,1}。无向单位权题中，若 d[t][1]==d[t][0]+1，再将 cnt[t][1] 加入答案并取模。

### 多源汇最短路（APSP问题）


<a id="apsp"></a>

依赖邻接矩阵；initMatrix(n) 后有向边执行 `g[u][v]=min(g[u][v],w)`，无向图同时更新反向。允许负边但要求无负环；有限距离及加法结果绝对值小于 LLINF。时间 O(n³)，额外空间 O(n²)。复制 g 到 dis 再计算，不改原图；不可达为 LLINF。

```c++
vector<vector<ll>> dis;
void floyd() {
    dis = g;
    for (int k = 1; k <= n; ++k)
        for (int u = 1; u <= n; ++u) if (dis[u][k] != LLINF)
            for (int v = 1; v <= n; ++v) if (dis[k][v] != LLINF)
                dis[u][v] = min(dis[u][v], dis[u][k] + dis[k][v]);
}
```

例：`initMatrix(3); g[1][2]=-2; g[2][3]=5; floyd();`，dis[1][3]=3。

### 平面图最短路（对偶图）

<a id="dual-shortest-path"></a>


矩形网格的对偶建图示例，依赖普通邻接表及 Dijkstra。k×k 个内部面编号 1..k²，源汇拆分外部面为 s、t；这是固定网格和指定边界割的建模，不是任意平面嵌入的自动对偶构造。

`readDual(k)` 从 cin 读四组各 k(k+1) 个非负边权，依次对应原图向右、向下、向左、向上的边；函数内部先 initGraph(k*k+2) 再读边，调用后执行 dijkstra(s)，答案 dis[t]。建图时间 / 空间 O(k²)，最短路 O(k² log(k+1))；k≥1，编号乘法不溢出。

```c++
int sideLen, s, t;
int cell(int i, int j) { return (i - 1) * sideLen + j; }
void readDual(int k) {
    sideLen = k; s = k * k + 1; t = s + 1;
    initGraph(t);
    for (int i = 1; i <= k + 1; i++)
        for (int j = 1; j <= k; j++) {
            ll w; cin >> w;
            int pre = cell(i - 1, j), now = cell(i, j);
            if (i == 1) add(s, now, w);
            else if (i == k + 1) add(pre, t, w);
            else add(pre, now, w);

        }
    for (int i = 1; i <= k; i++)
        for (int j = 1; j <= k + 1; j++) {
            ll w; cin >> w;
            int now = cell(i, j), net = cell(i, j - 1);
            if (j == 1) add(now, t, w);
            else if (j == k + 1) add(s, net, w);
            else add(now, net, w);

        }
    for (int i = 1; i <= k + 1; i++)
        for (int j = 1; j <= k; j++) {
            ll w; cin >> w;
            int now = cell(i, j), net = cell(i - 1, j);
            if (i == 1) add(now, s, w);
            else if (i == k + 1) add(t, net, w);
            else add(now, net, w);

        }
    for (int i = 1; i <= k; i++)
        for (int j = 1; j <= k + 1; j++) {
            ll w; cin >> w;
            int pre = cell(i, j - 1), now = cell(i, j);
            if (j == 1) add(t, now, w);
            else if (j == k + 1) add(pre, s, w);
            else add(pre, now, w);

        }
}
```

例：k=1 且四组边权均为 1 时，读入 8 个 1 后调用 dijkstra(s)，dis[t]=2。

### 最小生成树（MST问题）

<a id="mst"></a>

#### （稠密图）Prim算法


依赖邻接矩阵，initMatrix(n) 后无向边取 `g[u][v]=g[v][u]=min(g[u][v],w)`。允许负边、重边；边权在 (-LLINF,LLINF)，总权不溢出 ll。时间 O(n²)，额外空间 O(n)；返回是否连通，成功时 ans 为 MST 权值，失败时 ans 仅为已选部分权值。每次重新计算。

```c++
vector<ll> d;
vector<int> vis;
bool prim(ll &ans) {
    d.assign(n + 1, LLINF); vis.assign(n + 1, 0);
    d[1] = ans = 0;
    for (int i = 0; i < n; ++i) {
        int u = 0;
        for (int v = 1; v <= n; ++v)
            if (!vis[v] && (!u || d[v] < d[u])) u = v;
        if (d[u] == LLINF) return false;
        vis[u] = 1; ans += d[u];
        for (int v = 1; v <= n; ++v) d[v] = min(d[v], g[u][v]);
    }
    return true;
}
```

例：`initMatrix(2); g[1][2]=g[2][1]=-3; ll ans; prim(ans);`，ans=-3。

#### （稀疏图）Kruskal算法


只需要全局边表，不必建邻接表。顶点 1..n，es 的元素为 {u,v,w}；可直接复用带编号建图的 es。排序边编号而不改 es，`mst` 保存选中原边编号；时间 O(n+m log(m+1))，空间 O(n+m)。负权、重边、自环均可处理；总权不溢出 ll。返回是否连通，失败时 ans 是最小生成森林权值；可重复调用。

```c++
int n;
vector<tuple<int, int, ll>> es;
vector<int> fa, siz, mst;
int find(int u) {
    while (fa[u] != u) u = fa[u] = fa[fa[u]];
    return u;
}
bool kruskal(ll &ans) {
    fa.resize(n + 1); iota(fa.begin(), fa.end(), 0);
    siz.assign(n + 1, 1); mst.clear(); ans = 0;
    vector<int> ord(es.size()); iota(ord.begin(), ord.end(), 0);
    sort(ord.begin(), ord.end(), [&](int i, int j) { return get<2>(es[i]) < get<2>(es[j]); });
    for (int id : ord) {
        auto [u, v, w] = es[id]; u = find(u); v = find(v);
        if (u == v) continue;
        if (siz[u] < siz[v]) swap(u, v);
        fa[v] = u; siz[u] += siz[v];
        ans += w; mst.push_back(id);
    }
    return (int)mst.size() == n - 1;
}
```

例：`n=3; es={{1,2,-2},{2,3,3},{1,3,5}}; ll ans; kruskal(ans);`，ans=1。

### 缩点（Tarjan 算法）

<a id="tarjan"></a>

#### （有向图）强连通分量缩点


依赖普通邻接表，忽略边权。scc() 重置状态并划分 SCC，col[u] 为分量号，siz[c] 为分量点数，adj 为缩点 DAG（保留重边）。时间 / 空间 O(n+m)，递归栈最深 O(n)。分量编号逆序 cnt..1 是拓扑序，同一原图可重复计算。

```c++
int timer, cnt;
vector<int> dfn, low, col, stk, siz;
vector<vector<int>> adj;
void tarjan(int u) {
    dfn[u] = low[u] = ++timer; stk.push_back(u);
    for (auto [v, w] : e[u]) {
        if (!dfn[v]) tarjan(v), low[u] = min(low[u], low[v]);
        else if (!col[v]) low[u] = min(low[u], dfn[v]);
    }
    if (dfn[u] == low[u]) {
        ++cnt;
        int v;
        do { v = stk.back(); stk.pop_back(); col[v] = cnt; } while (v != u);
    }
}
void scc() {
    timer = cnt = 0; stk.clear();
    dfn.assign(n + 1, 0); low.assign(n + 1, 0); col.assign(n + 1, 0);
    for (int u = 1; u <= n; ++u) if (!dfn[u]) tarjan(u);
    siz.assign(cnt + 1, 0); adj.assign(cnt + 1, {});
    for (int u = 1; u <= n; ++u) {
        ++siz[col[u]];
        for (auto [v, w] : e[u]) if (col[u] != col[v]) adj[col[u]].push_back(col[v]);
    }
}
```

例：`initGraph(3); add(1,2); add(2,1); add(2,3); scc();`，col[1]=col[2]，cnt=2。

#### （无向图）割边缩点


依赖带编号邻接表，全部使用无向 addEdge。删除某条边后连通分量数增加，该边就是桥；删去全部桥得到边双连通分量。支持重边、自环、不连通图。时间 / 空间 O(n+m)，递归深度 O(n)。

edcc() 重置状态：bridge[id] 标记桥，col[u] 为边双编号，siz 为分量大小，adj 为桥森林。direct[id]={起点,终点} 保存 DFS 定向，桥也定向；每条重边保留自己的编号。边双内任意两点有两条不共边的路径。

```c++
int timer, cnt;
vector<int> dfn, low, col, siz, bridge;
vector<array<int, 2>> direct;
vector<vector<int>> adj;
void bridgeDfs(int u, int pe = -1) {
    dfn[u] = low[u] = ++timer;
    for (auto [v, w, id] : e[u]) {
        if (id == pe) continue;
        if (!dfn[v]) {
            direct[id] = {u, v}; bridgeDfs(v, id);
            low[u] = min(low[u], low[v]);
            bridge[id] = low[v] > dfn[u];
        } else {
            if (dfn[v] <= dfn[u]) direct[id] = {u, v};
            low[u] = min(low[u], dfn[v]);
        }
    }
}
void edcc() {
    timer = cnt = 0;
    dfn.assign(n + 1, 0); low.assign(n + 1, 0); col.assign(n + 1, 0);
    bridge.assign(es.size(), 0); direct.assign(es.size(), {});
    for (int u = 1; u <= n; ++u) if (!dfn[u]) bridgeDfs(u);
    siz = {0};
    for (int u = 1; u <= n; ++u) if (!col[u]) {
        ++cnt; siz.push_back(0);
        vector<int> st{u}; col[u] = cnt;
        while (!st.empty()) {
            int x = st.back(); st.pop_back(); ++siz[cnt];
            for (auto [v, w, id] : e[x]) if (!bridge[id] && !col[v]) {
                col[v] = cnt; st.push_back(v);
            }
        }
    }
    adj.assign(cnt + 1, {});
    for (int id = 0; id < (int)es.size(); ++id) if (bridge[id]) {
        auto [u, v, w] = es[id];
        adj[col[u]].push_back(col[v]); adj[col[v]].push_back(col[u]);
    }
}
```

例：`initGraph(3); addEdge(1,2); addEdge(1,2); addEdge(2,3); edcc();`，只有 bridge[2]=1，col[1]=col[2]。

#### （无向图）割点缩点


依赖带编号邻接表，全部使用无向 addEdge。删除顶点后连通分量数增加，该点就是割点；一个割点可以属于多个点双。支持重边、不连通图，忽略自环；桥的两端和孤立点也分别构成点双。时间 / 空间 O(n+m)，递归深度 O(n)。

vdcc() 一次完成划分和重建：comp[1..cnt] 为各点双的顶点，point[u] 标记割点；adj 是点双与割点构成的森林，1..cnt 为点双，之后为割点，tot 为新图点数。id[u] 映射到割点节点或唯一所属点双。可重复调用，不改原图。

```c++
int timer, cnt, tot;
vector<int> dfn, low, stk, point, id;
vector<vector<int>> comp, adj;
void blockDfs(int u, int pe = -1) {
    dfn[u] = low[u] = ++timer; stk.push_back(u);
    int children = 0;
    for (auto [v, w, ei] : e[u]) {
        if (ei == pe || v == u) continue;
        if (!dfn[v]) {
            ++children; blockDfs(v, ei); low[u] = min(low[u], low[v]);
            if (low[v] >= dfn[u]) {
                if (pe != -1 || children > 1) point[u] = 1;
                comp.push_back({u}); ++cnt;
                int x;
                do { x = stk.back(); stk.pop_back(); comp[cnt].push_back(x); } while (x != v);
            }
        } else low[u] = min(low[u], dfn[v]);
    }
    if (pe == -1) {
        if (!children) comp.push_back({u}), ++cnt;
        stk.pop_back();
    }
}
void vdcc() {
    timer = cnt = 0; stk.clear(); comp.assign(1, {});
    dfn.assign(n + 1, 0); low.assign(n + 1, 0); point.assign(n + 1, 0);
    for (int u = 1; u <= n; ++u) if (!dfn[u]) blockDfs(u);
    tot = cnt; id.assign(n + 1, 0);
    for (int u = 1; u <= n; ++u) if (point[u]) id[u] = ++tot;
    adj.assign(tot + 1, {});
    for (int c = 1; c <= cnt; ++c) for (int u : comp[c]) {
        if (point[u]) adj[c].push_back(id[u]), adj[id[u]].push_back(c);
        else id[u] = c;
    }
}
```

例：`initGraph(3); addEdge(1,2); addEdge(2,3); vdcc();`，point[2]=1，cnt=2，tot=3。

#### 连通性与加边例题

<a id="connectivity-examples"></a>

题意：以哪些点为起点可以无限的在有向图上绕

概括一下这些点可以发现，一类是环上的点，另一类是可以到达环的点。建反图跑一遍 topsort 板子，根据容斥，未被移除的点都是答案 [See](https://atcoder.jp/contests/abc245/tasks/abc245_f) 。

***

题意：添加最少的边，使得有向图变成一个 SCC

将原图的 SCC 缩点，统计缩点后的新图上入度为 $0$ 和出度为 $0$ 的点的数量 $cnt_{\tt in}$、$cnt_{\tt out}$ ，缩点后只有一个点时答案为 0，否则为 $\max(cnt_{\tt in}, cnt_{\tt out})$ 。过程大致是先将一个出度为 $0$ 的点和一个入度为 $0$ 的点相连，剩下的点随便连 [See](https://www.acwing.com/problem/content/369/) 。

***

题意：添加最少的边，使得无向图变成一个 E-DCC

要求原无向图连通；将 E-DCC 缩点，统计缩点后的新图上入度为 $1$ 的点（叶子结点）的数量 $cnt$ ，答案即为 $\left \lceil \frac{cnt}{2} \right \rceil$ 。过程大致是每次找两个叶子结点（但是还有一些条件限制）相连，若最后余下一个点随便连 [See](https://www.acwing.com/problem/content/397/) 。

### 染色法判定二分图


<a id="bipartite-coloring"></a>

依赖普通邻接表，双向建边，忽略边权。这里用迭代 BFS，时间 O(n+m)，额外空间 O(n)，覆盖所有连通块；自环会判失败，重边不影响。返回是否二分图，成功时 color[u]∈{1,2}；失败时颜色只有部分有效，不终止主程序。

```c++
vector<int> color;
bool bipartite() {
    color.assign(n + 1, 0);
    queue<int> q;
    for (int s = 1; s <= n; ++s) if (!color[s]) {
        color[s] = 1; q.push(s);
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto [v, w] : e[u]) {
                if (color[v] == color[u]) return false;
                if (!color[v]) color[v] = 3 - color[u], q.push(v);
            }
        }
    }
    return true;
}
```

例：`initGraph(2); add(1,2); add(2,1); bipartite();` 返回 true。

### 链式前向星建图与搜索


<a id="adjacency-arrays"></a>

本节独立存储，不复制邻接表公共代码。顶点 1..n，n<N，有向边条数<M（无向边占两条）。initStar 清空多测；add 加单向边；dfs 生成 DFS 树的子树点数 siz 和进入/退出序 a，首次调用前由 initStar 清空状态；重跑 DFS 须清空 vis、siz、a 并重置根深度。bfs 可重复调用，dis 为最少边数加 1，源点为 1、不可达为 0。topsort 重建全局 ord 并返回是否无环，不消耗原入度。

搜索时间 O(n+m)，额外空间 O(n)，静态存储 O(N+M)；DFS 有 O(n) 深度递归。

```c++
const int N = 1e5 + 7;
const int M = 1e6 + 7;
int tot, h[N], ver[M], ne[M];
int n, deg[N], vis[N], dis[N], siz[N];
vector<int> a, ord; // DFS 进入/退出序列

void initStar(int count) {
    n = count;
    a.clear(); ord.clear();
    tot = 0; //多组样例清空
    for (int i = 1; i <= n; ++i) {
        h[i] = 0;
        deg[i] = vis[i] = dis[i] = siz[i] = 0;
    }
}
void add(int x, int y) {
    ver[++tot] = y, ne[tot] = h[x], h[x] = tot;
    ++deg[y];
}
void dfs(int x) {
    a.push_back(x); // DFS序
    siz[x] = vis[x] = 1;
    for (int i = h[x]; i; i = ne[i]) {
        int y = ver[i];
        if (vis[y]) continue;
        dis[y] = dis[x] + 1;
        dfs(y);
        siz[x] += siz[y];
    }
    a.push_back(x);
}
void bfs(int s) {
    fill(dis, dis + n + 1, 0);
    queue<int> q;
    q.push(s);
    dis[s] = 1;
    while (!q.empty()) {
        int x = q.front();
        q.pop();
        for (int i = h[x]; i; i = ne[i]) {
            int y = ver[i];
            if (dis[y]) continue;
            dis[y] = dis[x] + 1;
            q.push(y);
        }
    }
}
bool topsort() {
    vector<int> in(deg, deg + n + 1); // 保留原入度，可重复调用
    queue<int> q;
    ord.clear();
    for (int i = 1; i <= n; ++i)
        if (in[i] == 0) q.push(i);
    while (!q.empty()) {
        int x = q.front();
        q.pop();
        ord.push_back(x);
        for (int i = h[x]; i; i = ne[i]) {
            int y = ver[i];
            --in[y];
            if (in[y] == 0) q.push(y);
        }
    }
    return (int)ord.size() == n; //判断是否存在拓扑排序
}

```

例：`initStar(3); add(1,2); add(2,3); bfs(1); topsort();`，dis[3]=3，ord={1,2,3}。

### 一般图最大匹配（带花树算法）


<a id="blossom"></a>

依赖普通邻接表，双向建边、忽略边权；1..n 编号，建图时丢弃自环。blossom() 从空匹配重新计算，返回匹配边数，match[u] 为伙伴，-1 表示未匹配。保留重边时采用保守上界 O(n³+nm)；简单图 m=O(n²) 时为 O(n³)，额外空间 O(n)。[UOJ #79](https://uoj.ac/problem/79)。

```c++
vector<int> match;
int blossom() {
    match.assign(n + 1, -1);
    vector<int> vis(n + 1), link(n + 1), f(n + 1), dep(n + 1);
    auto find = [&](int u) {
        while (f[u] != u) u = f[u] = f[f[u]];
        return u;
    };
    auto lca = [&](int u, int v) {
        u = find(u), v = find(v);
        while (u != v) {
            if (dep[u] < dep[v]) swap(u, v);
            u = find(link[match[u]]);
        }
        return u;
    };
    queue<int> q;
    auto shrink = [&](int u, int v, int p) {
        while (find(u) != p) {
            link[u] = v;
            v = match[u];
            if (vis[v] == 0) {
                vis[v] = 1;
                q.push(v);
            }
            f[u] = f[v] = p;
            u = link[v];
        }
    };
    auto augment = [&](int u) {
        while (!q.empty()) q.pop();
        iota(f.begin(), f.end(), 0);
        fill(vis.begin(), vis.end(), -1);
        q.push(u);
        vis[u] = 1;
        dep[u] = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            for (auto [v, w] : e[u])
                if (vis[v] == -1) {
                    vis[v] = 0;
                    link[v] = u;
                    dep[v] = dep[u] + 1;
                    if (match[v] == -1) {
                        for (int x = v, y = u, temp; y != -1; x = temp, y = x == -1 ? -1 : link[x]) {
                            temp = match[y];
                            match[x] = y;
                            match[y] = x;
                        }
                        return;
                    }
                    vis[match[v]] = 1;
                    dep[match[v]] = dep[u] + 2;
                    q.push(match[v]);
                } else if (vis[v] == 1 && find(v) != find(u)) {
                    int p = lca(u, v);
                    shrink(u, v, p);
                    shrink(v, u, p);
                }
        }
    };
    auto greedy = [&]() {
        for (int u = 1; u <= n; ++u) {
            if (match[u] != -1) continue;
            for (auto [v, w] : e[u])
                if (match[v] == -1) {
                    match[u] = v;
                    match[v] = u;
                    break;
                }
        }
    };
    greedy();
    for (int u = 1; u <= n; u++)
        if (match[u] == -1) augment(u);
    int ans = 0;
    for (int u = 1; u <= n; u++)
        if (match[u] != -1) ans++;
    return ans / 2;
}
```

例：三角形双向建边后 blossom() 返回 1；输出伙伴时将 -1 改成题目要求的 0。

### 一般图最大权匹配（带权带花树算法）


<a id="weighted-blossom"></a>

本节独立全局存储，不复制普通邻接表。1..n，0≤n≤402，时间 O(n³+m)，静态空间 O(402²)，原边表另占 O(m)。允许不匹配，最大化权值和，不以边数优先；非正权边和自环忽略，重边取最大值。要求 4*n*最大正边权 < LLINF/2。

initWeighted(n) 后直接向 edges 放 {u,v,w}，weightedBlossom() 重置花和匹配状态并返回答案；lk[u] 为原点伙伴，0 为未匹配，也可用 matchingEdges() 得到每条匹配边一次。Q 只是边记录，不封装图；lab 为对偶标号，st 为所属花，p 为花内点序列，sl 为最小松弛边来源；f 是交错树前驱，b[u][v] 是花 u 中包含原点 v 的直接子花，s 为交错树标记（-1 未访问、0 外点、1 内点），ed/id 为 LCA 时间戳，m 是含花的当前节点数。

```c++
const int N = 403 * 2; //两倍点数
using T = ll; // 权值、对偶标号；要求 4*n*最大正边权 < LLINF/2
struct Q {
    int u, v;
    T w;
} e[N][N];
T lab[N];
vector<tuple<int, int, ll>> edges; // 原边表，1-based 顶点
int n, m = 0, id, h, t, lk[N], sl[N], st[N], f[N], b[N][N], s[N], ed[N];
vector<int> q(1); // 缩花时可能多次入队，动态扩展
vector<int> p[N];
#define dvd(x) (lab[x.u] + lab[x.v] - e[x.u][x.v].w * 2)
#define FOR(i, b) for (int i = 1; i <= (int)(b); i++)
#define ALL(x) (x).begin(), (x).end()
#define ms(x, i) memset(x + 1, i, m * sizeof x[0])
void upd(int u, int v) {
    if (!sl[v] || dvd(e[u][v]) < dvd(e[sl[v]][v])) {
        sl[v] = u;
    }
}
void ss(int v) {
    sl[v] = 0;
    FOR(u, n) {
        if (e[u][v].w > 0 && st[u] != v && !s[st[u]]) {
            upd(u, v);
        }
    }
}
void ins(int u) {
    if (u <= n) {
        ++t;
        if (t == (int)(q.size())) q.push_back(u);
        else q[t] = u;
    } else {
        for (int v : p[u]) ins(v);
    }
}
void mdf(int u, int w) {
    st[u] = w;
    if (u > n) {
        for (int v : p[u]) mdf(v, w);
    }
}
int gr(int u, int v) {
    v = find(ALL(p[u]), v) - p[u].begin();
    if (v & 1) {
        reverse(1 + ALL(p[u]));
        return (int)p[u].size() - v;
    }
    return v;
}
void stm(int u, int v) {
    lk[u] = e[u][v].v;
    if (u <= n) return;
    Q w = e[u][v];
    int x = b[u][w.u], y = gr(u, x);
    for (int i = 0; i < y; i++) {
        stm(p[u][i], p[u][i ^ 1]);
    }
    stm(x, v);
    rotate(p[u].begin(), y + ALL(p[u]));
}
void aug(int u, int v) {
    int w = st[lk[u]];
    stm(u, v);
    if (!w) return;
    stm(w, st[f[w]]), aug(st[f[w]], w);
}
int lca(int u, int v) {
    for (++id; u | v; swap(u, v)) {
        if (!u) continue;
        if (ed[u] == id) return u;
        ed[u] = id;
        if (u = st[lk[u]]) u = st[f[u]];
    }
    return 0;
}
void shrink(int u, int a, int v) {
    int x = n + 1, i, j;
    while (x <= m && st[x]) ++x;
    if (x > m) ++m;
    lab[x] = s[x] = st[x] = 0;
    lk[x] = lk[a];
    p[x].clear();
    p[x].push_back(a);
    for (i = u; i != a; i = st[f[j]]) {
        p[x].push_back(i);
        p[x].push_back(j = st[lk[i]]);
        ins(j);
    }
    reverse(1 + ALL(p[x]));
    for (i = v; i != a; i = st[f[j]]) { // 复制，只需改循环
        p[x].push_back(i);
        p[x].push_back(j = st[lk[i]]);
        ins(j);
    }
    mdf(x, x);
    FOR(i, m) {
        e[x][i].w = e[i][x].w = 0;
    }
    memset(b[x] + 1, 0, n * sizeof b[0][0]);
    for (int u : p[x]) {
        FOR(v, m) {
            if (!e[x][v].w || dvd(e[u][v]) < dvd(e[x][v])) {
                e[x][v] = e[u][v], e[v][x] = e[v][u];
            }
        }
        FOR(v, n) {
            if (b[u][v]) {
                b[x][v] = u;
            }
        }
    }
    ss(x);
}
void ex(int u) {
    for (int x : p[u]) mdf(x, x);
    int a = b[u][e[u][f[u]].u], r = gr(u, a);
    for (int i = 0; i < r; i += 2) {
        int x = p[u][i], y = p[u][i + 1];
        f[x] = e[y][x].u;
        s[x] = 1;
        s[y] = sl[x] = 0;
        ss(y), ins(y);
    }
    s[a] = 1, f[a] = f[u];
    for (int i = r + 1; i < p[u].size(); i++) {
        s[p[u][i]] = -1;
        ss(p[u][i]);
    }
    st[u] = 0;
}
bool on(const Q &e) {
    int u = st[e.u], v = st[e.v];
    if (s[v] == -1) {
        f[v] = e.u, s[v] = 1;
        int a = st[lk[v]];
        sl[v] = sl[a] = s[a] = 0;
        ins(a);
    } else if (!s[v]) {
        int a = lca(u, v);
        if (!a) {
            return aug(u, v), aug(v, u), 1;
        } else {
            shrink(u, a, v);
        }
    }
    return 0;
}
bool bfs() {
    ms(s, -1), ms(sl, 0);
    h = 1, t = 0;
    FOR(i, m) {
        if (st[i] == i && !lk[i]) {
            f[i] = s[i] = 0;
            ins(i);
        }
    }
    if (h > t) return 0;
    while (1) {
        while (h <= t) {
            int u = q[h++];
            if (s[st[u]] == 1) continue;
            FOR(v, n) {
                if (e[u][v].w > 0 && st[u] != st[v]) {
                    if (dvd(e[u][v])) upd(u, st[v]);
                    else if (on(e[u][v])) return 1;
                }
            }
        }
        T x = LLINF / 2;
        for (int i = n + 1; i <= m; i++) {
            if (st[i] == i && s[i] == 1) {
                x = min(x, lab[i] >> 1);
            }
        }
        FOR(i, m) {
            if (st[i] == i && sl[i] && s[i] != 1) {
                x = min(x, dvd(e[sl[i]][i]) >> s[i] + 1);
            }
        }
        FOR(i, n) {
            if (~s[st[i]]) {
                if ((lab[i] += (s[st[i]] * 2 - 1) * x) <= 0) return 0;
            }
        }
        for (int i = n + 1; i <= m; i++) {
            if (st[i] == i && ~s[st[i]]) {
                lab[i] += (2 - s[st[i]] * 4) * x;
            }
        }
        h = 1, t = 0;
        FOR(i, m) {
            if (st[i] == i && sl[i] && st[sl[i]] != i && !dvd(e[sl[i]][i]) && on(e[sl[i]][i])) {
                return 1;
            }
        }
        for (int i = n + 1; i <= m; i++) {
            if (st[i] == i && s[i] == 1 && !lab[i]) ex(i);
        }
    }
    return 0;
}
ll weightedBlossom() {

    fill(begin(ed), end(ed), 0);
    fill(begin(lk), end(lk), 0);
    fill(begin(st), end(st), 0);
    m = n;
    id = 0;
    iota(st + 1, st + n + 1, 1);
    T wm = 0;
    ll r = 0;
    FOR(i, n) FOR(j, n) {
        e[i][j] = {i, j, 0};
    }
    for (auto [u, v, w] : edges) {
        /* assert(1 <= u && u <= n && 1 <= v && v <= n) */;
        if (u == v || w <= 0) continue;
        /* assert((i128)w * max(1, n) * 4 < LLINF / 2) */;
        wm = max(wm, e[v][u].w = e[u][v].w = max(e[u][v].w, (T)w));
    }
    FOR(i, n) {
        p[i].clear();
    }
    FOR(i, n) FOR(j, n) {
        b[i][j] = i * (i == j);
    }
    fill_n(lab + 1, n, wm);
    while (bfs()) {
    };
    FOR(i, n) if (lk[i]) {
        r += e[i][lk[i]].w;
    }
    return r / 2;
}
vector<array<int, 2>> matchingEdges() {
    vector<array<int, 2>> ans;
    FOR(i, n) if (lk[i] > i) { // 每条匹配边只输出一次
        ans.push_back({i, lk[i]});
    }
    return ans;
}
```

### 二分图最大匹配

<a id="bipartite-matching"></a>

> 二分图：一个图能被分为左右两部分，任何一条边的两个端点都不在同一部分中。
> 
> 匹配（独立边集）：一个边的集合，这些边没有公共顶点。
> 
> 二分图最大匹配即找到边的数量最多的那个匹配。
> 
> 一般我们规定，左半部包含 $n_1$ 个点（编号 $1 - n_1$），右半部包含 $n_2$ 个点（编号 $1-n_2$ ），保证任意一条边的两个端点都不可能在同一部分中。

#### Kuhn 算法（DFS 增广）


这里是无权二分图的 DFS 增广（Kuhn），KM 指下一节的带权算法。左右编号分别为 1..nl、1..nr。只存左到右的 bg；initMatch 清空多测，ml/mr 保存双方伙伴，0 为未匹配。本组声明也供 Hopcroft–Karp 和 Konig 复用。

kuhn() 每次从空匹配开始，时间 O(nl*m+nl+nr)，存图 O(nl+nr+m)，额外空间 O(nl+nr)，递归深度 O(nl)。vis 用轮次避免每轮清空整张右侧数组。

```c++
int nl, nr, tick;
vector<vector<int>> bg;
vector<int> ml, mr, vis;
void initMatch(int L, int R) {
    nl = L; nr = R; bg.assign(nl + 1, {});
}
bool augment(int u) {
    for (int v : bg[u]) if (vis[v] != tick) {
        vis[v] = tick;
        if (!mr[v] || augment(mr[v])) { ml[u] = v; mr[v] = u; return true; }
    }
    return false;
}
int kuhn() {
    ml.assign(nl + 1, 0); mr.assign(nr + 1, 0); vis.assign(nr + 1, 0);
    int ans = 0; tick = 0;
    for (int u = 1; u <= nl; ++u) { ++tick; ans += augment(u); }
    return ans;
}
```

例：`initMatch(2,2); bg[1]={1,2}; bg[2]={1}; kuhn();` 返回 2。

#### Hopcroft–Karp 算法（分层增广）


复用上节 nl,nr,bg,ml,mr 和 initMatch，只需声明及初始化部分，不依赖 kuhn/augment。BFS 找最短增广层数，DFS 在该层图上同时增广；时间 O((nl+nr+m)√(nl+nr))，额外空间 O(nl+nr)，递归深度 O(nl)。每次重新计算，左右均为 1-based，0 为未匹配。

```c++
vector<int> level, cur;
int lim;
bool matchBfs() {
    level.assign(nl + 1, -1);
    queue<int> q;
    for (int u = 1; u <= nl; ++u) if (!ml[u]) level[u] = 0, q.push(u);
    lim = nl + 1;
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (level[u] >= lim) continue;
        for (int v : bg[u]) {
            if (!mr[v]) lim = level[u] + 1;
            else if (level[mr[v]] == -1) level[mr[v]] = level[u] + 1, q.push(mr[v]);
        }
    }
    return lim <= nl;
}
bool matchDfs(int u) {
    for (int &i = cur[u]; i < (int)bg[u].size(); ++i) {
        int v = bg[u][i], p = mr[v];
        if ((!p && level[u] + 1 == lim) || (p && level[p] == level[u] + 1 && matchDfs(p))) {
            ml[u] = v; mr[v] = u; return true;
        }
    }
    level[u] = -1; return false;
}
int hopcroftKarp() {
    ml.assign(nl + 1, 0); mr.assign(nr + 1, 0);
    int ans = 0;
    while (matchBfs()) {
        cur.assign(nl + 1, 0);
        for (int u = 1; u <= nl; ++u) if (!ml[u]) ans += matchDfs(u);
    }
    return ans;
}
```

上节同一建图后调用 hopcroftKarp() 也返回 2，直接遍历 ml 输出方案。

### 二分图最大权匹配（二分图完美匹配）


<a id="weighted-bipartite-matching"></a>

本节独立存储；`initKm(L,R)` 取 n=max(L,R)，用 0 补齐缺边和虚点；`g[u][v]=max(g[u][v],w)` 合并重边。允许不匹配，负边丢弃，真实正权边才计入输出方案；不能直接用于强制使用真实边的完美匹配。时间 O(n³)，空间 O(n²)。单边权≤LLONG_MAX/8，顶标运算和总权不溢出 ll。

km() 重算最大权值；ansl/ansr 是补齐后的伙伴，可能对应虚边，读原图伙伴时判断 g 是否为正；lx/ly 为左右顶标，pre 为增广前驱。[UOJ #80](https://uoj.ac/problem/80)。

```c++
int n;
vector<vector<ll>> g;
vector<int> ansl, ansr, pre;
vector<ll> lx, ly;
void initKm(int L, int R) {
    n = max(L, R); g.assign(n + 1, vector<ll>(n + 1));
    ansl.resize(n + 1); ansr.resize(n + 1); pre.resize(n + 1);
    lx.resize(n + 1); ly.resize(n + 1);
}
void kmBfs(int x) {
    vector<bool> visl(n + 1), visr(n + 1);
    vector<ll> slack(n + 1, LLINF / 2); // 到交错树的最小松弛量
    queue<int> q;
    function<bool(int)> check = [&](int x) {
        visr[x] = 1;
        if (~ansr[x]) {
            q.push(ansr[x]);
            visl[ansr[x]] = 1;
            return false;
        }
        while (~x) {
            ansr[x] = pre[x];
            swap(x, ansl[pre[x]]);
        }
        return true;
    };
    q.push(x);
    visl[x] = 1;
    while (1) {
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            for (int y = 1; y <= n; ++y) {
                if (visr[y]) continue;
                ll del = lx[x] + ly[y] - g[x][y];
                if (del < slack[y]) {
                    pre[y] = x;
                    slack[y] = del;
                    if (!slack[y] && check(y)) return;
                }
            }
        }
        ll val = LLINF / 2;
        for (int i = 1; i <= n; ++i)
            if (!visr[i]) val = min(val, slack[i]);
        for (int i = 1; i <= n; ++i) {
            if (visl[i]) lx[i] -= val;
            if (visr[i]) ly[i] += val;
            else slack[i] -= val;
        }
        for (int i = 1; i <= n; ++i)
            if (!visr[i] && !slack[i] && check(i)) return;
    }
}
ll km() {
    fill(ansl.begin(), ansl.end(), -1);
    fill(ansr.begin(), ansr.end(), -1);
    fill(lx.begin(), lx.end(), 0);
    fill(ly.begin(), ly.end(), 0);
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= n; ++j) ly[i] = max(ly[i], g[j][i]);
    for (int i = 1; i <= n; ++i) kmBfs(i);
    ll res = 0;
    for (int i = 1; i <= n; ++i) res += g[i][ansl[i]];
    return res;
}

```

例：`initKm(2,2); g[1][1]=4; g[1][2]=5; g[2][1]=3; km();` 返回 8，ansl[1]=2。

### 二分图最大独立点集（Konig 定理）


<a id="konig"></a>

Konig 定理：二分图的最小点覆盖大小等于最大匹配，最大独立集大小为 nl+nr−最大匹配。需要具体方案时，先 kuhn() 或 hopcroftKarp()，再从左侧未匹配点沿「非匹配边向右、匹配边向左」遍历。

minCover() 依赖公共二分图及最大匹配结果；O(nl+nr+m) 时间、O(nl+nr) 额外空间。coverL/coverR 为最小点覆盖，取补集得到最大独立集；不能对非最大匹配调用。

```c++
vector<int> coverL, coverR;
void minCover() {
    vector<int> vl(nl + 1), vr(nr + 1);
    queue<int> q;
    for (int u = 1; u <= nl; ++u) if (!ml[u]) vl[u] = 1, q.push(u);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int v : bg[u]) if (v != ml[u] && !vr[v]) {
            vr[v] = 1;
            if (mr[v] && !vl[mr[v]]) vl[mr[v]] = 1, q.push(mr[v]);
        }
    }
    coverL.clear(); coverR.clear();
    for (int u = 1; u <= nl; ++u) if (!vl[u]) coverL.push_back(u);
    for (int v = 1; v <= nr; ++v) if (vr[v]) coverR.push_back(v);
}
```

例：initMatch(2,1)，两条边均指向右侧 1，最大匹配后 minCover() 得 coverR={1}，独立集为两个左点。

### 最长路（topsort+DP算法）


<a id="longest-path"></a>

依赖普通邻接表，输入须为 DAG；支持负权，有限距离及候选在 (-LLINF,LLINF)。longestPath(s) 返回是否无环，成功时 dis 为 s 到各点最长路，不可达为 -LLINF，ord 是全图拓扑序；失败时只得到部分结果。时间 O(n+m)，额外空间 O(n)，可重复调用。

SCC 缩点后以分量大小作点权可以求「路径能依次访问的分量总点数」，不等于原图最长简单路；一般图最长简单路不能直接用此模板。

```c++
vector<ll> dis;
vector<int> ord;
bool longestPath(int s = 1) {
    vector<int> deg(n + 1);
    for (int u = 1; u <= n; ++u) for (auto [v, w] : e[u]) ++deg[v];
    ord.clear(); dis.assign(n + 1, -LLINF); dis[s] = 0;
    for (int u = 1; u <= n; ++u) if (!deg[u]) ord.push_back(u);
    for (int i = 0; i < (int)ord.size(); ++i) {
        int u = ord[i];
        for (auto [v, w] : e[u]) {
            if (dis[u] != -LLINF) dis[v] = max(dis[v], dis[u] + w);
            if (!--deg[v]) ord.push_back(v);
        }
    }
    return (int)ord.size() == n;
}
```

例：`initGraph(3); add(1,2,-2); add(2,3,5); longestPath();`，dis[3]=3。

### 最短路径树（SPT问题）


<a id="shortest-path-tree"></a>

依赖带编号邻接表，非负权，使用无向 addEdge（有向图也可求最短路前驱树）。spt(s) 返回从 s 可达部分的树边权和，pre[u] 为最后一条边编号，-1 表示源点或不可达，treeEdges 为选中边编号，dis 为最短距离。

时间 O((n+m)log(n+m))，额外空间 O(n+m)，候选距离小于 LLINF、树边权和可用 ll 表示。只做严格松弛，避免零权前驱环；结果不保证在所有最短路径树中边权和最小，也不是 MST。可重复调用，不改变原图。

```c++
vector<ll> dis;
vector<int> pre, treeEdges;
ll spt(int s = 1) {
    dis.assign(n + 1, LLINF); pre.assign(n + 1, -1); treeEdges.clear();
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> q;
    q.push({dis[s] = 0, s});
    while (!q.empty()) {
        auto [d, u] = q.top(); q.pop();
        if (d != dis[u]) continue;
        for (auto [v, w, id] : e[u]) if (dis[v] > d + w) {
            pre[v] = id; q.push({dis[v] = d + w, v});
        }
    }
    ll sum = 0;
    for (int u = 1; u <= n; ++u) if (pre[u] != -1) {
        treeEdges.push_back(pre[u]); sum += get<2>(es[pre[u]]);
    }
    return sum;
}
```

例：`initGraph(3); addEdge(1,2,2); addEdge(2,3,3); addEdge(1,3,9); spt();` 返回 5，treeEdges={0,1}。

### 环与平面图例题

<a id="cycles-and-planarity"></a>

#### 输出任意一个三元环


竞赛图（任意两点之间恰有一条有向边），依赖邻接矩阵，initMatrix(n,0)，有边 g[u][v]=1。triangle() 返回 {u,v,w}，表示 u→v→w→u；没有则返回 {0,0,0}。时间 O(n²)，额外空间 O(n)，递归深度 O(n)；不能直接套一般有向图。[例题](https://codeforces.com/problemset/problem/117/C)。

```c++
vector<int> vis;
array<int, 3> tri;
bool triangleDfs(int u, int p) {
    vis[u] = 1;
    for (int v = 1; v <= n; ++v) if (g[u][v]) {
        if (p && g[v][p]) { tri = {p, u, v}; return true; }
        if (!vis[v] && triangleDfs(v, u)) return true;
    }
    return false;
}
array<int, 3> triangle() {
    vis.assign(n + 1, 0); tri = {};
    for (int u = 1; u <= n; ++u) if (!vis[u] && triangleDfs(u, 0)) break;
    return tri;
}
```

例：initMatrix(3,0)，设 g[1][2]=g[2][3]=g[3][1]=1，返回该三元环的循环排列。

#### 带权最小环大小与计数


依赖邻接矩阵：initMatrix(n,0)，g[u][v] 为**严格正权有向简单图**的边权，0 表示无边，允许自环、不能有重边。返回 {最小环长,数量}，无环为 {-1,0}；数量对 mod 取模，1≤mod≤INT_MAX。时间 O(n³)，额外空间 O(n²)，有限路径与闭环候选须小于 LLINF。不改 g，可重复调用；无向边拆双向会把来回同一条边计为环，不能直接套用。

```c++
pair<ll, ll> minCycle(int mod = MOD) {

    vector<vector<ll>> d(n + 1, vector<ll>(n + 1, LLINF)), cnt(n + 1, vector<ll>(n + 1));
    ll best = LLINF, ways = 0;
    auto add = [&](ll v, ll c) {
        if (v < best) {
            best = v;
            ways = c % mod;
        } else if (v == best) ways = (ways + c) % mod;
    };
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= n; ++j) {
            /* assert(g[i][j]>=0&&g[i][j]<LLINF) */;
            if (i == j) {
                d[i][j] = 0;
                cnt[i][j] = 1 % mod;
                if (g[i][i]) add(g[i][i], 1);
            } else if (g[i][j]) {
                d[i][j] = g[i][j];
                cnt[i][j] = 1 % mod;
            }
        }
    for (int k = 1; k <= n; ++k) {
        // k 为环的最大编号；从 k 的出边和一条回到 k 的最短路组成环。
        for (int i = 1; i < k; ++i)
            if (g[k][i] && d[i][k] != LLINF) add(g[k][i] + d[i][k], cnt[i][k]);
        for (int i = 1; i <= n; ++i)
            if (i != k && d[i][k] != LLINF)
                for (int j = 1; j <= n; ++j)
                    if (j != k && d[k][j] != LLINF) {
                        ll v = d[i][k] + d[k][j], c = cnt[i][k] * cnt[k][j] % mod;
                        if (v < d[i][j]) {
                            d[i][j] = v;
                            cnt[i][j] = c;
                        } else if (v == d[i][j]) cnt[i][j] = (cnt[i][j] + c) % mod;
                    }
    }
    return best == LLINF ? make_pair(-1LL, 0LL) : make_pair(best, ways);
}
```

例：initMatrix(2,0)，g[1][2]=2，g[2][1]=3，minCycle()={5,1}。

#### 最小环大小


无向正权简单图的 Floyd 版，依赖邻接矩阵：initMatrix(n)，无向边取最小权，不支持自环和重边形成的二元环。时间 O(n³)，额外空间 O(n²)；无环返回 LLINF，有限路径及候选环长小于 LLINF。保留 g，内部复制距离，可重复调用。

```c++
ll minCycleUndirected() {
    auto d = g;
    ll ans = LLINF;
    for (int k = 1; k <= n; ++k) {
        for (int u = 1; u < k; ++u) for (int v = 1; v < u; ++v)
            if (d[u][v] != LLINF && g[u][k] != LLINF && g[k][v] != LLINF) {
                i128 cur = i128(d[u][v]) + g[u][k] + g[k][v];
                if (cur < ans) ans = (ll)cur;
            }
        for (int u = 1; u <= n; ++u) if (d[u][k] != LLINF)
            for (int v = 1; v <= n; ++v) if (d[k][v] != LLINF)
                d[u][v] = min(d[u][v], d[u][k] + d[k][v]);
    }
    return ans;
}
```

无向无权简单图的 BFS 版，改为依赖**普通邻接表**，双向建边。每个起点跑一次 BFS，时间 O(n(n+m))，额外空间 O(n)；无环返回 -1，不支持自环、重边。

```c++
int girth() {
    int ans = n + 1;
    for (int s = 1; s <= n; ++s) {
        vector<int> d(n + 1, -1), fa(n + 1);
        queue<int> q; q.push(s); d[s] = 0;
        while (!q.empty()) {
            int u = q.front(); q.pop();
            for (auto [v, w] : e[u]) {
                if (v == fa[u]) continue;
                if (d[v] == -1) d[v] = d[u] + 1, fa[v] = u, q.push(v);
                else ans = min(ans, d[u] + d[v] + 1);
            }
        }
    }
    return ans == n + 1 ? -1 : ans;
}
```

例：单位权三角形，两版均返回 3；一条链分别返回 LLINF 和 -1。

#### 本质不同简单环计数


依赖普通邻接表，无自环、无重边的无向图，双向建边、忽略权。按最小编号顶点固定起点，状压 DP 计数，反向视为同一环。时间 O((n+m)2^n)，空间 O(n2^n)，建议 n≤19；所有中间计数须能放入 ll。n=19 时主要 DP 约 76 MiB；不能拿此算法处理大图。[CF 11D](https://codeforces.com/contest/11/problem/D)。

```c++
ll countCycles() {
    int lim = 1LL << n;
    vector<vector<ll>> dp(lim, vector<ll>(n));
    for (int u = 0; u < n; ++u) dp[1LL << u][u] = 1;
    ll ans = 0;
    for (int mask = 1; mask < lim; ++mask) {
        int s = __builtin_ctzll((ull)mask);
        for (int u = s; u < n; ++u) if (dp[mask][u])
            for (auto [v1, w] : e[u + 1]) {
                int v = v1 - 1;
                if (v < s) continue;
                if (!(mask >> v & 1)) dp[mask | (1LL << v)][v] += dp[mask][u];
                else if (v == s && __builtin_popcountll((ull)mask) >= 3) ans += dp[mask][u];
            }
    }
    return ans / 2;
}
```

例：无向三角形返回 1；完全图 K4 返回 7。

#### 输出任意一个非二元简单环


依赖普通邻接表，无向简单图，双向建边；无自环、无重边，忽略权。findSimpleCycle() 返回是否有环，cycle 保存沿环顺序的顶点，末尾不重复起点；不保证最短。时间 O(n+m)，额外空间和递归深度 O(n)，覆盖所有分量，不在函数内输出或 exit。[例题](https://codeforces.com/problemset/problem/1364/D)。

```c++
vector<int> dep, fa, cycle;
bool simpleCycleDfs(int u) {
    for (auto [v, w] : e[u]) {
        if (v == fa[u]) continue;
        if (dep[v] == -1) {
            dep[v] = dep[u] + 1; fa[v] = u;
            if (simpleCycleDfs(v)) return true;
        } else if (dep[v] < dep[u]) {
            cycle = {v};
            for (int x = u; x != v; x = fa[x]) cycle.push_back(x);
            return true;
        }
    }
    return false;
}
bool findSimpleCycle() {
    dep.assign(n + 1, -1); fa.assign(n + 1, 0); cycle.clear();
    for (int u = 1; u <= n; ++u) if (dep[u] == -1) {
        dep[u] = 0;
        if (simpleCycleDfs(u)) return true;
    }
    return false;
}
```

例：双向三角形返回 true，cycle.size()=3；森林返回 false。

#### 有向图环计数


依赖普通邻接表，统计 DFS 返祖边条数。只有每点出度至多 1 的函数图中，它才等于有向环数；一般有向图的结果可能随边遍历顺序改变，只能用 >0 判有环。时间 O(n+m)，额外空间 O(n)，使用显式栈避免深递归。可重复调用。

```c++
ll backEdges() {
    vector<int> vis(n + 1), cur(n + 1), st;
    ll ans = 0;
    for (int s = 1; s <= n; ++s) if (!vis[s]) {
        vis[s] = 1; st.push_back(s);
        while (!st.empty()) {
            int u = st.back();
            if (cur[u] == (int)e[u].size()) { vis[u] = 2; st.pop_back(); continue; }
            int v = e[u][cur[u]++].first;
            if (!vis[v]) vis[v] = 1, st.push_back(v);
            else if (vis[v] == 1) ++ans;
        }
    }
    return ans;
}
```

例：`initGraph(3); add(1,2); add(2,1); add(3,3); backEdges();` 返回 2。

#### 有向图简单环检查、输出


依赖带编号邻接表，有向边用 addEdge(u,v,w,false)。findCycle(false) 搜索任意有向简单环；也作为下一节无向版的公共实现。支持自环、重边、不连通图，时间 O(n+m)，额外空间 O(n)，显式 DFS 栈。

返回是否找到，cv 为顺序顶点，ce[i] 为 cv[i]→cv[(i+1)%长度] 的原边编号；末尾不重复起点。每次清空旧结果，原图不变。[例题](https://ac.nowcoder.com/acm/contest/94803/1004)。

```c++
vector<int> cv, ce;
bool findCycle(bool undirected = false) {
    cv.clear(); ce.clear();
    vector<int> vis(n + 1), cur(n + 1), fa(n + 1), pe(n + 1, -1), st;
    for (int s = 1; s <= n; ++s) if (!vis[s]) {
        st = {s}; vis[s] = 1;
        while (!st.empty()) {
            int u = st.back();
            if (cur[u] == (int)e[u].size()) { vis[u] = 2; st.pop_back(); continue; }
            auto [v, w, id] = e[u][cur[u]++];
            if (undirected && id == pe[u]) continue;
            if (!vis[v]) {
                fa[v] = u; pe[v] = id; vis[v] = 1; st.push_back(v);
            } else if (vis[v] == 1) {
                for (int x = u; x != v; x = fa[x]) cv.push_back(x), ce.push_back(pe[x]);
                cv.push_back(v);
                reverse(cv.begin(), cv.end()); reverse(ce.begin(), ce.end());
                ce.push_back(id); return true;
            }
        }
    }
    return false;
}
```

例：1→2、2→1 分别为边 0、1，则 cv={1,2}，ce={0,1}。

#### 无向图简单环检查、输出


复制带编号邻接表和上一节 findCycle，建无向边后调用 findCycle(true)。只跳过父边编号，保留其他平行边，支持自环和二元环；时间 O(n+m)、额外空间 O(n)。cv/ce 的对应关系与有向版相同，边可以沿任意方向走；失败时数组为空。[例题](https://ac.nowcoder.com/acm/contest/94803/1005)。

```c++
bool undirectedCycle() { return findCycle(true); }
```

例：`initGraph(2); addEdge(1,2); addEdge(1,2); undirectedCycle();` 返回 true，ce 包含 0、1。

#### 判定带环图是否是平面图


给定一个固定环的顶点循环顺序和额外弦，将每条弦放环内或环外，使同侧弦不相交；不是一般平面图判定。两条弦端点严格交错时必须异侧，共端点不算冲突。[CF 27D](https://codeforces.com/contest/27/problem/D)、[P3209](https://www.luogu.com.cn/problem/P3209)。

依赖普通邻接表 → SCC → 下方 2-Sat。chords 保存端点在环上的位置（1-based），planarChords() 返回是否可行，ans[i] 给第 i 条弦的侧别。弦数 k，时间 / 空间 O(k²+k)，会重建公共 e 和 SCC 状态，原环只需存位置，不必建入 e。

```c++
vector<pair<int, int>> chords;
bool planarChords() {
    int k = chords.size(); initSat(k);
    for (int i = 0; i < k; ++i) for (int j = i + 1; j < k; ++j) {
        auto [a, b] = chords[i]; auto [c, d] = chords[j];
        if (a > b) swap(a, b);
        if (c > d) swap(c, d);
        if ((a < c && c < b && b < d) || (c < a && a < d && d < b)) {
            clause(i, 0, j, 0); clause(i, 1, j, 1);
        }
    }
    return twoSat();
}
```

例：chords={{1,3},{2,4}}，返回 true，ans[0] 与 ans[1] 不同。

### 欧拉路径/欧拉回路 Hierholzers

<a id="euler-paths"></a>

> 欧拉路径：一笔画完图中全部边，画的顺序就是一个可行解；当起点终点相同时称欧拉回路。

#### 有向图欧拉路径存在判定


依赖带编号邻接表；有向图 addEdge 的末参为 false。忽略孤立点后底层无向图须连通，出度−入度均为 0，或恰有一个 +1 起点、一个 −1 终点。eulerStart(false) 返回是否存在，成功时全局 s,t 为端点；空边图取 s=t=1。

下方也供无向版复用：根据 es 统计度数和底层连通性，不改 e；时间 O(n+m)，额外空间 O(n+m)，支持自环、重边。每次重算，失败时 s,t 不可用于求路径。

```c++
int s, t;
bool eulerStart(bool undirected = false) {
    vector<int> in(n + 1), out(n + 1), vis(n + 1);
    vector<vector<int>> weak(n + 1);
    for (auto [u, v, w] : es) {
        ++out[u]; ++in[v]; weak[u].push_back(v); weak[v].push_back(u);
        if (undirected) ++out[v], ++in[u];
    }
    int first = 1, starts = 0, ends = 0, odd = 0;
    s = t = 0;
    for (int u = 1; u <= n; ++u) {
        if (!weak[u].empty() && weak[first].empty()) first = u;
        if (undirected) {
            if (out[u] & 1) { if (!odd) s = u; t = u; ++odd; }
        } else {
            int d = out[u] - in[u];
            if (d == 1) s = u, ++starts;
            else if (d == -1) t = u, ++ends;
            else if (d) return false;
        }
    }
    if (undirected ? (odd != 0 && odd != 2) : !((starts == 0 && ends == 0) || (starts == 1 && ends == 1))) return false;
    if (!s) s = t = first;
    vector<int> q{s}; vis[s] = 1;
    for (int i = 0; i < (int)q.size(); ++i)
        for (int v : weak[q[i]]) if (!vis[v]) vis[v] = 1, q.push_back(v);
    for (int u = 1; u <= n; ++u) if (!weak[u].empty() && !vis[u]) return false;
    return true;
}
```

例：1→2→3 返回 true，s=1,t=3；两个互不连通的有向环返回 false。

#### 无向图欧拉路径存在判定


复用上节 eulerStart，全部使用无向 addEdge，再调用 eulerStart(true)。忽略孤立点后须连通，奇度点数为 0 或 2；自环度数为 2，重边分别计数，无边图视为存在空路径。时间 / 额外空间 O(n+m)，成功时 s,t 为端点。

```c++
bool undirectedEulerStart() { return eulerStart(true); }
```

例：无向链 1—2—3，s=1,t=3；两个平行边 1—2 构成欧拉回路。

#### 有向图欧拉路径求解（字典序最小）


依赖带编号邻接表和 eulerStart。euler(false,true) 自动判存在性，按邻点升序运行迭代 Hierholzer；开放路径使用唯一合法起点，回路使用最小非孤立点。path 是顶点序列，pathEdge[i] 对应 path[i]→path[i+1]。失败时结果为空，空边图 path={1}。

sortEdges=true 时原邻接表会排序（边编号不变），时间 O(n+m log(m+1))；false 时 O(n+m)，只保证任意合法路径。额外空间 O(n+m)，原边不删除，可重复调用。

```c++
vector<int> path, pathEdge;
bool euler(bool undirected = false, bool sortEdges = true) {
    path.clear(); pathEdge.clear();
    if (!eulerStart(undirected)) return false;
    if (sortEdges) for (auto &a : e) sort(a.begin(), a.end());
    vector<int> cur(n + 1), used(es.size());
    vector<pair<int, int>> st{{s, -1}};
    while (!st.empty()) {
        int u = st.back().first;
        while (cur[u] < (int)e[u].size() && used[get<2>(e[u][cur[u]])]) ++cur[u];
        if (cur[u] == (int)e[u].size()) {
            path.push_back(u);
            if (st.back().second != -1) pathEdge.push_back(st.back().second);
            st.pop_back();
        } else {
            auto [v, w, id] = e[u][cur[u]++]; used[id] = 1; st.push_back({v, id});
        }
    }
    reverse(path.begin(), path.end()); reverse(pathEdge.begin(), pathEdge.end());
    return true;
}
```

例：边 1→2、2→1、1→3，euler() 返回 true，path={1,2,1,3}。

#### 无向图欧拉路径求解


复用上一节 euler，全部使用无向 addEdge，调用 euler(true,false) 即可，O(n+m) 时间 / 额外空间。支持自环和重边，两端邻接项通过同一原边编号只消费一次；原图不删除。需要按邻点顺序选边时末参为 true，增加排序开销。

```c++
bool undirectedEuler() { return euler(true, false); }
```

例：两个平行边 1—2，path={1,2,1}，pathEdge 含两条不同原边编号。

### 差分约束


<a id="difference-constraints"></a>

对约束 x[u]−x[v]≤w，在普通邻接表中 add(v,u,w)。differenceConstraints() 用 Bellman–Ford 求可行解；全部初值 0 等价于超级源点连 0 权边，返回 false 表示有负环、无解。时间 O(n(n+m))，额外空间 O(n)；中间运算用 i128，不溢出其范围，成功后 dis 为一组解，转 ll 前自行确认范围。[P5960](https://www.luogu.com.cn/problem/P5960)。

```c++
vector<i128> dis;
bool differenceConstraints() {
    dis.assign(n + 1, 0);
    for (int k = 1; k <= n; ++k) {
        bool changed = false;
        for (int u = 1; u <= n; ++u) for (auto [v, w] : e[u])
            if (dis[v] > dis[u] + w) dis[v] = dis[u] + w, changed = true;
        if (!changed) return true;
    }
    return false;
}
```

例：`initGraph(2); add(2,1,-3); differenceConstraints();` 返回 true，dis[1]=-3、dis[2]=0。

### 2-Sat

<a id="two-sat"></a>

#### 2-Sat 全局函数


依赖普通邻接表和 SCC，实现直接复用 tarjan。变量编号 0..vars−1，内部图节点为 1..2*vars：node(u,f)=2*u+f+1 表示 x[u]=f。initSat(k) 会设置公共 n=2*k 并清空 e；clause(u,f,v,g) 添加 (x[u]=f)∨(x[v]=g)。

twoSat() 返回是否有解，成功时 ans[u] 为任一可行赋值，不保证字典序最小；无解时 ans 清空。时间 / 空间 O(vars+子句数)，SCC 递归深度 O(vars)。可以增添子句后重新调用。

```c++
int vars;
vector<int> ans;
int node(int u, bool f) { return 2 * u + f + 1; }
void initSat(int k) { vars = k; initGraph(2 * k); ans.clear(); }
void clause(int u, bool f, int v, bool g) {
    add(node(u, !f), node(v, g)); add(node(v, !g), node(u, f));
}
bool twoSat() {
    scc(); ans.assign(vars, 0);
    for (int u = 0; u < vars; ++u) {
        if (col[node(u, 0)] == col[node(u, 1)]) { ans.clear(); return false; }
        ans[u] = col[node(u, 1)] < col[node(u, 0)];
    }
    return true;
}
```

例：`initSat(1); clause(0,1,0,1); twoSat();` 返回 true，ans[0]=1。

#### 答案不唯一时不输出


依赖普通邻接表和 2-Sat，先确认 twoSat() 有解。forced(u) 返回 0/1 表示唯一取值，-1 表示两种都可行；每次检查从某个取值能否推出其否定。每个变量 O(n+m) 时间 / 额外空间，全部变量 O(vars*(n+m))；不改图或 ans。

```c++
bool reachable(int s, int t) {
    vector<int> vis(n + 1), q{s}; vis[s] = 1;
    for (int i = 0; i < (int)q.size(); ++i) {
        int u = q[i];
        if (u == t) return true;
        for (auto [v, w] : e[u]) if (!vis[v]) vis[v] = 1, q.push_back(v);
    }
    return false;
}
int forced(int u) {
    if (reachable(node(u, 0), node(u, 1))) return 1;
    if (reachable(node(u, 1), node(u, 0))) return 0;
    return -1;
}
```

例：上节强制 x[0]=1 后 forced(0)=1；无任何子句时为 -1，主程序可输出 `?`。

### 网络流与割

<a id="network-flow"></a>


#### 残量网络公共代码

<a id="flow-base"></a>

本组独立存储，不复制普通邻接表。n 为点数，1..n 编号；e[u] 存边下标，edge[id] 存终点 v、当前残量 c、初始容量 cap。正反边相邻，反边为 id^1；Edge 仅是数据记录。addFlow 加有向容量边，自环和重边均可保存；无向容量边要调用两次 addFlow(u,v,c)、addFlow(v,u,c)。

initFlow 清空多测，resetFlow 用 O(m) 时间恢复零流，cutSide(s) 用 O(n+m) 时间求残量可达集合 side；最大流结束后 side 给出最小割源侧。建图时间 / 空间 O(n+m)。容量非负，所有容量之和须可用 ll 表示；源汇不同。

```c++
int n;
struct Edge { int v; ll c, cap; };
vector<Edge> edge;
vector<vector<int>> e;
vector<int> side;
void initFlow(int N) { n = N; e.assign(n + 1, {}); edge.clear(); }
int addFlow(int u, int v, ll c) {
    int id = edge.size();
    e[u].push_back(id); edge.push_back({v, c, c});
    e[v].push_back(id ^ 1); edge.push_back({u, 0, 0});
    return id;
}
void resetFlow() { for (auto &a : edge) a.c = a.cap; }
void cutSide(int s) {
    side.assign(n + 1, 0);
    vector<int> q{s}; side[s] = 1;
    for (int i = 0; i < (int)q.size(); ++i) for (int id : e[q[i]]) {
        auto [v, c, cap] = edge[id];
        if (c > 0 && !side[v]) side[v] = 1, q.push_back(v);
    }
}
```

#### 最大流


<a id="dinic"></a>

依赖残量网络公共代码。Dinic 理论最坏 O(n²m)，额外空间 O(n)，DFS 递归深度 O(n)。dinic(s,t) 修改残量网络并返回**本次追加流量**；同一源汇跑完再调用为 0。独立重算或更换源汇前先 resetFlow()。要求 s!=t、总流量可用 ll 表示。

```c++
vector<int> level, cur;
bool flowBfs(int s, int t) {
    level.assign(n + 1, -1); level[s] = 0;
    queue<int> q; q.push(s);
    while (!q.empty()) {
        int u = q.front(); q.pop();
        for (int id : e[u]) {
            auto [v, c, cap] = edge[id];
            if (c > 0 && level[v] == -1) level[v] = level[u] + 1, q.push(v);
        }
    }
    return level[t] != -1;
}
ll flowDfs(int u, int t, ll f) {
    if (u == t) return f;
    ll rest = f;
    for (int &i = cur[u]; i < (int)e[u].size(); ++i) {
        int id = e[u][i], v = edge[id].v;
        if (edge[id].c > 0 && level[v] == level[u] + 1) {
            ll sent = flowDfs(v, t, min(rest, edge[id].c));
            edge[id].c -= sent; edge[id ^ 1].c += sent; rest -= sent;
            if (!rest) break;
        }
    }
    return f - rest;
}
ll dinic(int s, int t) {
    ll ans = 0;
    while (flowBfs(s, t)) {
        cur.assign(n + 1, 0); ans += flowDfs(s, t, LLONG_MAX);
    }
    return ans;
}
```

例：`initFlow(3); addFlow(1,2,7); addFlow(2,3,5); dinic(1,3);` 返回 5；cutSide(1) 后 side[2]=1，side[3]=0。

#### 最大流：预流推进 HLPP


<a id="hlpp"></a>

依赖残量网络公共代码，与 Dinic 共用同一图；最高标号活动点选择、当前弧，最坏时间 O(n²√m)，额外空间 O(n)。hlpp(s,t) 每次 resetFlow 从零流重算，返回完整最大流；结束后 edge 为可用于 cutSide 的残量网络。

容量及所有容量之和须能放入 ll，s!=t；自环忽略，重边保留。h 为高度，ex 为超额流，bucket 按高度存活动点；pc 与 Dinic 的 cur 分开，便于同图比较。实际速度按题目图形测试。

```c++
int src, dst, hi;
vector<int> h, pc, active;
vector<ll> ex;
vector<vector<int>> bucket;
void wake(int u) {
    if (u == src || u == dst || ex[u] <= 0 || active[u]) return;
    active[u] = 1; bucket[h[u]].push_back(u); hi = max(hi, h[u]);
}
void pushFlow(int u, int id) {
    int v = edge[id].v;
    ll f = min(ex[u], edge[id].c);
    if (!f) return;
    edge[id].c -= f; edge[id ^ 1].c += f;
    ex[u] -= f; ex[v] += f; wake(v);
}
ll hlpp(int s, int t) {
    resetFlow(); src = s; dst = t; hi = 0;
    h.assign(n + 1, 0); pc.assign(n + 1, 0); ex.assign(n + 1, 0);
    active.assign(n + 1, 0); bucket.assign(2 * n + 1, {}); h[s] = n;
    for (int id : e[s]) if (edge[id].v != s && edge[id].c > 0) {
        int v = edge[id].v; ll f = edge[id].c;
        edge[id].c = 0; edge[id ^ 1].c += f;
        ex[s] -= f; ex[v] += f; wake(v);
    }
    while (hi >= 0) {
        if (bucket[hi].empty()) { --hi; continue; }
        int u = bucket[hi].back(); bucket[hi].pop_back(); active[u] = 0;
        while (ex[u] > 0) {
            if (pc[u] == (int)e[u].size()) {
                int nh = 2 * n;
                for (int id : e[u]) if (edge[id].c > 0) nh = min(nh, h[edge[id].v] + 1);
                h[u] = nh; pc[u] = 0; wake(u); break;
            }
            int id = e[u][pc[u]], v = edge[id].v;
            if (edge[id].c > 0 && h[u] == h[v] + 1) pushFlow(u, id);
            else ++pc[u];
        }
    }
    return ex[t];
}
```

例：沿用 Dinic 的三点建图，hlpp(1,3) 连续两次都返回 5。

#### 最小割


<a id="min-cut"></a>

最大流后 cutSide(s) 标出的残量可达集合就是最小割源侧；原图中从源侧指向其余点的容量边组成割。下面是最大权闭合子图的项目/材料模型：项目收益非负，材料成本非负，选择项目须购买其全部依赖材料。

依赖残量网络和 Dinic；profit[1..P]、cost[1..R]、need[1..P] 为全局输入，need[i] 存所需材料编号。maxProfit() 重建公共流图，返回最大净收益，side[i] 表示选项目，side[P+j] 表示购买材料。建图 O(P+R+依赖数)，流复杂度按 Dinic；空间 O(P+R+依赖数)。总收益须小于 LLONG_MAX，容量总和亦须可表示。

```c++
vector<ll> profit, cost;
vector<vector<int>> need;
ll maxProfit() {
    int P = (int)profit.size() - 1, R = (int)cost.size() - 1;
    int s = P + R + 1, t = s + 1; initFlow(t);
    ll sum = accumulate(profit.begin() + 1, profit.end(), 0LL);
    for (int i = 1; i <= P; ++i) {
        addFlow(s, i, profit[i]);
        for (int j : need[i]) addFlow(i, P + j, sum + 1);
    }
    for (int j = 1; j <= R; ++j) addFlow(P + j, t, cost[j]);
    ll ans = sum - dinic(s, t); cutSide(s); return ans;
}
```

例：profit={0,10,4}、cost={0,7,9}、need={{},{1},{1,2}}，返回 3。

#### 无源汇点的最小割问题 Stoer–Wagner


<a id="stoer-wagner"></a>

全局最小割：将无向图顶点分成两个非空集合，跨集合边权和最小。依赖邻接矩阵，initMatrix(n,0)，非负容量边执行 g[u][v]+=w、g[v][u]+=w，自环忽略，重边累加。时间 O(n³)，额外空间 O(n²)；n<2 或不连通返回 0，所有容量之和须能放入 ll。mincut() 复制后收缩，不改原图，可重复调用。

```c++
ll mincut() {
    auto mat = g; // 保留原图，收缩副本
    if (n < 2) return 0;
    vector<int> a(n);
    iota(a.begin(), a.end(), 1); // 尚未被收缩的点
    ll ans = LLONG_MAX;
    while (a.size() > 1) {
        vector<ll> w(n + 1);
        vector<bool> vis(n + 1);
        int prev = -1;
        for (int i = 0; i < (int)(a.size()); ++i) {
            int u = -1;
            for (int v : a)
                if (!vis[v] && (u == -1 || w[v] > w[u])) u = v;
            if (i + 1 == (int)(a.size())) {
                ans = min(ans, w[u]);
                if (ans == 0) return 0;
                for (int v : a)
                    if (v != prev && v != u) mat[prev][v] = mat[v][prev] = mat[prev][v] + mat[u][v];
                a.erase(find(a.begin(), a.end(), u));
                break;
            }
            vis[u] = true;
            prev = u;
            for (int v : a)
                if (!vis[v]) w[v] += mat[u][v];
        }
    }
    return ans;
}

```

例：三点完全图每条边权 1，返回 2。

#### 最小割树 Gomory-Hu Tree


<a id="gomory-hu"></a>

依赖残量网络和 Dinic，无向非负容量边用两次 addFlow 建双向容量；n≥1，容量和可用 ll 表示。gomoryHu() 求 n−1 次最大流，最坏 O(n³m) 时间，含图 O(n+m) 空间。每次求流先恢复容量，结束后也恢复零流；fa/cut/tree 保留最小割树，原图不变，可重复调用。

任意两点最小割为树路径最小边权，不连通点对为 0。buildCutTable() 是可选的 O(n²) 时间 / 空间全点对预处理，将答案放入 cutAns，同点约定 0；大图应改用树上倍增查询路径最小值。

```c++
vector<int> fa;
vector<ll> cut;
vector<vector<pair<int, ll>>> tree;
vector<vector<ll>> cutAns;
void gomoryHu() {
    fa.assign(n + 1, 1); fa[1] = 0; cut.assign(n + 1, 0);
    for (int s = 2; s <= n; ++s) {
        int t = fa[s]; resetFlow(); ll value = dinic(s, t); cutSide(s);
        for (int u = s + 1; u <= n; ++u) if (fa[u] == t && side[u]) fa[u] = s;
        if (side[fa[t]]) {
            fa[s] = fa[t]; fa[t] = s; cut[s] = cut[t]; cut[t] = value;
        } else cut[s] = value;
    }
    tree.assign(n + 1, {});
    for (int u = 2; u <= n; ++u) {
        tree[u].push_back({fa[u], cut[u]}); tree[fa[u]].push_back({u, cut[u]});
    }
    resetFlow();
}
void buildCutTable() {
    cutAns.assign(n + 1, vector<ll>(n + 1));
    for (int s = 1; s <= n; ++s) {
        vector<tuple<int, int, ll>> st{{s, 0, LLONG_MAX}};
        while (!st.empty()) {
            auto [u, p, val] = st.back(); st.pop_back();
            cutAns[s][u] = u == s ? 0 : val;
            for (auto [v, w] : tree[u]) if (v != p) st.push_back({v, u, min(val, w)});
        }
    }
}
```

例：三点无向单位权三角形，gomoryHu(); buildCutTable(); 后任意不同点的 cutAns 均为 2。

#### 费用流


<a id="min-cost-flow"></a>

本节独立全局残量存储，点 1..n。initCost(n) 清空多测；addCost(u,v,c,f) 加容量 c、单位费用 f 的有向边，边记录 e、邻接边号 g 可直接读。容量和流量使用 ll，h 为势能，dis 为约化费用距离，pre 为增广前驱边。

minCostFlow(s,t) 返回 {本次追加流量,本次追加费用}，修改残量；同源汇连续调用可追加，更换源汇须重新建图。允许负费用边但输入**无负费用环**；不处理负费用循环流，初始化发现源点可达负环会抛异常。s!=t，容量非负，总流量与总费用不溢出 ll，距离、势能及中间运算绝对值小于 LLINF，有限负环检测过程也须不溢出。

初始有负费用边先 Bellman–Ford，再用势能+Dijkstra，时间 O(n(n+m)+K(n+m)log(n+m))，K 为增广次数；费用均非负时略去 Bellman–Ford。含图空间 O(n+m)，堆可占 O(m)。

```c++
int n;
struct Edge { int v; ll c, f; };
vector<Edge> e;
vector<vector<int>> g;
vector<ll> h, dis;
vector<int> pre;
void initCost(int N) { n = N; e.clear(); g.assign(n + 1, {}); }
void addCost(int u, int v, ll c, ll f) {
    int id = e.size();
    g[u].push_back(id); e.push_back({v, c, f});
    g[v].push_back(id ^ 1); e.push_back({u, 0, -f});
}
void initH(int s) {
    h.assign(n + 1, 0);
    bool negative = false;
    for (auto edge : e) negative |= edge.c > 0 && edge.f < 0;
    if (!negative) return;
    h.assign(n + 1, LLINF);
    h[s] = 0;
    for (int step = 0; step < n; ++step) {
        bool changed = false;
        for (int u = 1; u <= n; ++u) {
            if (h[u] == LLINF) continue;
            for (int i : g[u]) {
                auto [v, c, f] = e[i];
                if (c > 0 && h[v] > h[u] + f) {
                    h[v] = h[u] + f;
                    changed = true;
                }
            }
        }
        if (!changed) break;
        if (step == n - 1) throw invalid_argument("reachable negative cost cycle");
    }
    for (auto &x : h)
        if (x == LLINF) x = 0;
}
bool costDijkstra(int s, int t) {
    dis.assign(n + 1, LLINF);
    pre.assign(n + 1, -1);
    priority_queue<pair<ll, int>, vector<pair<ll, int>>, greater<pair<ll, int>>> que;
    dis[s] = 0;
    que.emplace(0, s);
    while (!que.empty()) {
        auto [d, u] = que.top();
        que.pop();
        if (dis[u] < d) continue;
        for (int i : g[u]) {
            auto [v, c, f] = e[i];
            if (c > 0 && dis[v] > d + h[u] - h[v] + f) {
                dis[v] = d + h[u] - h[v] + f;
                pre[v] = i;
                que.emplace(dis[v], v);
            }
        }
    }
    return dis[t] != LLINF;
}
pair<ll, ll> minCostFlow(int s, int t) {
    ll flow = 0;
    ll cost = 0;
    /* assert(s != t) */;
    initH(s);
    while (costDijkstra(s, t)) {
        for (int i = 1; i <= n; ++i)
            if (dis[i] != LLINF) h[i] += dis[i];
        ll aug = LLONG_MAX;
        for (int i = t; i != s; i = e[pre[i] ^ 1].v) aug = min(aug, e[pre[i]].c);
        for (int i = t; i != s; i = e[pre[i] ^ 1].v) {
            e[pre[i]].c -= aug;
            e[pre[i] ^ 1].c += aug;
        }
        flow += aug;
        cost += ll(aug) * h[t];
    }
    return {flow, cost};
}
```

例：`initCost(3); addCost(1,2,2,-1); addCost(2,3,2,3); minCostFlow(1,3);` 返回 {2,4}。
