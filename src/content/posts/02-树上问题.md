## 第二章：树上问题

[树上进阶模型题 100 题](#tree100)：路径、DP、颜色、虚树、点分治、持久化、同构与综合应用。


### 比赛速查与约定

<a id="quick-reference"></a>

默认复用第 01 章缺省源，GNU C++17；支持按需启用 `#define int long long`。除特别说明，点编号 1..n、n≥1，输入为连通无环的无向树，数组下标 0 占位。先加边再预处理，之后不改拓扑；多测先 `initTree(n)`，再重建本题使用的辅助数据。距离、点权和答案用 ll，所有中间加减乘也须在其范围内；超出时按题意改用 i128。

| 需求 | 模板 | 时间 / 空间 | 要点 |
| --- | --- | --- | --- |
| 无权直径 | [diameter](#diameter) | $\mathcal{O}(n)$ / $\mathcal{O}(n)$ | 两遍遍历，返回端点和长度 |
| 带权直径、中心、重心 | [metrics](#tree-metrics) | $\mathcal{O}(n)$ / $\mathcal{O}(n)$ | 边权非负；中心按顶点选，重心按点数选 |
| LCA、祖先、路径第 k 点 | [HLD](#lca) | 建树 $\mathcal{O}(n)$，查询 $\mathcal{O}(\log n)$ / $\mathcal{O}(n)$ | 无需线段树；k 从 0 开始 |
| 带权距离、路径最大边 | [LCA](#binary-lifting) | 建树 $\mathcal{O}(n \log n)$，查询 $\mathcal{O}(\log n)$ / $\mathcal{O}(n \log n)$ | 支持负边权；同点最大边为 LLONG_MIN |
| 路径 / 子树加法求和 | [路径维护](#hld) | 建树 $\mathcal{O}(n)$，路径 $\mathcal{O}(\log ^{2} n)$，子树 $\mathcal{O}(\log n)$ / $\mathcal{O}(n)$ | 依赖 HLD；支持边权和动态根子树 |
| 批量路径加后一次统计 | [树上差分](#tree-difference) | $\mathcal{O}(n+q \log n)$ / $\mathcal{O}(n)$ | 区分点差分和边差分 |
| 静态路径不同颜色 | [树上莫队](#tree-mo) | 见该节 / $\mathcal{O}(n+q)$ 额外空间 | 依赖 HLD + 双次欧拉序 |
| 多组少量关键点 | [虚树](#virtual-tree) | $\mathcal{O}(k \log k+k \log n)$ / $\mathcal{O}(k)$ 额外空间 | 依赖 HLD，不自动加入原根 |
| 子树众数颜色之和 | [DSU on tree](#dsu-on-tree) | $\mathcal{O}(n \log n)$ / $\mathcal{O}(n)$ | 依赖 HLD；颜色离散化、保留原值求和 |
| 路径距离存在性 / 点对计数 | [点分治](#centroid-decomposition) | 见该节 / $\mathcal{O}(n+m)$ | 非负边权，不把同一个点配给自己 |
| 动态标记点、最近标记点 | [动态点分治](#dynamic-centroid-decomposition) | 预处理 $\mathcal{O}(n \log n)$，修改 $\mathcal{O}(\log ^{2} n)$，查询 $\mathcal{O}(\log n)$ / $\mathcal{O}(n \log n)$ | 非负边权，无标记点返回 -1 |
| 全根距离和、最大连通权和 | [树形 DP](#tree-dp) | $\mathcal{O}(n)$ / $\mathcal{O}(n)$ | 遍历非递归，最大连通块必须非空 |
| 标号树编解码、计数 | [Prüfer](#tree-counting) | 编解码 $\mathcal{O}(n \log n)$ / $\mathcal{O}(n)$ | 每次删除最小编号叶子 |
| 无标号树同构 | [AHU](#tree-isomorphism) | $\mathcal{O}(n \log n)$ / $\mathcal{O}(n)$ 从空字典开始 | 确定性编号；比较时共用字典 |
| 子树类型、换根树哈希 | [treeHash](#tree-hash) | $\mathcal{O}(n)$ / $\mathcal{O}(n)$ | 双 64 位；共用种子，存在碰撞可能 |

本章以**全局变量 + 自由函数**组合使用；公共声明只保留一份，主程序已有同名变量时直接复用。树遍历均使用显式栈或遍历序；线段树保留 $\mathcal{O}(\log n)$ 深度递归。只复制当前题目需要的函数及依赖。

动态森林见 [08 章 LCT](<08 - 数据结构.md#link-cut-tree>)；子树内值域合并、路径第 k 小分别复用 [动态线段树](<08 - 数据结构.md#merge-segtree>)、[主席树](<08 - 数据结构.md#persistent-order-statistics>)。矩阵树定理见 [04 章](<04 - 数学.md#determinant>)。


### 公共全局变量与有根遍历

<a id="tree-base"></a>

邻接表统一为 `e[u] = {{v,w},...}`，表示邻点和边权；无权树用默认 `w=1`。主程序可直接访问、修改 `e,fa,dep,siz,son,top,id,rid,ord,dis,pw`，无需创建树对象或在算法之间复制数组。已有这些全局声明时不要重复粘贴；若原程序使用 `vector<vector<int>> e`，可按无权题需求把遍历的 `[v,w]` 改为 `v`，距离增量改成 1。

`initTree(N)` 只设置 n、清空邻接表，随后 `add(u,v,w)` 建边。`rootTree(root)` 用 $\mathcal{O}(n)$ 时间 / 空间重建有根信息：`fa[root]=dep[root]=pw[root]=dis[root]=0`，`siz[0]=0`；`ord` 是父先于子的顺序，**不保证 DFS 序**。`siz/son` 按点数统计，`pw[u]` 为父边权，`dis[u]` 为根到 u 的边权和；允许负边权。只使用直径、点分治或 Prüfer 时不必调用 rootTree。

```c++
int n;
vector<vector<pair<int, ll>>> e;
vector<int> fa, dep, siz, son, top, id, rid, ord;
vector<ll> dis, pw;
void initTree(int N) {
    n = N;
    e.assign(n + 1, {});
}
void add(int u, int v, ll w = 1) {
    e[u].push_back({v, w});
    e[v].push_back({u, w});
}
void rootTree(int root = 1) {
    fa.assign(n + 1, 0), dep.assign(n + 1, 0), siz.assign(n + 1, 1);
    siz[0] = 0;
    son.assign(n + 1, 0), dis.assign(n + 1, 0), pw.assign(n + 1, 0);
    ord = {root};
    for (int i = 0; i < n; ++i) {
        int u = ord[i];
        for (auto [v, w] : e[u])
            if (v != fa[u]) {
                fa[v] = u;
                dep[v] = dep[u] + 1;
                pw[v] = w;
                dis[v] = dis[u] + w;
                ord.push_back(v);
            }
    }
    for (int i = n - 1; i > 0; --i) {
        int u = ord[i], p = fa[u];
        siz[p] += siz[u];
        if (siz[u] > siz[son[p]]) son[p] = u;
    }
}
```

| 需要的功能 | 建边后的调用顺序 | 新增全局状态 |
| --- | --- | --- |
| HLD / LCA / 差分 / DSU / 虚树 | `rootTree(r); buildHld();` | `top,id,rid` |
| 倍增 LCA / 路径最大边 | `rootTree(r); buildLca();` | `up,mx` |
| 树上莫队 | `rootTree(r); buildHld(); buildTour();` | `tin,tout,euler` |
| 路径 / 子树加与求和 | `rootTree(r); buildHld(); buildPath(a);` | `seg` |
| 树形 DP / 树的度量 / 有根 AHU / 树哈希 | `rootTree(r);` 再调用所需函数 | 各节结果或 DP 数组 |
| 动态点分治 | `buildDcd();` | `anc,bag,active` 及分治临时数组 |

**换根或改边之后，先重新 rootTree，再重建本题使用的 HLD / 倍增 / 欧拉序 / 线段树等数据。** `buildHld/buildLca/buildTour` 只读取公共有根信息，不偷偷重新遍历改根；`buildPath` 清除旧修改。直接修改公共数组时也要保持这些依赖一致。多测时各 build 函数会重置其负责的状态；未调用 build 的旧辅助数组不可使用。点分治的 `cp/csiz/dead` 是当前分割连通块的临时信息，与整棵树的 `fa/siz` 含义不同，不能混用。

LCA 有 HLD 和倍增两版，`lca/jump` 同名，**二选一复制**。后面的路径工具函数共用这两个接口；HLD 的 `path/subtree/ancestor` 不依赖倍增。

### 树的直径

<a id="diameter"></a>

无权树 / 森林，从 root 所在连通块求直径，单点长度 0。两次找最远点，`diameter(root)` 返回 `array<int,3>{st,ed,len}`，依次为两个端点和边数，忽略邻接表中的权值，不修改公共有根信息。设当前连通块 c 个点，每次调用含数组初始化 $\mathcal{O}(n+c)$，空间 $\mathcal{O}(n)$，避免 map 的对数开销和递归长链爆栈。若反复枚举森林所有分量，应自行复用访问时间戳，避免每个分量都清空 n 个元素。

```c++
array<int, 3> diameter(int root = 1) { // {st, ed, len}
    vector<int> d(n + 1, -1), q;
    auto far = [&](int s) {
        fill(d.begin(), d.end(), -1);
        q = {s};
        d[s] = 0;
        int t = s;
        for (int i = 0; i < (int)q.size(); ++i) {
            int u = q[i];
            if (d[u] > d[t]) t = u;
            for (auto [v, w] : e[u])
                if (d[v] < 0) {
                    d[v] = d[u] + 1;
                    q.push_back(v);
                }
        }
        return t;
    };
    int st = far(root), ed = far(st);
    return {st, ed, d[ed]};
}
```

调用：`initTree(3); add(1,2); add(2,3); auto [st,ed,len]=diameter();` 得到 `len=2`；端点为 1、3，顺序不固定。只取长度用 `diameter()[2]`。非负带权用下一节；含负边时两遍最远点法不成立，应改为树形 DP。

### 树的度量：直径、重心与中心


<a id="tree-metrics"></a>

非负边权树，先 `rootTree(root)`；`metrics()` 返回直径 `diam`、端点 `st,ed`、各点离心率 `ecc[u]`（到最远顶点的距离）、顶点中心 `center` 与半径 `radius`、一个重心 `cog` 和删除它后最大连通块大小 `rem`。时间 / 空间 $\mathcal{O}(n)$；结果保存在信息结构体中，不修改 `fa/siz/ord/dis`。

性质：到直径两端距离的最大值就是离心率；重心按点数计算，与边权无关，至多两个且相邻。顶点中心与重心不同；带权或零权时中心不保证只有两个，连续边上中心也不等于本模板的顶点中心。全零权允许 `st==ed`，直径长度仍为 0。

```c++
struct Metrics {
    int st, ed, center, cog, rem;
    ll diam, radius;
    vector<ll> ecc;
};
Metrics metrics() {
    auto scan = [&](int s) {
        vector<ll> d(n + 1);
        vector<pair<int, int>> st{{s, 0}};
        while (!st.empty()) {
            auto [u, p] = st.back();
            st.pop_back();
            for (auto [v, w] : e[u])
                if (v != p) {
                    d[v] = d[u] + w;
                    st.push_back({v, u});
                }
        }
        return d;
    };
    int st = max_element(dis.begin() + 1, dis.end()) - dis.begin();
    auto a = scan(st);
    int ed = max_element(a.begin() + 1, a.end()) - a.begin();
    auto b = scan(ed);
    Metrics t{st, ed, 1, 1, n, a[ed], 0, vector<ll>(n + 1)};
    for (int u = 1; u <= n; ++u) {
        t.ecc[u] = max(a[u], b[u]);
        if (t.ecc[u] < t.ecc[t.center]) t.center = u;
        int mx = n - siz[u];
        for (auto [v, w] : e[u])
            if (fa[v] == u) mx = max(mx, siz[v]);
        if (mx < t.rem) t.rem = mx, t.cog = u;
    }
    t.radius = t.ecc[t.center];
    return t;
}
```

调用：`initTree(3); add(1,2,2); add(2,3,5); rootTree(); auto t=metrics();` 得 `t.diam=7, t.center=2, t.radius=5, t.cog=2, t.rem=1`。

### 最近公共祖先 LCA

<a id="lca"></a>

#### 树链剖分解法

只需 LCA / 树上跳点时优先此版：建树 $\mathcal{O}(n)$，空间 $\mathcal{O}(n)$，LCA、jump、kth、rootLca 均 $\mathcal{O}(\log n)$，ancestor $\mathcal{O}(1)$。按子树大小选择重儿子，每跨一条轻边子树至少减半。`rootTree(root); buildHld();` 可换根重建。

`fa[root]=0, dep[root]=0`；`id[u]` 为 1-based 重链优先 DFS 序，子树为 `[id[u],id[u]+siz[u]-1]`；`rid` 为反向点号，`ord` 为父先于子的遍历序。`jump(u,k)` 向上 k 条边；`kth(u,v,k)` 沿 u→v 走 k 条边，二者 k 非法均返回 0。后面的共用路径工具提供 `clac/kth/rootLca/dist`；`clac` 沿用旧拼写，返回路径边数。rootLca 查询以 r 为根的 LCA，不重建。

```c++
void buildHld() {
    top.assign(n + 1, 0), id.assign(n + 1, 0), rid.assign(n + 1, 0);
    int root = ord[0], idx = 0;
    vector<pair<int, int>> st{{root, root}};
    while (!st.empty()) {
        auto [u, head] = st.back();
        st.pop_back();
        for (; u; u = son[u]) {
            id[u] = ++idx;
            rid[idx] = u;
            top[u] = head;
            for (auto [v, w] : e[u])
                if (v != fa[u] && v != son[u]) st.push_back({v, v});
        }
    }
}
int lca(int u, int v) {
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        u = fa[top[u]];
    }
    return dep[u] < dep[v] ? u : v;
}
bool ancestor(int u, int v) {
    return id[u] <= id[v] && id[v] < id[u] + siz[u];
}
int jump(int u, int k) {
    if (k < 0 || k > dep[u]) return 0;
    while (k > dep[u] - dep[top[u]]) {
        k -= dep[u] - dep[top[u]] + 1;
        u = fa[top[u]];
    }
    return rid[id[u] - k];
}
template <class F> void path(int u, int v, F f, bool edge = false) {
    // 将路径拆成闭区间；edge=true 时跳过 LCA，适合“边权存儿子”。
    while (top[u] != top[v]) {
        if (dep[top[u]] < dep[top[v]]) swap(u, v);
        f(id[top[u]], id[u]);
        u = fa[top[u]];
    }
    if (dep[u] > dep[v]) swap(u, v);
    if (id[u] + edge <= id[v]) f(id[u] + edge, id[v]);
}
template <class F> void subtree(int u, int r, F f) {
    // 以 r 为根时 u 的点集合，至多两个闭区间，不改原剖分。
    if (u == r) f(1, n);
    else if (!ancestor(u, r)) f(id[u], id[u] + siz[u] - 1);
    else {
        int v = jump(r, dep[r] - dep[u] - 1);
        if (id[v] > 1) f(1, id[v] - 1);
        if (id[v] + siz[v] <= n) f(id[v] + siz[v], n);
    }
}
```

调用：`initTree(3); add(1,2); add(2,3); rootTree(); buildHld();` 后 `lca(2,3)==2`；连同共用路径工具，`kth(3,1,1)==2`、`rootLca(1,2,3)==2`。path 的区间顺序不保证沿 u→v，适用于和、最值等与顺序无关的聚合；矩阵乘法、字符串拼接需分别维护正反向并按路径方向合并。

#### 树上倍增解法

<a id="binary-lifting"></a>

依赖 `rootTree`，随后调用 `buildLca()`；与 HLD 的 `lca/jump` 二选一。`add(u,v)` 默认边权 1。建树时间 / 空间 $\mathcal{O}(n \log n)$，查询 $\mathcal{O}(\log n)$；按 n 决定层数，不使用固定 30 层。`dist` 为边权和，`dep[u]+dep[v]-2*dep[lca(u,v)]` 才是边数。支持负边权，因为树上简单路径唯一，不是在一般图上求最短路。

`maxEdge(u,v)` 返回最大边权，空路径 `u==v` 约定为 LLONG_MIN（max 的单位元），不能据此判断查询失败。根的父亲为 0，jump/kth 的 k 越界返回 0。倍增可扩展维护路径最小边、异或等，需换正确单位元；含方向的聚合需分开维护正反顺序。

```c++
int lg;
vector<vector<int>> up;
vector<vector<ll>> mx;
void buildLca() {
    lg = 1;
    while ((1LL << lg) <= n) ++lg;
    up.assign(lg, vector<int>(n + 1));
    mx.assign(lg, vector<ll>(n + 1, LLONG_MIN));
    up[0] = fa;
    for (int u : ord) if (fa[u]) mx[0][u] = pw[u];
    for (int j = 1; j < lg; ++j)
        for (int u = 1; u <= n; ++u) {
            up[j][u] = up[j - 1][up[j - 1][u]];
            mx[j][u] = max(mx[j - 1][u], mx[j - 1][up[j - 1][u]]);
        }
}
int jump(int u, int k) {
    if (k < 0 || k > dep[u]) return 0;
    for (int j = 0; j < lg; ++j)
        if ((k >> j) & 1) u = up[j][u];
    return u;
}
int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    u = jump(u, dep[u] - dep[v]);
    if (u == v) return u;
    for (int j = lg - 1; j >= 0; --j)
        if (up[j][u] != up[j][v]) u = up[j][u], v = up[j][v];
    return up[0][u];
}
ll maxEdge(int u, int v) {
    ll ans = LLONG_MIN;
    if (dep[u] < dep[v]) swap(u, v);
    int d = dep[u] - dep[v];
    for (int j = lg - 1; j >= 0; --j)
        if ((d >> j) & 1) {
            ans = max(ans, mx[j][u]);
            u = up[j][u];
        }
    if (u == v) return ans;
    for (int j = lg - 1; j >= 0; --j)
        if (up[j][u] != up[j][v]) {
            ans = max(ans, max(mx[j][u], mx[j][v]));
            u = up[j][u];
            v = up[j][v];
        }
    return max(ans, max(mx[0][u], mx[0][v]));
}
```

调用：`initTree(3); add(1,2,-4); add(2,3,-2); rootTree(); buildLca();`；连同下面的工具，`dist(1,3)==-6`、`maxEdge(1,3)==-2`、`kth(3,1,2)==1`。只需 LCA 时可删去 mx 及其维护、maxEdge，减少空间。

#### 共用路径工具

依赖已建好的 HLD 或倍增版 `lca/jump`，时间均为 $\mathcal{O}(\log n)$、额外空间 $\mathcal{O}(1)$。`clac` 返回边数，`dist` 返回边权和；`kth` 的 k 从 0 开始，越界返回 0；`rootLca` 查询临时以 r 为根时的 LCA，不修改任何预处理。两版只复制一份这些函数。

```c++
int clac(int u, int v) {
    return dep[u] + dep[v] - 2 * dep[lca(u, v)];
}
ll dist(int u, int v) {
    int w = lca(u, v);
    return (dis[u] - dis[w]) + (dis[v] - dis[w]);
}
int kth(int u, int v, int k) {
    int w = lca(u, v), a = dep[u] - dep[w], b = dep[v] - dep[w];
    if (k < 0 || k > a + b) return 0;
    return k <= a ? jump(u, k) : jump(v, a + b - k);
}
int rootLca(int u, int v, int r) {
    int a = lca(u, v), b = lca(u, r), c = lca(v, r);
    if (dep[b] > dep[a]) a = b;
    return dep[c] > dep[a] ? c : a;
}
```

### 轻重链剖分/树链剖分

<a id="hld"></a>

依赖已 `buildHld()` 的公共数组，直接调用 `path/subtree` 拆区间，配一份区间加 / 和线段树；`SegInfo` 只保存节点信息。建树 $\mathcal{O}(n)$、空间 $\mathcal{O}(n)$，路径修改 / 查询 $\mathcal{O}(\log ^{2} n)$，普通或动态根子树操作 $\mathcal{O}(\log n)$。递归只在线段树中，深度 $\mathcal{O}(\log n)$。不取模；需要模运算时替换 apply / pull / query 的运算。

点权 `a` 为 n+1 项，`buildPath(a)` 重建并清除全部旧修改；`buildPath()` 用全零点权重建，二者均不重复剖分。`addPath(u,v,x)` / `sumPath(u,v)` 操作路径；`addSub(u,x)` / `sumSub(u)` 操作预处理根下的子树；`addSub(u,r,x)` / `sumSub(u,r)` 操作临时以 r 为根的子树，r 可每次不同。

```c++
struct SegInfo {
    ll sum = 0, tag = 0;
};
vector<SegInfo> seg;
void pull(int p) {
    seg[p].sum = seg[p * 2].sum + seg[p * 2 + 1].sum;
}
void apply(int p, int len, ll x) {
    seg[p].sum += x * len;
    seg[p].tag += x;
}
void push(int p, int l, int r) {
    if (!seg[p].tag) return;
    int m = (l + r) / 2;
    apply(p * 2, m - l + 1, seg[p].tag);
    apply(p * 2 + 1, r - m, seg[p].tag);
    seg[p].tag = 0;
}
void segBuild(int p, int l, int r, const vector<ll> &a) {
    if (l == r) {
        seg[p].sum = a[l];
        return;
    }
    int m = (l + r) / 2;
    segBuild(p * 2, l, m, a);
    segBuild(p * 2 + 1, m + 1, r, a);
    pull(p);
}
void segAdd(int p, int l, int r, int L, int R, ll x) {
    if (L <= l && r <= R) {
        apply(p, r - l + 1, x);
        return;
    }
    push(p, l, r);
    int m = (l + r) / 2;
    if (L <= m) segAdd(p * 2, l, m, L, R, x);
    if (R > m) segAdd(p * 2 + 1, m + 1, r, L, R, x);
    pull(p);
}
ll segQuery(int p, int l, int r, int L, int R) {
    if (L <= l && r <= R) return seg[p].sum;
    push(p, l, r);
    int m = (l + r) / 2;
    ll ans = 0;
    if (L <= m) ans += segQuery(p * 2, l, m, L, R);
    if (R > m) ans += segQuery(p * 2 + 1, m + 1, r, L, R);
    return ans;
}
void addRange(int l, int r, ll x) {
    if (l <= r) segAdd(1, 1, n, l, r, x);
}
ll sumRange(int l, int r) {
    return l <= r ? segQuery(1, 1, n, l, r) : 0;
}

template <class T> void buildPath(const vector<T> &a) {
    vector<ll> b(n + 1);
    for (int u = 1; u <= n; ++u)
        b[id[u]] = a[u];
    seg.assign(4 * n + 4, {});
    segBuild(1, 1, n, b);
}
void buildPath() {
    buildPath(vector<ll>(n + 1));
}
void addPath(int u, int v, ll x, bool edge = false) {
    path(u, v, [&](int l, int r) {
        addRange(l, r, x);
    }, edge);
}
ll sumPath(int u, int v, bool edge = false) {
    ll ans = 0;
    path(u, v, [&](int l, int r) {
        ans += sumRange(l, r);
    }, edge);
    return ans;
}
void addSub(int u, ll x) {
    addRange(id[u], id[u] + siz[u] - 1, x);
}
ll sumSub(int u) {
    return sumRange(id[u], id[u] + siz[u] - 1);
}
void addSub(int u, int r, ll x) {
    subtree(u, r, [&](int l, int rr) {
        addRange(l, rr, x);
    });
}
ll sumSub(int u, int r) {
    ll ans = 0;
    subtree(u, r, [&](int l, int rr) {
        ans += sumRange(l, rr);
    });
    return ans;
}
```

边权用法：以固定预处理根确定每条边较深的端点，将边权存该点，根存 0；`addPath(u,v,x,true)` / `sumPath(u,v,true)` 跳过 LCA，同点路径得到空集。固定根子树的内部边区间为 `[id[u]+1,id[u]+siz[u]-1]`。动态根子树接口按点集合定义，不能直接用于内部边集合。

最小示例：

```c++
void solve() {
    initTree(3);
    add(1, 2);
    add(2, 3);
    rootTree();
    buildHld();
    buildPath(vector<ll>{0, 1, 2, 3});
    addPath(1, 3, 2);              // 点权变为 3,4,5
    cout << sumPath(1, 3) << endl; // 12
    cout << sumSub(2, 3) << endl;  // 以 3 为根，2 的子树是 {1,2}，和为 7
    // fa、dep、siz、id 等仍可在这里直接读写，修改后须维护派生数据的一致性。
}
```

### 树上路径交

<a id="path-intersection"></a>

下段为自由函数，依赖任一 LCA 及共用路径工具。返回两条路径的公共点数，空交为 0；时间 $\mathcal{O}(\log n)$，额外空间 $\mathcal{O}(1)$。依赖 `lca,dep,clac`，clac 必须按边数计，不能换成带权距离。若交非空，其本身是一条路径。

```c++
int intersect(int x, int y, int X, int Y) {
    vector<int> t = {lca(x, X), lca(x, Y), lca(y, X), lca(y, Y)};
    sort(t.begin(), t.end(), [&](int a, int b) {return dep[a] < dep[b];});
    int r = lca(x, y), R = lca(X, Y);
    if (dep[t[0]] < min(dep[r], dep[R]) || dep[t[2]] < max(dep[r], dep[R])) return 0;
    return 1 + clac(t[2], t[3]);
}
```

例如链 1-2-3-4，`intersect(1,3,2,4)==2`。路径判点：`clac(u,x)+clac(x,v)==clac(u,v)`；此条件同样用边数，对含零 / 负边权不能直接改用加权距离。

### 树上差分：点差分与边差分

<a id="tree-difference"></a>

依赖公共 `fa/ord` 和已预处理的任一 `lca`。离线对 q 条路径各加一个权值，最后一次求出所有点 / 边的累加值；不是在线查询模板。时间 $\mathcal{O}(n+q \log n)$，空间 $\mathcal{O}(n)$，可加负数。`ops` 每项 `{u,v,x}`，返回数组 1..n；边模式中 `ans[u]` 表示边 `(fa[u],u)`，根位置为 0。

点差分：端点各加 x，LCA 减 x，LCA 的父亲再减 x；边差分：端点各加 x，LCA 减 2x。逆序向父亲累加。以下连续减两次避免单独计算 2x，但所有中间值仍须不溢出。

```c++
vector<ll> treeDiff(const vector<tuple<int, int, ll>> &ops, bool edge = false) {
    vector<ll> d(n + 1);
    for (auto [u, v, x] : ops) {
        int w = lca(u, v);
        d[u] += x;
        d[v] += x;
        d[w] -= x;
        if (edge) d[w] -= x;
        else d[fa[w]] -= x;
    }
    for (int i = n - 1; i > 0; --i) {
        int u = ord[i];
        d[fa[u]] += d[u];
    }
    d[0] = 0;
    return d;
}
```

链 1-2-3，`treeDiff({{1,3,2},{2,2,5}})` 得点权 `{2,7,2}`；加 `true` 得边权根位置 0、边 1-2 为 2、边 2-3 为 2。

### 树上离线查询公共预处理：双次欧拉序


<a id="tree-tour"></a>

树上莫队需要双次欧拉序，先 `rootTree(root)`，再调用 `buildTour()`；LCA 复用 HLD，虚树直接用 HLD 的 id，不需要这段。`tin/tout` 是每点进入、退出时在 euler 中的 0-based 下标，euler 长度为 2n；n 和 2n 均须能存入 int。

本函数只补充欧拉序，不重建父亲、深度或 LCA。时间 / 空间 $\mathcal{O}(n)$，显式栈避免长链爆栈，可重复调用。tin/tout 与 HLD 的 id 含义不同，不可混用。

```c++
vector<int> tin, tout, euler;
void buildTour() {
    tin.assign(n + 1, 0);
    tout.assign(n + 1, 0);
    euler.clear();
    euler.reserve(2 * n);
    vector<int> st{ord[0]};
    while (!st.empty()) {
        int u = st.back();
        st.pop_back();
        if (u < 0) {
            u = -u;
            tout[u] = euler.size();
            euler.push_back(u);
            continue;
        }
        tin[u] = euler.size();
        euler.push_back(u);
        st.push_back(-u);
        for (auto [v, w] : e[u])
            if (v != fa[u]) st.push_back(v);
    }
}
```

### 树上莫队：路径不同颜色数量

<a id="tree-mo"></a>

依赖 `buildHld()` 和 `buildTour()`；color 为 1-based ll 颜色数组，内部离散化。queries 中每项是两个合法点编号，返回相同顺序的路径不同颜色数量。静态点颜色，不支持修改、不统计边颜色。空询问返回空，可重复调用同一个树预处理。

将 tin[u]≤tin[v]：若 LCA=u，取 [tin[u],tin[v]]；否则取 [tout[u],tin[v]]，另临时加入 LCA。对欧拉序位置增删均切换该点的选中状态；出现两次的点抵消。单次切换 $\mathcal{O}(1)$，块长 B 时移动量 $\mathcal{O}(n^{2}/B+qB)$，另有颜色压缩 $\mathcal{O}(n \log n)$、查询排序 $\mathcal{O}(q \log q)$ 及 q 次 LCA；空间 $\mathcal{O}(n+q)$，不含公共预处理。

```c++
// pathColors：树上莫队，统计路径不同颜色数
vector<int> pathColors(const vector<ll> &color,
                       const vector<pair<int, int>> &queries) {
    int q = (int)(queries.size());
    if (!q) return {};
    vector<ll> val(color.begin() + 1, color.end());
    sort(val.begin(), val.end());
    val.erase(unique(val.begin(), val.end()), val.end());
    vector<int> c(n + 1);
    for (int u = 1; u <= n; ++u)
        c[u] = (int)(lower_bound(val.begin(), val.end(), color[u]) - val.begin());
    vector<array<int, 4>> a; // {左端点, 右端点, 额外 LCA（0 表示无）, 询问编号}
    for (int i = 0; i < q; ++i) {
        auto [u, v] = queries[i];
        if (tin[u] > tin[v]) swap(u, v);
        int w = lca(u, v);
        if (w == u) a.push_back({tin[u], tin[v], 0, i});
        else a.push_back({tout[u], tin[v], w, i});
    }
    int B = max<int>(1, (int)(2.0 * n / sqrt(q)));
    sort(a.begin(), a.end(), [&](const auto &x, const auto &y) {
        int bx = x[0] / B, by = y[0] / B;
        if (bx != by) return bx < by;
        return (bx & 1) ? x[1] > y[1] : x[1] < y[1];
    });
    vector<int> cnt(val.size()), active(n + 1), ans(q);
    int col = 0;
    auto toggle = [&](int u) {
        if (active[u]) {
            if (--cnt[c[u]] == 0) --col;
        } else {
            if (cnt[c[u]]++ == 0) ++col;
        }
        active[u] ^= 1;
    };
    int l = 0, r = -1;
    for (auto [L, R, w, i] : a) {
        while (l > L) toggle(euler[--l]);
        while (r < R) toggle(euler[++r]);
        while (l < L) toggle(euler[l++]);
        while (r > R) toggle(euler[r--]);
        if (w) toggle(w);
        ans[i] = col;
        if (w) toggle(w);
    }
    return ans;
}
```

### 虚树：关键点及相邻 LCA 建树

<a id="virtual-tree"></a>

依赖已 buildHld 的 `id/dep/ancestor/lca`，无需双次欧拉序。输入本次关键点，允许重复和空集合；返回关键点与必要 LCA 组成的最小虚树，不强制包含原树根。如需原树根到所有关键点的子树，请把原树根也加入 keys。

结果使用局部 0-based 编号：nodes[i] 是原树点号；fa[i] 是虚树父亲的局部编号，根为 -1；len[i] 是对应原树路径的边数，根为 0；marked[i] 表示是否是输入关键点。nodes 按 id 排序，父亲总在孩子之前，可逆序做 DP。它只压缩树形与路径长度；路径最小边权等信息需要额外的倍增/路径查询，不能用 len 代替。

输入 k 个点，去重后 k' 个关键点，结果至多 2k'-1 个点（k'=0 时为空）。时间 $\mathcal{O}(k \log (k+1)+k \log (n+1))$，结果及辅助空间 $\mathcal{O}(k)$，无 $\mathcal{O}(n)$ 清空；各次结果互相独立。

```c++
// virtualTree：按关键点及 LCA 构建虚树
struct VirtualTree {
    vector<int> nodes, fa, len;
    vector<bool> marked;
};
VirtualTree virtualTree(vector<int> keys) {
    auto cmp = [&](int u, int v) {
        return id[u] < id[v];
    };
    sort(keys.begin(), keys.end(), cmp);
    keys.erase(unique(keys.begin(), keys.end()), keys.end());
    VirtualTree ans;
    if (keys.empty()) return ans;
    ans.nodes = keys;
    for (int i = 1; i < (int)(keys.size()); ++i)
        ans.nodes.push_back(lca(keys[i - 1], keys[i]));
    sort(ans.nodes.begin(), ans.nodes.end(), cmp);
    ans.nodes.erase(unique(ans.nodes.begin(), ans.nodes.end()), ans.nodes.end());
    int m = (int)(ans.nodes.size());
    ans.fa.assign(m, -1);
    ans.len.assign(m, 0);
    ans.marked.resize(m);
    vector<int> st;
    for (int i = 0; i < m; ++i) {
        int u = ans.nodes[i];
        ans.marked[i] = binary_search(keys.begin(), keys.end(), u, cmp);
        while (!st.empty() && !ancestor(ans.nodes[st.back()], u))
            st.pop_back();
        if (!st.empty()) {
            int p = st.back();
            ans.fa[i] = p;
            ans.len[i] = dep[u] - dep[ans.nodes[p]];
        }
        st.push_back(i);
    }
    return ans;
}
```

调用：原树边为 1-2、1-3、3-4，`virtualTree({2,4,4})` 含原点 {1,2,4}，边长度为 1 和 2；具体局部顺序按 id。`accumulate(v.len.begin(),v.len.end(),0LL)` 是连通所有关键点所需的最小子树边数。只有一个关键点时结果仅该点，边数 0。

### 树上启发式合并 (DSU on tree)

<a id="dsu-on-tree"></a>

依赖已 buildHld 的公共数组，统计每棵子树中出现次数最多的所有颜色的原值之和（CF 600E 模型）。颜色为 n+1 项 ll，可为负数、大数；内部离散化，sum 累加的是原颜色，不是离散化编号。返回 `ans[u]`。时间 $\mathcal{O}(n \log n)$，空间 $\mathcal{O}(n)$，不含 HLD；可重复调用。

流程：先算轻子树并清空，再保留重子树的计数，最后加入轻子树和当前点。每个点只在它祖先的轻边处被重复加入，至多 $\mathcal{O}(\log n)$ 次。显式任务栈代替深递归；清空时只减计数，随后整体重置 mx / sum，不需要逐次维护“删除后的众数”。

```c++
vector<ll> subtreeMode(const vector<ll> &color) {
    vector<ll> val(color.begin() + 1, color.end());
    sort(val.begin(), val.end());
    val.erase(unique(val.begin(), val.end()), val.end());
    vector<int> c(n + 1), cnt(val.size());
    for (int u = 1; u <= n; ++u)
        c[u] = lower_bound(val.begin(), val.end(), color[u]) - val.begin();
    vector<ll> ans(n + 1);
    ll sum = 0;
    int mx = 0;
    auto add = [&](int u) {
        int x = c[u], k = ++cnt[x];
        if (k > mx) mx = k, sum = val[x];
        else if (k == mx) sum += val[x];
    };
    vector<array<int, 3>> st{{ord[0], 1, 0}}; // {点, 是否保留计数, 阶段}
    while (!st.empty()) {
        auto [u, keep, phase] = st.back();
        st.pop_back();
        if (!phase) {
            st.push_back({u, keep, 1});
            if (son[u]) st.push_back({son[u], 1, 0});
            for (auto [v, w] : e[u])
                if (v != fa[u] && v != son[u]) st.push_back({v, 0, 0});
        } else {
            for (auto [v, w] : e[u])
                if (v != fa[u] && v != son[u])
                    for (int i = id[v]; i < id[v] + siz[v]; ++i)
                        add(rid[i]);
            add(u);
            ans[u] = sum;
            if (!keep) {
                for (int i = id[u]; i < id[u] + siz[u]; ++i)
                    --cnt[c[rid[i]]];
                mx = 0;
                sum = 0;
            }
        }
    }
    return ans;
}
```

例：边 1-2、1-3，颜色 `{0,7,9,9}`，`subtreeMode(color)` 得 `ans[1]=9, ans[2]=9, ans[3]=9`。改成不同颜色数、频次恰为 k 的颜色数时，替换 add 和清空逻辑即可；本版不支持在线改色。

### 点分治 / 树的重心

<a id="centroid-decomposition"></a>

适用非负边权树。每次移除当前连通块的重心，剩余块大小至多减半；总层数 $\mathcal{O}(\log n)$。对子树距离先查询再合入，可以避免把同一子树内的路径误当作经过重心的路径。所有遍历包括分治调度均非递归；每次公开查询会重置删除标记，可重复调用。

提供两种常用统计，均只统计**不同顶点组成的无序点对**：

- `exists(q)`：q 为 0-based 距离列表，返回同顺序 0/1；用 set 保证最坏复杂度 $\mathcal{O}((m+1)n \log ^{2}(n+1))$，空间 $\mathcal{O}(n+m)$。适合询问数较少；m 很大时不能当作 $\mathcal{O}(n \log n)$ 使用。
- `pairsLE(k)`：返回距离 ≤k 的点对数；每层收集距离后排序，减去同一子树内部点对。时间 $\mathcal{O}(n \log ^{2}(n+1))$，空间 $\mathcal{O}(n)$。距离恰好 K（K≥0）可用 `pairsLE(K)-pairsLE(K-1)`；两次调用不共享中间结果。

负查询直接无解；零权树可以有不同点距离为 0。距离和与点对数须存入 ll。无需离散化距离，避免按最大距离开数组。

```c++
vector<int> dead, cp, csiz; // 分割连通块专用，不改 fa/siz/ord
int centroid(int root) {
    vector<int> seq{root};
    cp[root] = 0;
    for (int i = 0; i < (int)(seq.size()); ++i) {
        int u = seq[i];
        for (auto [v, w] : e[u])
            if (!dead[v] && v != cp[u]) cp[v] = u, seq.push_back(v);
    }
    int total = seq.size(), best = total, c = root;
    for (int i = total - 1; i >= 0; --i) {
        int u = seq[i], mx = 0;
        csiz[u] = 1;
        for (auto [v, w] : e[u])
            if (!dead[v] && cp[v] == u) {
                csiz[u] += csiz[v];
                mx = max(mx, csiz[v]);
            }
        mx = max(mx, total - csiz[u]);
        if (mx < best) best = mx, c = u;
    }
    return c;
}
template <class F> void runCd(F calc) {
    dead.assign(n + 1, 0);
    cp.assign(n + 1, 0);
    csiz.assign(n + 1, 0);
    vector<int> st{1};
    while (!st.empty()) {
        int u = st.back();
        st.pop_back();
        int c = centroid(u);
        dead[c] = 1;
        calc(c);
        for (auto [v, w] : e[c])
            if (!dead[v]) st.push_back(v);
    }
}
```

统计函数（复制上面的核心后，按需选择）：

```c++
vector<ll> distances(int root, int par, ll d) {
    vector<ll> a;
    vector<tuple<int, int, ll>> st{{root, par, d}};
    while (!st.empty()) {
        auto [u, f, dis] = st.back();
        st.pop_back();
        a.push_back(dis);
        for (auto [v, w] : e[u])
            if (!dead[v] && v != f) st.push_back({v, u, dis + w});
    }
    return a;
}
vector<int> exists(const vector<ll> &q) {
    vector<int> ans(q.size());
    if (q.empty()) return ans;
    runCd([&](int c) {
        set<ll> pre{0};
        for (auto [v, w] : e[c])
            if (!dead[v]) {
                auto a = distances(v, c, w);
                for (ll d : a)
                    for (int i = 0; i < (int)(q.size()); ++i)
                        if (!ans[i] && q[i] >= d && pre.count(q[i] - d)) ans[i] = 1;
                pre.insert(a.begin(), a.end());
            }
    });
    return ans;
}
ll pairsLE(ll k) {
    if (k < 0) return 0;
    auto count = [&](vector<ll> &a) {
        sort(a.begin(), a.end());
        ll res = 0;
        int l = 0, r = (int)(a.size()) - 1;
        while (l < r)
            if (a[l] <= k - a[r]) res += r - l, ++l; // 非负距离，避免 a[l]+a[r] 溢出
            else --r;
        return res;
    };
    ll ans = 0;
    runCd([&](int c) {
        vector<ll> all{0};
        for (auto [v, w] : e[c])
            if (!dead[v]) {
                auto a = distances(v, c, w);
                ans -= count(a);
                all.insert(all.end(), a.begin(), a.end());
            }
        ans += count(all);
    });
    return ans;
}
```

调用：`initTree(3); add(1,2,0); add(2,3,2);` 后 `exists({0,1,2})` 为 `{1,0,1}`，`pairsLE(2)==3`。在操作间保留点集状态时，使用下一节的动态点分治。

### 动态点分治：最近标记点

<a id="dynamic-centroid-decomposition"></a>

用途：非负边权树上动态激活 / 取消节点，查询与点 `u` 距离最近的激活点。`buildDcd()` 复用上一节的 `runCd/centroid` 核心，将原树建成点分树，`anc[u]` 保存 `{c,dist(u,c)}`，其中 `c` 为 `u` 的各级重心祖先；`bag[c]` 保存所有激活点到 `c` 的距离。

先加边再调用一次 `buildDcd()`；它会清空原有激活状态。`setActive(u,on)` 设置状态，重复设置不会重复插入；`toggle(u)` 翻转状态；`nearest(u)` 返回最短距离，没有激活点时返回 -1。因边权非负，候选值 `dist(u,c)+*bag[c].begin()` 不会小于真实最短路；对任意激活点 `v`，`u,v` 在点分树上的首个公共重心位于原树路径上，对应候选值恰为 `dist(u,v)`。

预处理时间 $\mathcal{O}(n \log n)$、空间 $\mathcal{O}(n \log n)$；点分树高 $\mathcal{O}(\log n)$，`multiset` 单次插入 / 删除 $\mathcal{O}(\log n)$，因此状态修改 $\mathcal{O}(\log ^{2} n)$，查询 $\mathcal{O}(\log n)$。距离须可存入 `ll`；查询候选和用 `i128` 比较，避免中间加法溢出。所有遍历与分治调度均非递归。

```c++
vector<vector<pair<int, ll>>> anc; // anc[u]: {重心祖先, 到该重心的距离}
vector<multiset<ll>> bag;
vector<char> active;
void buildDcd() {
    anc.assign(n + 1, {});
    bag.assign(n + 1, {});
    active.assign(n + 1, 0);
    runCd([&](int c) { // c 已标记 dead，但仍从 c 出发扫描本分量
        vector<tuple<int, int, ll>> st{{c, 0, 0}};
        while (!st.empty()) {
            auto [u, p, d] = st.back();
            st.pop_back();
            anc[u].push_back({c, d});
            for (auto [v, w] : e[u])
                if (!dead[v] && v != p)
                    st.push_back({v, u, d + w});
        }
    });
}
void setActive(int u, bool on) {
    if (active[u] == on) return;
    active[u] = on;
    for (auto [c, d] : anc[u])
        if (on) bag[c].insert(d);
        else bag[c].erase(bag[c].find(d));
}
void toggle(int u) {
    setActive(u, !active[u]);
}
ll nearest(int u) {
    bool found = false;
    i128 ans = 0;
    for (auto [c, d] : anc[u])
        if (!bag[c].empty()) {
            i128 cur = (i128)d + *bag[c].begin();
            if (!found || cur < ans) found = true, ans = cur;
        }
    return found ? (ll)ans : -1;
}
```

调用：`initTree(3); add(1,2,2); add(2,3,1); buildDcd(); setActive(1,true);`，则 `nearest(3)==3`；再执行 `toggle(1)` 后 `nearest(3)==-1`。静态距离统计只改 dead/cp/csiz，不破坏 anc/bag/active，可与动态标记查询组合。

若只激活不取消，可将 `bag[c]` 精简为一个最小值，修改降为 $\mathcal{O}(\log n)$。若要查“距离不超过 k 的激活点数 / 点权和”，需对每级重心按距离维护排序数组与 Fenwick，并减去 `u` 所在的同一分支；不能直接用本段的最小值容器求和。

### 树形 DP 与贡献统计

<a id="tree-dp"></a>

#### 共用有根遍历与换根 DP

直接复用 `rootTree(root)` 得到的 `fa/pw/siz/dis/ord`；若已经做过 HLD 等预处理，不再重复建树。下列函数按需复制，每个功能时间 $\mathcal{O}(n)$；distSum/maxConn/independent 额外空间 $\mathcal{O}(n)$，pairSum/matchMax 额外空间 $\mathcal{O}(1)$。输入点权 / 点质量数组 n+1 项，功能调用不修改公共有根信息或原权值。

$\operatorname{distSum}(a)[u]=\sum_v a[v]\cdot\operatorname{dist}(u,v)$，a 是点质量；a 全 1 即所有点到 u 的距离和，允许有符号点质量及边权。先求子树质量 sub，换根经过边 u-v 时：`ans[v]=ans[u]+pw[v]*(total-2*sub[v])`。无序点对距离和为 $\sum_v \mathrm{pw}[v]\cdot\mathrm{siz}[v]\cdot(n-\mathrm{siz}[v])$；若每点有质量，则换成 `sub[v]*(total-sub[v])`。

`maxConn(a)` 返回非空连通块内点权与内部边权之和的最大值，允许负数；`independent(a)` 返回最大权独立集，允许空集，不能同时选相邻点。两者都不适用于一般有环图。

```c++
vector<ll> distSum(const vector<ll> &a) {
    auto sub = a;
    vector<ll> ans(n + 1);
    int r = ord[0];
    for (int u = 1; u <= n; ++u)
        ans[r] += a[u] * dis[u];
    for (int i = n - 1; i > 0; --i)
        sub[fa[ord[i]]] += sub[ord[i]];
    for (int i = 1; i < n; ++i) {
        int u = ord[i];
        ans[u] = ans[fa[u]] + pw[u] * (sub[r] - 2 * sub[u]);
    }
    return ans;
}
ll maxConn(const vector<ll> &a) {
    auto f = a;
    ll ans = LLONG_MIN;
    for (int i = n - 1; i >= 0; --i) {
        int u = ord[i];
        ans = max(ans, f[u]);
        if (fa[u]) f[fa[u]] += max(0LL, f[u] + pw[u]);
    }
    return ans;
}
ll independent(const vector<ll> &a) {
    vector<ll> f(n + 1);
    auto g = a; // f 不选当前点，g 选当前点
    for (int i = n - 1; i > 0; --i) {
        int u = ord[i];
        f[fa[u]] += max(f[u], g[u]);
        g[fa[u]] += f[u];
    }
    int r = ord[0];
    return max(f[r], g[r]);
}
ll pairSum() {
    ll ans = 0;
    for (int i = 1; i < n; ++i) {
        int u = ord[i];
        ans += pw[u] * siz[u] * (n - siz[u]);
    }
    return ans;
}
ll matchMax() { // n 为偶数、边权非负；所有点恰好配一次
    ll ans = 0;
    for (int i = 1; i < n; ++i) {
        int u = ord[i];
        ans += pw[u] * min(siz[u], n - siz[u]);
    }
    return ans;
}
```

调用：链 1-2-3，边权均为 1，`distSum({0,1,1,1})` 的 1..3 项为 `{3,2,3}`，`pairSum()==4`；点权 `{0,-5,4,3}` 时 `maxConn(a)==8`（点 2、3 及中间边），`independent(a)==4`（只选点 2）。

#### 点对距离和最大化

给定 **偶数 N** 个点，将所有点配成 N/2 对，使配对距离总和最大；调用上述 `matchMax()`。输入必须非负边权：每条边最多被跨越 `min(sz,N-sz)` 次，存在一种配对同时达到所有边的上界，因此答案是这些贡献的加权和。构造可将 DFS 先序排列的前 N/2 个点分别与后 N/2 个点配对。链 1-2-3-4（单位权）答案为 4。

复杂度 $\mathcal{O}(n)$，空间复用公共有根信息。原片段中含糊的 n / k 已统一为总点数 n；这里不是要求相邻点组成匹配，也不同于 `pairSum()` 枚举全部无序点对。

#### 点权与边权之和最大的连通块

直接使用 `maxConn(a)`：$f[u]=a[u]+\sum_v\max(0,f[v]+w(u,v))$，答案 $\max_u f[u]$。u 是选中连通块中最浅的点，贡献为负的儿子整体舍弃。全负点权、边权时也必须选一个点；不能把答案初始化为 0。与旧的 map 存边 + 两遍递归相比，邻接表每条边处理常数次，时间和空间均 $\mathcal{O}(n)$。

### 树计数

<a id="tree-counting"></a>

#### Prüfer 序列：凯莱公式

n≥2 的标号树与长度 n-2、元素在 1..n 的 Prüfer 序列一一对应，因此有 $n^{n-2}$ 棵；n=1 单独计 1。每一步删最小编号叶子并记录邻点；点 i 在序列中出现 deg[i]-1 次。

给定度数 d[i]：n≥2、各 d[i]≥1 且 $\sum_i d[i]=2(n-1)$ 时，树数为 $\frac{(n-2)!}{\prod_i(d[i]-1)!}$，否则为 0。模数下的阶乘除法是否可用，需按数论章的组合数前提判断，不能直接对合数取逆元。

#### Prüfer 序列：连通块连成树的计数

一个带标号无向图有 k 个连通块，各大小为 s[i]，总点数 n。添加 k-1 条原点之间的边使图连通的方案数为 $n^{k-2}\prod_i s[i]$；k=1 为 1。连通块内部已有边固定，新增边只能跨块。题例：[CF 156D](https://codeforces.com/contest/156/problem/D)。

#### Prüfer 编码与解码

两函数可分别使用。`pruferEncode()` 读取全局 n/e 并忽略边权，不需要 rootTree；解码输入 n 和长度 max(0,n-2) 的合法序列，返回无向边列表。显式传 n，区分 n=1 与 n=2 的空序列。优先队列维护最小叶子，时间 $\mathcal{O}(n \log n)$，空间 $\mathcal{O}(n)$；相比线性指针版更容易直接套用。

```c++
vector<int> pruferEncode() {
    vector<int> d(n + 1), ans;
    priority_queue<int, vector<int>, greater<int>> q;
    for (int u = 1; u <= n; ++u) {
        d[u] = e[u].size();
        if (d[u] == 1) q.push(u);
    }
    for (int i = 0; i < n - 2; ++i) {
        int u = q.top();
        q.pop();
        d[u] = 0;
        for (auto [v, w] : e[u])
            if (d[v]) {
                ans.push_back(v);
                if (--d[v] == 1) q.push(v);
                break;
            }
    }
    return ans;
}
vector<pair<int, int>> pruferDecode(int n, const vector<int> &a) {
    if (n == 1) return {};
    vector<int> d(n + 1, 1);
    for (int u : a)
        ++d[u];
    priority_queue<int, vector<int>, greater<int>> q;
    for (int u = 1; u <= n; ++u)
        if (d[u] == 1) q.push(u);
    vector<pair<int, int>> e;
    for (int v : a) {
        int u = q.top();
        q.pop();
        e.push_back({u, v});
        if (--d[v] == 1) q.push(v);
    }
    int u = q.top();
    q.pop();
    e.push_back({u, q.top()});
    return e;
}
```

例如 `pruferDecode(4,{4,4})` 得星形边 `{1,4},{2,4},{3,4}`，再编码得到 `{4,4}`。用于随机树生成时均匀独立生成序列，得到的是均匀随机标号树；“每个新点随机接到前面的点”不是同一种分布。

### 树同构：确定性 AHU 编号


<a id="tree-isomorphism"></a>

判断忽略点编号后两棵无向无权树是否同构。把每点的儿子类型排序，用全局 `map<vector<int>,int> iso` 分配编号；相同儿子多重集得到相同编号，无随机哈希碰撞。`typ[u]` 保存类型，避免占用 HLD 的 id。

`rootedIso()` 复用公共 fa/ord，返回当前根的类型，同时写入所有 typ。`unrootedIso()` 先用 siz 找重心，再以该重心调用 rootTree/rootedIso；一个重心返回 `{类型,0}`，两个重心返回排序后的两个半树类型。**此调用会更换公共根，之前的 HLD / 倍增 / 欧拉序需重建**；只需有根比较时调用 rootedIso，不会改根。

比较不同树时先保存签名，再 initTree 建下一棵树；**中途不能清空 iso**，独立字典生成的数字没有可比性。开始新一批互不关联的比较时才 `iso.clear()`；initTree 不清空字典。不支持点标签或边权，若有需把标签加入键。

单棵 n 点、从空字典开始时，时间 $\mathcal{O}(n \log(n+1))$、空间 $\mathcal{O}(n)$。所有儿子列表总长度 $\mathcal{O}(n)$，排序、map 查找总计上述复杂度；累计处理 N 个点时，总时间 $\mathcal{O}(N \log(N+1))$、空间 $\mathcal{O}(N)$。

```c++
map<vector<int>, int> iso;
vector<int> typ;
int typeId(vector<int> a) {
    sort(a.begin(), a.end());
    return iso.emplace(a, (int)iso.size() + 1).first->second;
}
int rootedIso() {
    typ.assign(n + 1, 0);
    for (int i = n - 1; i >= 0; --i) {
        int u = ord[i];
        vector<int> a;
        for (auto [v, w] : e[u])
            if (fa[v] == u) a.push_back(typ[v]);
        typ[u] = typeId(a);
    }
    return typ[ord[0]];
}
pair<int, int> unrootedIso() {
    vector<int> c;
    for (int u = 1; u <= n; ++u) {
        int mx = n - siz[u];
        for (auto [v, w] : e[u])
            if (fa[v] == u) mx = max(mx, siz[v]);
        if (mx <= n / 2) c.push_back(u);
    }
    rootTree(c[0]);
    rootedIso();
    if (c.size() == 1) return {typ[c[0]], 0};
    vector<int> a;
    for (auto [v, w] : e[c[0]])
        if (v != c[1]) a.push_back(typ[v]);
    int x = typeId(a), y = typ[c[1]];
    if (x > y) swap(x, y);
    return {x, y};
}
```

调用：第一棵树建边并 rootTree 后 `auto a=unrootedIso();`，第二棵树重新 initTree、建边并 rootTree 后 `bool same=(a==unrootedIso());`；只改变点号时 same 为 true，4 点链与 4 点星为 false。这里只返回是否同构的签名，不构造点之间的对应关系。

### 树哈希：子树哈希与换根哈希

<a id="tree-hash"></a>

用途：对子树结构分类、统计不同子树、比较有根 / 无根树是否同构。忽略点编号和邻接表顺序，不含点标签、边权。复用公共 fa/ord，先 rootTree，n≥1。

`treeHash()` 同时计算：

- `sub[u]`：以当前公共根为根时，u 及其后代组成的有根子树哈希。
- `all[u]`：把**整棵树**重新以 u 为根后的哈希，不是原子树的哈希。
- `unrootedHash()`：所有 `all[u]` 的字典序最小值，作为无根树签名；该调用重新 treeHash 并覆盖 sub/all，不修改公共根。

每条边处理常数次，时间 $\mathcal{O}(n)$、空间 $\mathcal{O}(n)$，遍历非递归，支持长链。儿子的贡献相加，所以不需要排序。设 $F(T)=1+\sum_{\mathrm{son}}\operatorname{mix}(F(\mathrm{son})+\mathrm{salt})$；换根 u→v 时，从 all[u] 中减去 v 子树贡献，得到 u 侧的哈希，再将其混合后加入 sub[v]。两个 64 位分量使用不同盐值。

所有算术使用 ull，自然模 $2^{64}$；无符号溢出是预期行为，不需要 MOD。双哈希仍可能碰撞，**相等只能作为概率性结构判断**，不能宣称绝对正确或给出未经证明的固定碰撞概率。要求确定性时使用上一节 AHU。此方法不是密码学哈希。

程序开始时调用一次 `initHash()` 初始化盐值；待比较的树须沿用相同盐值，不要在每次 initTree 后重新随机初始化。默认 seed 随运行时钟变化，不能跨运行直接比较；`initHash(42)` 可固定种子复现调试。处理下一棵树之前先复制需要保留的 sub/all 或签名。

```c++
using Hash = pair<ull, ull>;
ull s1, s2;
vector<Hash> sub, all;
ull treeMix(ull x) {
    x += 0x9e3779b97f4a7c15ULL;
    x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
    x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
    return x ^ (x >> 31);
}
void initHash(ull seed = chrono::steady_clock::now().time_since_epoch().count()) {
    s1 = treeMix(seed);
    s2 = treeMix(seed ^ 0xd1b54a32d192ed03ULL);
}
Hash lift(Hash a) {
    return {treeMix(a.first + s1), treeMix(a.second + s2)};
}
void treeHash() {
    sub.assign(n + 1, {1, 1});
    for (int i = n - 1; i > 0; --i) {
        int u = ord[i];
        auto h = lift(sub[u]);
        sub[fa[u]].first += h.first;
        sub[fa[u]].second += h.second;
    }
    all = sub;
    for (int i = 1; i < n; ++i) {
        int u = ord[i];
        auto h = lift(sub[u]);
        Hash up = {all[fa[u]].first - h.first, all[fa[u]].second - h.second};
        h = lift(up);
        all[u].first += h.first;
        all[u].second += h.second;
    }
}
Hash unrootedHash() {
    treeHash();
    return *min_element(all.begin() + 1, all.end());
}
```

调用示例（依赖上段）：

```c++
void solve() {
    initHash(42); // 同一批树只初始化一次
    initTree(3);
    add(1, 2);
    add(1, 3);
    rootTree();
    treeHash();
    cout << (sub[2] == sub[3]) << endl; // 1：两片单点子树相同
    cout << (all[2] == all[3]) << endl; // 1：以两片叶子为根的整树相同
    auto a = unrootedHash();
    initTree(3);
    add(1, 2);
    add(2, 3);
    rootTree();                            // 改编号后，2 为中心
    cout << (a == unrootedHash()) << endl; // 1：无根树相同
}
```

统计某次 treeHash 后的不同有根子树，可用 `set<Hash>(sub.begin()+1,sub.end()).size()`，这一步另需 $\mathcal{O}(n \log n)$ 时间 / $\mathcal{O}(n)$ 空间。带点标签时，应把标签编码到每点初值，换根时保留对应顶点的初值；带边权时，应把边权也混入 lift，不能直接沿用无权签名。

#### 百题共用 BIT

<a id="tree100-bit"></a>

自由函数，数组由使用者分配。`b.assign(n+2,0)`，位置必须 ≥1；支持把 n+1 作为差分终点。单次 O(log n)，空间 O(n)。

```c++
void bitAdd(vector<ll> &b, int p, ll x) {
    for (; p < (int)b.size(); p += p & -p)
        b[p] += x;
}
ll bitSum(const vector<ll> &b, int p) {
    ll s = 0;
    for (; p; p -= p & -p)
        s += b[p];
    return s;
}
```


#### 百题共用有向路径分段

<a id="tree100-direction"></a>

依赖公共全局与 HLD。返回的各段依次覆盖 u→v 的所有点，每点恰一次；段内按 rev 决定方向。时间、临时空间 O(log n)。用于矩阵乘积、最大子段、颜色段等不可随意交换次序的聚合。

```c++
vector<array<int, 3>> directedPath(int u, int v) {
    vector<array<int, 3>> a, b; // {l,r,rev}；rev=1 表示 r→l
    while (top[u] != top[v]) {
        if (dep[top[u]] >= dep[top[v]]) {
            a.push_back({id[top[u]], id[u], 1});
            u = fa[top[u]];
        } else {
            b.push_back({id[top[v]], id[v], 0});
            v = fa[top[v]];
        }
    }
    if (dep[u] >= dep[v]) a.push_back({id[v], id[u], 1});
    else b.push_back({id[u], id[v], 0});
    reverse(b.begin(), b.end());
    a.insert(a.end(), b.begin(), b.end());
    return a;
}
```

##### 树上题 001：多个点是否共处一条简单路径

<a id="tree100-001"></a>

**建议难度：铜牌。题意与用途：** 给定 k 个关键点，判断能否用一条简单路径覆盖全部关键点；用于把多点约束压缩成两个端点。

**思路：** 从任一关键点找最远关键点 a，再从 a 找最远关键点 b。若关键点共线，a、b 必为两端；逐点检查 d(a,x)+d(x,b)=d(a,b)。用边数判定，不能用可能为零的边权距离。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** rootTree(r); buildHld(); 调用 onePath(keys)，空集也返回 true。

**复杂度与边界：** O(k log n) 时间，O(1) 额外空间。

```c++
bool onePath(const vector<int> &a) {
    if (a.empty()) return true;
    int s = a[0], t = s;
    for (int x : a)
        if (clac(s, x) > clac(s, t)) t = x;
    s = t;
    for (int x : a)
        if (clac(s, x) > clac(s, t)) t = x;
    for (int x : a)
        if (clac(s, x) + clac(x, t) != clac(s, t)) return false;
    return true;
}
```

**例：** 星形 1 连 2、3、4：{2,1,3} 可行，{2,3,4} 不可行。

##### 树上题 002：三点最优会合

<a id="tree100-002"></a>

**建议难度：铜牌。题意与用途：** 在非负边权树上找一个顶点，使它到给定三个点的距离和最小；用于三路汇合、三终端 Steiner 树。

**思路：** 三条两两路径唯一公共的中位点是三个两两 LCA 中最深者。每条支路走一次，总距离等于三组两两距离和的一半；零边权时最优点可能不唯一，本题返回中位点。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** rootTree(r); buildHld(); meet3(a,b,c) 返回中位点，距离和另算 dist。

**复杂度与边界：** O(log n) 时间，O(1) 空间。

```c++
int meet3(int a, int b, int c) {
    int x = lca(a, b), y = lca(a, c), z = lca(b, c);
    if (dep[y] > dep[x]) x = y;
    if (dep[z] > dep[x]) x = z;
    return x;
}
```

**例：** 星形 1 连 2、3、4：三片叶子会合于 1，距离和为 3。

##### 树上题 003：两条路径的公共段

<a id="tree100-003"></a>

**建议难度：银牌。题意与用途：** 求两条简单路径的交集端点；可用于判断路径冲突和累计公共路段权值。

**思路：** 交集非空时仍是一条路径，端点出现在四个交叉 LCA 中。以边数判候选是否在两条路径上，再选候选中最远的一对。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** rootTree(r); buildHld(); pathMeet(a,b,c,d) 返回 {端点,端点}，无交返回 {0,0}。

**复杂度与边界：** O(log n) 时间、O(1) 空间；点交的两个端点相同。

```c++
array<int, 2> pathMeet(int a, int b, int c, int d) {
    vector<int> v;
    for (int x : {lca(a, c), lca(a, d), lca(b, c), lca(b, d)})
        if (clac(a, x) + clac(x, b) == clac(a, b) && clac(c, x) + clac(x, d) == clac(c, d)) v.push_back(x);
    if (v.empty()) return {0, 0};
    int s = v[0], t = s;
    for (int x : v)
        for (int y : v)
            if (clac(x, y) > clac(s, t)) s = x, t = y;
    return {s, t};
}
```

**例：** 链 1–2–3–4：路径 1–3 与 2–4 的交为 2–3。

##### 树上题 004：到两点距离相等的顶点数

<a id="tree100-004"></a>

**建议难度：银牌。题意与用途：** 无权树，多次询问到 u、v 等距的顶点数量；用于中点划分与支路计数。

**思路：** 距离为奇数时无解。否则取中点 m，排除通往 u 和 v 的两侧分量。用父子关系把每一侧大小写成 siz[child] 或 n−siz[m]。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** rootTree(r); buildHld(); equalDist(u,v)。

**复杂度与边界：** O(log n) 时间、O(1) 空间；u=v 时全部 n 个点合法。

```c++
int equalDist(int u, int v) {
    if (u == v) return n;
    int d = clac(u, v);
    if (d & 1) return 0;
    int m = kth(u, v, d / 2), a = kth(m, u, 1), b = kth(m, v, 1);
    auto side = [&](int x) {
        return fa[x] == m ? siz[x] : n - siz[m];
    };
    return n - side(a) - side(b);
}
```

**例：** 星形 1 连 2、3、4，询问 2、3 得 2（点 1、4）。

##### 树上题 005：加一条边后恰好走 K 步

<a id="tree100-005"></a>

**建议难度：铜牌。题意与用途：** 无权树临时增加 x–y，判断能否从 a 走到 b 恰好 K 步，允许重复顶点和边；用于奇偶性与单环路径。

**思路：** 只需考虑不用新边、沿两个方向使用新边的三种长度。存在长度≤K 且同奇偶的方案即可：剩下的偶数步可在任意边往返。多次走环不增加新的奇偶可能性。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** n≥2，x≠y，rootTree(r); buildHld(); exactWalk(a,b,x,y,K)。

**复杂度与边界：** 每次 O(log n)，O(1) 空间。允许新边与原边平行。

```c++
bool exactWalk(int a, int b, int x, int y, ll k) {
    for (ll d : {clac(a, b) * 1LL, clac(a, x) + 1LL + clac(y, b), clac(a, y) + 1LL + clac(x, b)})
        if (d <= k && (k - d) % 2 == 0) return true;
    return false;
}
```

**例：** 链 1–2–3 加 1–3：从 1 回 1 可以走 3 步，不能走 1 步。

##### 树上题 006：点到路径的投影

<a id="tree100-006"></a>

**建议难度：银牌。题意与用途：** 非负边权树，给点 x 和路径 u–v，找路径上到 x 最近的一个顶点；用于点到路线距离和设施覆盖。

**思路：** 从 x 首次接入 u–v 的点正是三点中位点。树上任意绕行都增加非负长度，故它为最优投影。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)、[第 002 题](#tree100-002)。

**初始化与接口：** 按第 002 题初始化；project(x,u,v) 返回 {点号,距离}。

**复杂度与边界：** O(log n) 时间、O(1) 空间；零权可有多个最近点。

```c++
pair<int, ll> project(int x, int u, int v) {
    int p = meet3(x, u, v);
    return {p, dist(x, p)};
}
```

**例：** 星形 1 连 2、3、4，4 到路径 2–3 的投影为 1，距离 1。

##### 树上题 007：关键点的最小顶点覆盖半径

<a id="tree100-007"></a>

**建议难度：银牌。题意与用途：** 无权树选一个顶点作中心，最小化它到关键点的最远距离；用于通信半径与集合中心。

**思路：** 两次找最远关键点得到关键点直径，取该路径中点即可。直径长度 D 给出半径下界 ceil(D/2)，中点达到该界。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** keys 非空；rootTree(r); buildHld(); keyCenter(keys) 返回 {中心,半径}。

**复杂度与边界：** O(k log n) 时间、O(1) 空间；偶数边直径中心唯一，奇数边可任选两个中点之一。

```c++
array<int, 2> keyCenter(const vector<int> &a) {
    int s = a[0], t = s;
    for (int x : a)
        if (clac(s, x) > clac(s, t)) t = x;
    s = t;
    for (int x : a)
        if (clac(s, x) > clac(s, t)) t = x;
    int d = clac(s, t);
    return {kth(s, t, d / 2), (d + 1) / 2};
}
```

**例：** 链 1–2–3–4–5，关键点 {1,5}：中心 3，半径 2。

##### 树上题 008：点号区间的公共祖先

<a id="tree100-008"></a>

**建议难度：银牌。题意与用途：** 多次查询所有编号在 [l,r] 的点的 LCA；用于编号集合压缩和静态区间树结构查询。

**思路：** 任意点集的 LCA 等于 DFS 序最小、最大点的 LCA。按点号建稀疏表，保存 id 的最小和最大值。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); buildRangeLca(); rangeLca(l,r)。

**复杂度与边界：** 预处理 O(n log n)，查询 O(log n)（主要为 HLD LCA），空间 O(n log n)。1≤l≤r≤n。

```c++
vector<vector<int>> mnId, mxId;
vector<int> lgId;
void buildRangeLca() {
    lgId.assign(n + 1, 0);
    for (int i = 2; i <= n; i++)
        lgId[i] = lgId[i / 2] + 1;
    mnId.assign(lgId[n] + 1, vector<int>(n + 1));
    mxId = mnId;
    mnId[0] = mxId[0] = id;
    for (int j = 1; j <= lgId[n]; j++)
        for (int i = 1; i + (1LL << j) - 1 <= n; i++) {
            mnId[j][i] = min(mnId[j - 1][i], mnId[j - 1][i + (1LL << (j - 1))]);
            mxId[j][i] = max(mxId[j - 1][i], mxId[j - 1][i + (1LL << (j - 1))]);
        }
}
int rangeLca(int l, int r) {
    int k = lgId[r - l + 1], p = r - (1LL << k) + 1;
    return lca(rid[min(mnId[k][l], mnId[k][p])], rid[max(mxId[k][l], mxId[k][p])]);
}
```

**例：** 星形根 1，编号区间 [2,4] 的公共祖先是 1。

##### 树上题 009：增量维护关键点直径

<a id="tree100-009"></a>

**建议难度：银牌。题意与用途：** 非负边权树中逐个加入关键点，每次输出当前集合的直径；用于在线集合跨度与最远点查询。

**思路：** 若旧直径端点为 s,t，新点 x 到旧集合的最大距离等于 max(d(x,s),d(x,t))，比较这两条候选即可。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** rootTree(r); buildHld(); 首次加入前 ds=dt=0, dd=0；pushDiameter(x) 返回新直径。

**复杂度与边界：** 单次 O(log n)，O(1) 额外空间。重复加入不影响结果，边权必须非负。

```c++
int ds = 0, dt = 0;
ll dd = 0;
ll pushDiameter(int x) {
    if (!ds) {
        ds = dt = x;
        return dd = 0;
    }
    ll a = dist(ds, x), b = dist(dt, x);
    if (a > dd && a >= b) dt = x, dd = a;
    else if (b > dd) ds = x, dd = b;
    return dd;
}
```

**例：** 链 1–2–3–4，依次加入 2、4、1，直径为 0、2、3。

##### 树上题 010：树上追逐的必胜判定

<a id="tree100-010"></a>

**建议难度：银牌。题意与用途：** 无权树，Alice 从 a、Bob 从 b 出发轮流行动，Alice 先手；各自每步可走至多 da、db 条边，允许不动，Alice 占到 Bob 所在点即获胜。判断 Alice 是否必胜。用于树直径博弈。

**思路：** 能一步追上则胜；否则 Alice 的控制范围若覆盖直径的一半，可以先占中心。剩余情形中 db≤2da 时可持续压缩距离；db>2da 且直径>2da 时 Bob 能保持逃逸。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)、[无权直径](#diameter)。

**初始化与接口：** da,db≥1；rootTree(r); buildHld(); aliceWin(a,b,da,db)。

**复杂度与边界：** O(n) 时间求直径，O(n) 临时空间；同树多询问可缓存直径使每次 O(log n)。

```c++
bool aliceWin(int a, int b, int da, int db) {
    return clac(a, b) <= da || db <= 2LL * da || diameter()[2] <= 2LL * da;
}
```

**例：** 5 点链，两人在 1、5，da=1、db=3 时 Bob 可逃逸；db=2 时 Alice 必胜。

##### 树上题 011：点赋值与路径点权和：子树差分法

<a id="tree100-011"></a>

**建议难度：铜牌。题意与用途：** 在线修改单点权值并查询路径点权和；用于只改点时替代完整 HLD 线段树。

**思路：** 修改 u 的权值会给全部后代的根路径前缀加同一增量，在 id 子树区间做差分。路径和为 P(u)+P(v)−2P(lca)+a[lca]。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); buildPoint(a); setPoint(u,x); pointPath(u,v)。

**复杂度与边界：** 建树 O(n log n)，每次 O(log n)，空间 O(n)；允许负点权。

```c++
vector<ll> pa, pb;
void buildPoint(const vector<ll> &a) {
    pa = a;
    pb.assign(n + 2, 0);
    for (int u = 1; u <= n; u++) {
        bitAdd(pb, id[u], a[u]);
        bitAdd(pb, id[u] + siz[u], -a[u]);
    }
}
void setPoint(int u, ll x) {
    ll d = x - pa[u];
    pa[u] = x;
    bitAdd(pb, id[u], d);
    bitAdd(pb, id[u] + siz[u], -d);
}
ll pointPath(int u, int v) {
    int p = lca(u, v);
    return bitSum(pb, id[u]) + bitSum(pb, id[v]) - 2 * bitSum(pb, id[p]) + pa[p];
}
```

**例：** 链 1–2–3，点权 1、2、3，路径和 6；把点 2 改为 5 后变成 9。

##### 树上题 012：子树加与根路径和

<a id="tree100-012"></a>

**建议难度：银牌。题意与用途：** 初始点权全零，每次给 u 的整棵子树加 x，查询根到 v 的点权和；用于深度一次函数维护。

**思路：** 当 v 在 u 子树内，根路径中受影响的点数为 dep[v]−dep[u]+1。因此对该子树加入系数 x 和常数 x(1−dep[u])，两棵差分 BIT 查询一次函数。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); buildDepthAdd(); depthAdd(u,x); rootSum(v)。

**复杂度与边界：** 预处理 O(n)，每次 O(log n)，空间 O(n)。初始非零权值可先逐点加入根路径前缀基值。

```c++
vector<ll> ba, bb;
void buildDepthAdd() {
    ba.assign(n + 2, 0);
    bb = ba;
}
void depthAdd(int u, ll x) {
    int l = id[u], r = l + siz[u];
    ll y = x * (1LL - dep[u]);
    bitAdd(ba, l, x);
    bitAdd(ba, r, -x);
    bitAdd(bb, l, y);
    bitAdd(bb, r, -y);
}
ll rootSum(int v) {
    return dep[v] * bitSum(ba, id[v]) + bitSum(bb, id[v]);
}
```

**例：** 链 1–2–3，给点 2 子树加 4：rootSum(3)=8，rootSum(1)=0。

##### 树上题 013：沿有向路径加等差数列

<a id="tree100-013"></a>

**建议难度：银牌。题意与用途：** 离线操作 (u,v,A,D)：沿 u→v 第 j 个点加 A+jD，j 从 0 开始，最后求每点总值；用于有方向的批量路径贡献。

**思路：** 以 p=LCA(u,v) 分成 u→p 和 p 的下一点→v，两段增量分别为深度的一次函数。对祖先链闭区间做端点差分，再倒序累加两个系数。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); apPaths(ops)；ops 用 tuple<int,int,ll,ll>。

**复杂度与边界：** O(n+q log n) 时间、O(n) 空间；有向性不能通过交换端点消除。

```c++
vector<ll> apPaths(const vector<tuple<int, int, ll, ll>> &qs) {
    vector<ll> a(n + 1), b(n + 1);
    auto put = [&](int u, int p, ll x, ll y) {
        a[u] += x;
        b[u] += y;
        a[fa[p]] -= x;
        b[fa[p]] -= y;
    };
    for (auto [u, v, A, D] : qs) {
        int p = lca(u, v);
        put(u, p, -D, A + D * dep[u]);
        if (v != p) put(v, jump(v, dep[v] - dep[p] - 1), D, A + D * (dep[u] - 2LL * dep[p]));
    }
    for (int i = n - 1; i > 0; i--) {
        int u = ord[i];
        a[fa[u]] += a[u];
        b[fa[u]] += b[u];
    }
    for (int u = 1; u <= n; u++)
        b[u] += a[u] * dep[u];
    b[0] = 0;
    return b;
}
```

**例：** 链 1–2–3，操作 (3,1,2,3) 后点 1、2、3 分别为 8、5、2。

##### 树上题 014：批量路径异或更新

<a id="tree100-014"></a>

**建议难度：铜牌。题意与用途：** 每次把路径所有点异或一个掩码，离线输出最终点值；用于开关状态和 bitmask 叠加。

**思路：** 异或下加减相同，对 u、v、LCA、LCA 的父亲各异或 x，再倒序汇总。LCA 被保留一次，两端以上部分抵消。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); xorPaths(ops)，初值全零；有初值时最后再异或。

**复杂度与边界：** O(n+q log n) 时间、O(n) 空间；ull 掩码支持完整 64 位。

```c++
vector<ull> xorPaths(const vector<tuple<int, int, ull>> &qs) {
    vector<ull> d(n + 1);
    for (auto [u, v, x] : qs) {
        int p = lca(u, v);
        d[u] ^= x;
        d[v] ^= x;
        d[p] ^= x;
        d[fa[p]] ^= x;
    }
    for (int i = n - 1; i > 0; i--) {
        int u = ord[i];
        d[fa[u]] ^= d[u];
    }
    d[0] = 0;
    return d;
}
```

**例：** 链 1–2–3，路径 1–2 异或 3、路径 2–3 异或 5，结果 3、6、5。

##### 树上题 015：每个子树的不同颜色数

<a id="tree100-015"></a>

**建议难度：铜牌。题意与用途：** 静态统计所有子树的颜色种类；用于子树去重，无需树上莫队。

**思路：** 转成 id 区间。按右端点扫描，每种颜色只在最近出现位置放 1；BIT 区间和即不同颜色数。子树查询挂在其右端点。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); subtreeDistinct(color)，颜色可为任意 ll。

**复杂度与边界：** O(n log n) 时间、O(n) 空间。

```c++
vector<int> subtreeDistinct(const vector<ll> &c) {
    vector<vector<int>> qs(n + 1);
    vector<int> ans(n + 1);
    vector<ll> b(n + 2);
    map<ll, int> last;
    for (int u = 1; u <= n; u++)
        qs[id[u] + siz[u] - 1].push_back(u);
    for (int i = 1; i <= n; i++) {
        int &p = last[c[rid[i]]];
        if (p) bitAdd(b, p, -1);
        bitAdd(b, i, 1);
        p = i;
        for (int u : qs[i])
            ans[u] = bitSum(b, i) - bitSum(b, id[u] - 1);
    }
    return ans;
}
```

**例：** 根 1 连 2、3，颜色 7、7、9，各子树种数为 2、1、1。

##### 树上题 016：子树指定深度的点数

<a id="tree100-016"></a>

**建议难度：铜牌。题意与用途：** 多次查询 u 的子树中绝对深度为 d 的点数；用于代数层、指定距离后代统计。

**思路：** 把每个深度的 id 排成有序表，查询就是两个 lower_bound 之差。若给相对深度 k，则传 d=dep[u]+k。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); buildLayers(); layerCount(u,d)。

**复杂度与边界：** O(n) 建表、O(log n) 每次、O(n) 空间；越界深度返回 0。

```c++
vector<vector<int>> layer;
void buildLayers() {
    layer.assign(n, {});
    for (int i = 1; i <= n; i++)
        layer[dep[rid[i]]].push_back(i);
}
int layerCount(int u, int d) {
    if (d < 0 || d >= n) return 0;
    auto &a = layer[d];
    return lower_bound(a.begin(), a.end(), id[u] + siz[u]) - lower_bound(a.begin(), a.end(), id[u]);
}
```

**例：** 星形根 1、三个儿子，layerCount(1,1)=3，layerCount(2,1)=1。

##### 树上题 017：子树中比根点权更大的点数

<a id="tree100-017"></a>

**建议难度：铜牌。题意与用途：** 对每个 u 求其子树内 a[v]>a[u] 的点数；用于层级排名和偏序统计。

**思路：** 按权值降序激活点，在 id 上用 BIT。相同权值整批先查询再激活，保证严格大于。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); greaterBelow(a)。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；相等权值不能边查边加。

```c++
vector<int> greaterBelow(const vector<ll> &a) {
    vector<int> p(n), ans(n + 1);
    iota(p.begin(), p.end(), 1);
    sort(p.begin(), p.end(), [&](int u, int v) {
        return a[u] > a[v];
    });
    vector<ll> b(n + 2);
    for (int l = 0, r; l < n; l = r) {
        for (r = l; r < n && a[p[r]] == a[p[l]]; r++)
            ;
        for (int i = l; i < r; i++) {
            int u = p[i];
            ans[u] = bitSum(b, id[u] + siz[u] - 1) - bitSum(b, id[u] - 1);
        }
        for (int i = l; i < r; i++)
            bitAdd(b, id[p[i]], 1);
    }
    return ans;
}
```

**例：** 根 1 的权为 5，两个儿子权为 5、8，答案为 1。

##### 树上题 018：路径上不超过阈值的点数

<a id="tree100-018"></a>

**建议难度：银牌。题意与用途：** 给静态点权，多次询问路径 u–v 中 a[x]≤t 的数量；用于路径值域排名。

**思路：** 将点权和查询阈值排序；激活点时对其子树作区间差分，使 BIT 单点查询得到根路径激活数，再做 LCA 容斥。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); pathRank(a,qs)，查询为 tuple<int,int,ll>，答案按原顺序。

**复杂度与边界：** O((n+q) log(n+q)) 时间、O(n+q) 空间。

```c++
vector<int> pathRank(const vector<ll> &a, const vector<tuple<int, int, ll>> &qs) {
    int q = qs.size();
    vector<int> p(n), o(q), ans(q);
    iota(p.begin(), p.end(), 1);
    iota(o.begin(), o.end(), 0);
    sort(p.begin(), p.end(), [&](int u, int v) {
        return a[u] < a[v];
    });
    sort(o.begin(), o.end(), [&](int i, int j) {
        return get<2>(qs[i]) < get<2>(qs[j]);
    });
    vector<ll> b(n + 2);
    int j = 0;
    for (int i : o) {
        auto [u, v, t] = qs[i];
        while (j < n && a[p[j]] <= t) {
            int x = p[j++];
            bitAdd(b, id[x], 1);
            bitAdd(b, id[x] + siz[x], -1);
        }
        int w = lca(u, v);
        ans[i] = bitSum(b, id[u]) + bitSum(b, id[v]) - 2 * bitSum(b, id[w]) + (a[w] <= t);
    }
    return ans;
}
```

**例：** 链点权 5、2、8，路径 1–3 中 ≤5 的点有 2 个。

##### 树上题 019：动态关键点的最小连通子树

<a id="tree100-019"></a>

**建议难度：银牌。题意与用途：** 在线增删关键点，维护包含它们的最小连通子树边权和；用于动态 Steiner 子树长度。

**思路：** 关键点按 DFS 序成环，相邻距离和恰为 Steiner 边权和的两倍。插删只影响前驱、当前、后继三项。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); ks.clear(); perimeter=0；keySet(u,on)，答案 perimeter/2。

**复杂度与边界：** 每次 O(log n)，O(k) 空间。重复设同状态无作用；空集、单点答案 0。

```c++
set<int> ks;
ll perimeter = 0;
void keySet(int u, bool on) {
    int x = id[u];
    auto it = ks.find(x);
    if (on) {
        if (it != ks.end()) return;
        if (ks.empty()) {
            ks.insert(x);
            return;
        }
        auto r = ks.lower_bound(x);
        if (r == ks.end()) r = ks.begin();
        auto l = r == ks.begin() ? prev(ks.end()) : prev(r);
        perimeter += dist(rid[*l], u) + dist(u, rid[*r]) - dist(rid[*l], rid[*r]);
        ks.insert(x);
    } else {
        if (it == ks.end()) return;
        if (ks.size() == 1) {
            ks.clear();
            perimeter = 0;
            return;
        }
        auto r = next(it);
        if (r == ks.end()) r = ks.begin();
        auto l = it == ks.begin() ? prev(ks.end()) : prev(it);
        perimeter -= dist(rid[*l], u) + dist(u, rid[*r]) - dist(rid[*l], rid[*r]);
        ks.erase(it);
    }
}
```

**例：** 链 1–2–3–4，标记 {1,4} 长度 3；取消 1 后长度 0。

##### 树上题 020：删除一个关键点的最优压缩

<a id="tree100-020"></a>

**建议难度：银牌。题意与用途：** 可删除恰一个关键点，求剩余关键点 Steiner 子树最小边权和；用于识别最昂贵的离群终端。

**思路：** 按 id 成环。删除 x 会让周长减少 d(pre,x)+d(x,next)−d(pre,next)，枚举取最大节省。不能仅按离根距离删除。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); removeKey(keys)，输入会复制并去重。

**复杂度与边界：** O(k log k+k log n) 时间、O(k) 空间；不同关键点≤1 时返回 0。

```c++
ll removeKey(vector<int> a) {
    sort(a.begin(), a.end(), [](int u, int v) {
        return id[u] < id[v];
    });
    a.erase(unique(a.begin(), a.end()), a.end());
    int k = a.size();
    if (k <= 1) return 0;
    ll all = 0, save = 0;
    for (int i = 0; i < k; i++)
        all += dist(a[i], a[(i + 1) % k]);
    for (int i = 0; i < k; i++) {
        int p = a[(i + k - 1) % k], x = a[i], q = a[(i + 1) % k];
        save = max(save, dist(p, x) + dist(x, q) - dist(p, q));
    }
    return (all - save) / 2;
}
```

**例：** 链 1–2–3–4–5，关键点 {1,2,5}，删除 5 后仅需长度 1。

##### 树上题 021：最小权点覆盖

<a id="tree100-021"></a>

**建议难度：铜牌。题意与用途：** 选一些点，使每条边至少有一个端点被选，最小化非负点权和；用于树上的覆盖与布站。

**思路：** f[u][0/1] 表示 u 不选/选。u 不选时孩子必须选；u 选时孩子可任选。每条边的限制恰在父子转移处处理。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); vertexCover(cost)。

**复杂度与边界：** O(n) 时间、O(n) 空间；单点可不选。

```c++
ll vertexCover(const vector<ll> &a) {
    vector<array<ll, 2>> f(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u][1] = a[u];
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                f[u][0] += f[v][1];
                f[u][1] += min(f[v][0], f[v][1]);
            }
    }
    return min(f[ord[0]][0], f[ord[0]][1]);
}
```

**例：** 3 点链，点权 3、2、3，选中间点费用 2。

##### 树上题 022：最小权支配集

<a id="tree100-022"></a>

**建议难度：银牌。题意与用途：** 选非负费用顶点，使每个点自身被选或与一个被选点相邻，求最小费用；用于一跳覆盖。

**思路：** 三状态：0=选 u；1=u 不选但被孩子支配；2=u 不选且等父亲支配。状态 1 在各孩子取 min(0,1) 的基础上强制至少一个选 0；状态 2 的孩子必须处于 1。根不能等父亲。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); dominate(cost)。

**复杂度与边界：** O(n) 时间、O(n) 空间；总费用须远小于 2^60，无穷大加法饱和避免溢出。

```c++
ll dominate(const vector<ll> &a) {
    const ll BIG = 1LL << 60;
    vector<array<ll, 3>> f(n + 1);
    auto plus = [&](ll x, ll y) {
        return min(BIG, x + y);
    };
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        ll x = a[u], y = 0, z = 0, extra = BIG;
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                x = plus(x, min({f[v][0], f[v][1], f[v][2]}));
                ll t = min(f[v][0], f[v][1]);
                y = plus(y, t);
                z = plus(z, f[v][1]);
                extra = min(extra, f[v][0] - t);
            }
        f[u] = {x, plus(y, extra), z};
    }
    return min(f[ord[0]][0], f[ord[0]][1]);
}
```

**例：** 3 点链、单位费用，选中间点，答案 1；单点必须付自己的费用。

##### 树上题 023：最大权匹配

<a id="tree100-023"></a>

**建议难度：银牌。题意与用途：** 在树上选互不共享端点的边，使总权最大；用于一对一配对，边权可负。

**思路：** f[u] 是子树最优值，g[u] 是不让 u 与孩子匹配时的值。以 sum f[v] 为基底，最多选一个孩子 v，增益为 w+g[v]−f[v]。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); weightedMatch()，边权取自 e/pw。

**复杂度与边界：** O(n) 时间、O(n) 空间；允许空匹配，答案至少 0。

```c++
ll weightedMatch() {
    vector<ll> f(n + 1), g(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        ll gain = 0;
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                g[u] += f[v];
                gain = max(gain, w + g[v] - f[v]);
            }
        f[u] = g[u] + gain;
    }
    return f[ord[0]];
}
```

**例：** 链边权 4、7、5，可取第一和第三条，答案 9。

##### 树上题 024：匹配方案总数

<a id="tree100-024"></a>

**建议难度：银牌。题意与用途：** 统计树上所有匹配，包含空匹配，对 MOD 取模；用于树形组合计数。

**思路：** 合并孩子时维护 a=根未匹配、b=根已与一个孩子匹配。新孩子可独立匹配，也可将其未匹配状态与父边相接。整个过程无需模逆元。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); matchCount()，MOD≥2，可合数；乘法用 i128。

**复杂度与边界：** O(n) 时间、O(n) 空间。

```c++
ll matchCount() {
    vector<ll> f(n + 1), g(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        ll a = 1, b = 0;
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                b = ((i128)b * f[v] + (i128)a * g[v]) % MOD;
                a = (i128)a * f[v] % MOD;
            }
        g[u] = a;
        f[u] = (a + b) % MOD;
    }
    return f[ord[0]];
}
```

**例：** 3 点链有空匹配及两种单边匹配，共 3 种。

##### 树上题 025：带禁色的树染色

<a id="tree100-025"></a>

**建议难度：银牌。题意与用途：** 每个点有允许颜色集合，要求相邻点不同色，求 K 色染色方案数；用于局部约束下的树形计数。

**思路：** 令 f[u][c] 为 u 选 c 的方案数。每个孩子可贡献 sum f[v]−f[v][c]，先求孩子总和，把朴素 O(K²) 转移降为 O(K)。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); listColor(ok)，ok 是 (n+1)×K 的 char 表，K≥1。

**复杂度与边界：** O(nK) 时间、O(nK) 空间；MOD≥2，可合数。

```c++
ll listColor(const vector<vector<char>> &ok) {
    int k = ok[1].size();
    vector<vector<ll>> f(n + 1, vector<ll>(k));
    vector<ll> s(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        for (int c = 0; c < k; c++)
            f[u][c] = ok[u][c];
        for (auto [v, w] : e[u])
            if (fa[v] == u)
                for (int c = 0; c < k; c++)
                    f[u][c] = (i128)f[u][c] * ((s[v] - f[v][c] + MOD) % MOD) % MOD;
        for (ll x : f[u])
            s[u] = (s[u] + x) % MOD;
    }
    return s[ord[0]];
}
```

**例：** 3 点链两色全部允许，共 2 种；固定点 1 的颜色后剩 1 种。

##### 树上题 026：每点必选的最大连通权和

<a id="tree100-026"></a>

**建议难度：银牌。题意与用途：** 点权可正可负，对每点 u 求包含 u 的非空连通点集最大权和；用于寻找最优区域与全根 DP。

**思路：** 向下只吸收正贡献。换根到孩子时，从父亲总答案中减去该孩子的正贡献，剩余父侧若为正再加入。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); allConnected(a)，返回 1-based 答案。

**复杂度与边界：** O(n) 时间、O(n) 空间；全负时每点答案就是自身权值。

```c++
vector<ll> allConnected(const vector<ll> &a) {
    vector<ll> d = a, ans(n + 1);
    for (int i = n - 1; i > 0; i--) {
        int u = ord[i];
        d[fa[u]] += max(0LL, d[u]);
    }
    ans[ord[0]] = d[ord[0]];
    for (int i = 1; i < n; i++) {
        int u = ord[i];
        ans[u] = d[u] + max(0LL, ans[fa[u]] - max(0LL, d[u]));
    }
    return ans;
}
```

**例：** 链点权 4、−2、5，三个点的答案都为 7。

##### 树上题 027：切成大小不超过 B 的分量

<a id="tree100-027"></a>

**建议难度：银牌。题意与用途：** 删最少条边，使每个连通块的点数≤B；用于树分区和容量约束。

**思路：** 子树返回与 u 相连的剩余块大小。孩子已完成切割后，把剩余块从小到大尽量合并，装不下的切开。较小剩余块总不劣，既最大化当前合并数，也给祖先留下最小负担。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** B≥1；rootTree(r); cutSize(B)。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；B≥n 时答案 0。

```c++
int cutSize(int B) {
    vector<int> s(n + 1, 1);
    int ans = 0;
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        vector<int> a;
        for (auto [v, w] : e[u])
            if (fa[v] == u) a.push_back(s[v]);
        sort(a.begin(), a.end());
        for (int x : a)
            if (s[u] + x <= B) s[u] += x;
            else ++ans;
    }
    return ans;
}
```

**例：** 5 点链，B=2，需要切 2 条边；5 点星形需要切 3 条边。

##### 树上题 028：含根的 K 条边最大收益

<a id="tree100-028"></a>

**建议难度：银牌。题意与用途：** 选包含给定根的连通子树，恰有 K 条边，最大化边权和；用于树上资源选择。

**思路：** 树背包 f[u][j] 为含 u、选 j 条边的最优值。吸收孩子 k 条内部边时还要支付一条连接边，因此增加 k+1。保留不选该孩子的选项。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 0≤K<n；rootTree(r); edgeBudget(K)；负边也必须满足恰好数量。

**复杂度与边界：** 此简版时间上界 O(nK²)、空间 O(nK)，对子树大小截断；K=0 返回 0。

```c++
ll edgeBudget(int K) {
    const ll NEG = -(1LL << 60);
    vector<vector<ll>> f(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u] = {0};
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                vector<ll> g(min(K + 1, (int)(f[u].size() + f[v].size())), NEG);
                for (int j = 0; j < (int)f[u].size(); j++) {
                    g[j] = max(g[j], f[u][j]);
                    for (int k = 0; k < (int)f[v].size() && j + k + 1 <= K; k++)
                        g[j + k + 1] = max(g[j + k + 1], f[u][j] + f[v][k] + w);
                }
                f[u].swap(g);
            }
    }
    return f[ord[0]][K];
}
```

**例：** 根 1 连 2(权 5)、3(权 2)，K=1 得 5。

##### 树上题 029：保留 K 点连通块的最少切边

<a id="tree100-029"></a>

**建议难度：银牌。题意与用途：** 从树上保留任意恰 K 点的连通块，求把它与其余顶点隔离需要删的最少边；用于局部连通区域抽取。

**思路：** f[u][j] 表示保留含 u 的 j 点，且只计向下边界。对每个孩子：不取则切一条边；取 k 点则加其代价。最后枚举块的最高点 u，若不是根还需切父边。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 1≤K≤n；rootTree(r); isolateK(K)。

**复杂度与边界：** 时间上界 O(nK²)，空间 O(nK)；计数上界 n，使用 n+1 作无穷大。

```c++
int isolateK(int K) {
    vector<vector<int>> f(n + 1);
    int ans = n;
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u] = {n + 1, 0};
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                vector<int> g(min(K + 1, (int)(f[u].size() + f[v].size() - 1)), n + 1);
                for (int j = 1; j < (int)f[u].size(); j++) {
                    g[j] = min(g[j], f[u][j] + 1);
                    for (int k = 1; k < (int)f[v].size() && j + k <= K; k++)
                        g[j + k] = min(g[j + k], f[u][j] + f[v][k]);
                }
                f[u].swap(g);
            }
        if (K < (int)f[u].size()) ans = min(ans, f[u][K] + (fa[u] != 0));
    }
    return ans;
}
```

**例：** 5 点星形保留 3 点，需要切掉另外两片叶子的边，答案 2。

##### 树上题 030：按大小统计连通子树

<a id="tree100-030"></a>

**建议难度：银牌。题意与用途：** 统计大小为 1..K 的连通顶点集数量；用于树上连通组合和生成函数。

**思路：** 每个连通点集有唯一最高点。f[u][j] 统计含 u 且位于 u 子树内的 j 点连通集，按孩子乘上 1+F[v]；把每个最高点的贡献相加。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 1≤K≤n；rootTree(r); connectedSizes(K)，返回下标 1..K 的模计数。

**复杂度与边界：** 时间上界 O(nK²)、空间 O(nK)；MOD≥2，可合数。

```c++
vector<ll> connectedSizes(int K) {
    vector<vector<ll>> f(n + 1);
    vector<ll> ans(K + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u] = {0, 1};
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                vector<ll> g(min(K + 1, (int)(f[u].size() + f[v].size() - 1)));
                for (int j = 1; j < (int)f[u].size(); j++) {
                    g[j] = (g[j] + f[u][j]) % MOD;
                    for (int k = 1; k < (int)f[v].size() && j + k <= K; k++)
                        g[j + k] = (g[j + k] + (i128)f[u][j] * f[v][k]) % MOD;
                }
                f[u].swap(g);
            }
        for (int j = 1; j < (int)f[u].size(); j++)
            ans[j] = (ans[j] + f[u][j]) % MOD;
    }
    return ans;
}
```

**例：** 3 点链大小 1、2、3 的连通点集数为 3、2、1。

##### 树上题 031：树形先修课程选择

<a id="tree100-031"></a>

**建议难度：银牌。题意与用途：** 每个项目有一个父项目，选项目必须选全部祖先；恰选 K 项最大化收益。用于课程和树形依赖背包。

**思路：** 祖先闭合的非空集合恰好是含根的连通点集。根收益单独计算，把每条父边权设为孩子收益，则可直接复用 K−1 条边背包；以下直接给点权版本避免改写邻接表。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 0≤K≤n；rootTree(r); prerequisite(a,K)。森林可加收益 0 的虚根，再令 K 加 1。

**复杂度与边界：** 时间上界 O(nK²)、空间 O(nK)；允许负收益，K=0 返回 0。

```c++
ll prerequisite(const vector<ll> &a, int K) {
    if (!K) return 0;
    const ll NEG = -(1LL << 60);
    vector<vector<ll>> f(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u] = {NEG, a[u]};
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                vector<ll> g(min(K + 1, (int)(f[u].size() + f[v].size() - 1)), NEG);
                for (int j = 1; j < (int)f[u].size(); j++) {
                    g[j] = max(g[j], f[u][j]);
                    for (int k = 1; k < (int)f[v].size() && j + k <= K; k++)
                        g[j + k] = max(g[j + k], f[u][j] + f[v][k]);
                }
                f[u].swap(g);
            }
    }
    return f[ord[0]][K];
}
```

**例：** 根收益 −2，两个孩子收益 5、4，选 2 项得 3。

##### 树上题 032：往返根并收集 K 个终端

<a id="tree100-032"></a>

**建议难度：银牌。题意与用途：** 非负边权树上标记若干终端，可从中选择恰 K 个领取奖励，要求从根出发访问所选终端再回根，最小化路程；途中经过未领取终端不受限制。用于巡检和树上收集。

**思路：** 被使用的边都必须往返。f[u][j] 表示从 u 往返并收集 j 个终端的最小距离，吸收孩子的非空方案额外加 2w；j=0 时不进入孩子。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 0≤K≤标记总数；rootTree(r); collectReturn(mark,K)，mark 为 0/1。

**复杂度与边界：** 时间上界 O(nK²)、空间 O(nK)；K=0 为 0。题意是选 K 个，不限制实际经过的标记点数量。

```c++
ll collectReturn(const vector<int> &mark, int K) {
    const ll BIG = 1LL << 60;
    vector<vector<ll>> f(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u] = vector<ll>(min(K, mark[u]) + 1, 0);
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                vector<ll> g(min(K + 1, (int)(f[u].size() + f[v].size() - 1)), BIG);
                for (int j = 0; j < (int)f[u].size(); j++)
                    for (int k = 0; k < (int)f[v].size() && j + k <= K; k++)
                        g[j + k] = min(g[j + k], f[u][j] + f[v][k] + (k ? 2 * w : 0));
                f[u].swap(g);
            }
    }
    return f[ord[0]][K];
}
```

**例：** 根 1 连终端 2(权 2)、3(权 5)，选一个往返花 4，两个花 14。

##### 树上题 033：固定起终点的终端巡游

<a id="tree100-033"></a>

**建议难度：银牌。题意与用途：** 从 s 出发到 t 结束，访问全部关键点，求最短路程；允许重复边。用于送货、巡逻和 Steiner 游走。

**思路：** 必要子树包含关键点及 s,t；非 s–t 边往返两次，s–t 路径走一次。标记向上累计，只有两侧均有标记的边属于必要子树。答案 2W−dist(s,t)。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); visitEnds(keys,s,t)。

**复杂度与边界：** O(n+k+log n) 时间、O(n) 空间；重复关键点会去重。

```c++
ll visitEnds(const vector<int> &keys, int s, int t) {
    vector<int> c(n + 1);
    for (int u : keys)
        c[u] = 1;
    c[s] = c[t] = 1;
    int tot = accumulate(c.begin(), c.end(), 0LL);
    ll w = 0;
    for (int i = n - 1; i > 0; i--) {
        int u = ord[i];
        if (c[u] && c[u] < tot) w += pw[u];
        c[fa[u]] += c[u];
    }
    return 2 * w - dist(s, t);
}
```

**例：** 星形 1 连 2、3、4，从 2 到 3 且访问 4，路程 4。

##### 树上题 034：黑白点对距离和最大化

<a id="tree100-034"></a>

**建议难度：金牌。题意与用途：** 给 n 点非负边权树，选 K 点染黑，其余染白，最大化所有黑白点对距离和；用于边贡献与全局数量约束背包。

**思路：** 对父边，子树有 s 点、j 个黑点时，跨边黑白对数为 j(n−K−s+j)+(s−j)(K−j)。边贡献仅依赖 s,j，于是树背包分配黑点数量。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 0≤K≤n；rootTree(r); blackWhite(K)。

**复杂度与边界：** 时间上界 O(nK²)、空间 O(nK)；不可能的外部黑白数量直接跳过，乘法用 ll。

```c++
ll blackWhite(int K) {
    const ll NEG = -(1LL << 60);
    vector<vector<ll>> f(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u] = vector<ll>(min(K, (int)1) + 1, 0);
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                vector<ll> g(min(K + 1, (int)(f[u].size() + f[v].size() - 1)), NEG);
                for (int j = 0; j < (int)f[u].size(); j++)
                    if (f[u][j] != NEG)
                        for (int k = 0; k < (int)f[v].size() && j + k <= K; k++)
                            if (f[v][k] != NEG && K - k <= n - siz[v] && siz[v] - k <= n - K) {
                                ll c = 1LL * k * (n - K - siz[v] + k) + 1LL * (siz[v] - k) * (K - k);
                                g[j + k] = max(g[j + k], f[u][j] + f[v][k] + c * w);
                            }
                f[u].swap(g);
            }
    }
    return f[ord[0]][K];
}
```

**例：** 3 点链选一个黑点，染端点可得到距离和 3。

##### 树上题 035：所有点到最远关键点的距离

<a id="tree100-035"></a>

**建议难度：银牌。题意与用途：** 对每个顶点求到关键点集合的最大距离；用于多源覆盖的最坏距离、选址可行区间。

**思路：** 关键点直径的两端 a,b 已覆盖所有最远距离：ans[u]=max(d(u,a),d(u,b))。用树上遍历求距离，无需每点 LCA 查询。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 非负边权、keys 非空；rootTree(r); farKeys(keys)。

**复杂度与边界：** O(n+k) 时间、O(n) 空间；扫描只用局部父状态，不改公共根。

```c++
vector<ll> farKeys(const vector<int> &keys) {
    auto scan = [&](int s) {
        vector<ll> d(n + 1);
        vector<pair<int, int>> q{{s, 0}};
        for (int i = 0; i < (int)q.size(); i++) {
            auto [u, p] = q[i];
            for (auto [v, w] : e[u])
                if (v != p) d[v] = d[u] + w, q.push_back({v, u});
        }
        return d;
    };
    auto d = scan(keys[0]);
    int a = keys[0];
    for (int u : keys)
        if (d[u] > d[a]) a = u;
    d = scan(a);
    int b = a;
    for (int u : keys)
        if (d[u] > d[b]) b = u;
    auto t = scan(b);
    for (int u = 1; u <= n; u++)
        d[u] = max(d[u], t[u]);
    return d;
}
```

**例：** 5 点链，关键点 {1,5}，答案为 4、3、2、3、4。

##### 树上题 036：全根距离平方和

<a id="tree100-036"></a>

**建议难度：银牌。题意与用途：** 每点有非负质量 mass[v]，求每个 u 的 Σ mass[v]·dist(u,v)²；用于二阶距离代价与换根矩。

**思路：** 先维护子树质量和以 u 为原点的一阶距离和。跨边 w 换根时，内侧距离减 w、外侧加 w：二阶矩变化为 2w(S−2T)+w²M，其中 T 是内侧到旧根的距离加权和。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); squareSum(mass)。边权可为有符号路径长度；通常使用非负距离。

**复杂度与边界：** O(n) 时间、O(n) 空间；平方及质量乘积必须在 ll 内。

```c++
vector<ll> squareSum(const vector<ll> &mass) {
    vector<ll> m = mass, s(n + 1), all(n + 1), ans(n + 1);
    int r = ord[0];
    for (int u = 1; u <= n; u++)
        all[r] += mass[u] * dis[u], ans[r] += mass[u] * dis[u] * dis[u];
    for (int i = n - 1; i > 0; i--) {
        int u = ord[i], p = fa[u];
        s[p] += s[u] + m[u] * pw[u];
        m[p] += m[u];
    }
    for (int i = 1; i < n; i++) {
        int u = ord[i], p = fa[u];
        ll w = pw[u], t = s[u] + m[u] * w;
        ans[u] = ans[p] + 2 * w * (all[p] - 2 * t) + w * w * m[r];
        all[u] = all[p] + w * (m[r] - 2 * m[u]);
    }
    return ans;
}
```

**例：** 3 点单位权链、单位质量，平方和为 5、2、5。

##### 树上题 037：每点的距离模 K 直方图

<a id="tree100-037"></a>

**建议难度：银牌。题意与用途：** 无权树，对每点 u 统计距离余数为 0..K−1 的顶点数，包含 u 自身；用于奇偶距离、余数分类概率。

**思路：** 向下 DP 移动一条边使余数加 1。换根到孩子时，先从父亲全树直方图中扣掉该孩子经过父边后的贡献，再整体平移一次加入孩子。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** K≥1；rootTree(r); residueHistogram(K)。

**复杂度与边界：** O(nK) 时间、O(nK) 空间；忽略 e 中权值，按边数计距离。

```c++
vector<vector<ll>> residueHistogram(int K) {
    vector<vector<ll>> d(n + 1, vector<ll>(K)), a;
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        d[u][0]++;
        if (fa[u])
            for (int j = 0; j < K; j++)
                d[fa[u]][(j + 1) % K] += d[u][j];
    }
    a = d;
    for (int i = 1; i < n; i++) {
        int u = ord[i], p = fa[u];
        for (int j = 0; j < K; j++)
            a[u][(j + 1) % K] += a[p][j] - d[u][(j + K - 1) % K];
    }
    return a;
}
```

**例：** 3 点链、K=2，点 1 的偶/奇距离数量为 2、1。

##### 树上题 038：每点所在连通子树的方案数

<a id="tree100-038"></a>

**建议难度：银牌。题意与用途：** 对所有 u 统计包含 u 的连通顶点集数；用于换根乘法 DP，模数允许为合数。

**思路：** 每个相邻分支可不选或选一个接到 u 的连通集。向下积求子树状态，向上用前后缀积排除指定孩子，避免除法与逆元。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); containingCount()，MOD≥2。

**复杂度与边界：** O(n) 时间、O(n) 空间；星形的大度数也只线性处理。

```c++
vector<ll> containingCount() {
    vector<ll> d(n + 1, 1), up(n + 1), ans(n + 1);
    for (int i = n - 1; i > 0; i--) {
        int u = ord[i];
        d[fa[u]] = (i128)d[fa[u]] * (d[u] + 1) % MOD;
    }
    for (int u : ord) {
        vector<int> c;
        for (auto [v, w] : e[u])
            if (fa[v] == u) c.push_back(v);
        int k = c.size();
        vector<ll> pre(k + 1, 1), suf(k + 1, 1);
        for (int i = 0; i < k; i++)
            pre[i + 1] = (i128)pre[i] * (d[c[i]] + 1) % MOD;
        for (int i = k - 1; i >= 0; i--)
            suf[i] = (i128)suf[i + 1] * (d[c[i]] + 1) % MOD;
        ans[u] = (i128)d[u] * (up[u] + 1) % MOD;
        for (int i = 0; i < k; i++)
            up[c[i]] = (i128)pre[i] * suf[i + 1] % MOD * (up[u] + 1) % MOD;
    }
    return ans;
}
```

**例：** 3 点链，包含各点的连通集分别有 3、4、3 个。

##### 树上题 039：所有根的递增标号方案数

<a id="tree100-039"></a>

**建议难度：银牌。题意与用途：** 用 1..n 给树顶点重新赋不同标号，要求父亲标号小于儿子，求每种根的方案数；用于偏序线性扩展计数。

**思路：** 树的钩长公式为 n!/∏siz[u]。根跨到孩子 v 时，只有两侧块大小改变，答案乘 siz[v]/(n−siz[v])。预先线性求逆元。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** MOD 为质数且 n<MOD；rootTree(r); increasingLabels()。

**复杂度与边界：** O(n) 时间、O(n) 空间；不能直接用于合数模或 n≥MOD。

```c++
vector<ll> increasingLabels() {
    vector<ll> inv(n + 1, 1), ans(n + 1);
    ll x = 1;
    for (int i = 2; i <= n; i++)
        inv[i] = MOD - (i128)(MOD / i) * inv[MOD % i] % MOD;
    for (int i = 1; i <= n; i++)
        x = (i128)x * i % MOD * inv[siz[i]] % MOD;
    ans[ord[0]] = x;
    for (int i = 1; i < n; i++) {
        int u = ord[i];
        ans[u] = (i128)ans[fa[u]] * siz[u] % MOD * inv[n - siz[u]] % MOD;
    }
    return ans;
}
```

**例：** 3 点链，根在端点时仅 1 种，在中间时 2 种。

##### 树上题 040：随机 DFS 的首次访问排名期望

<a id="tree100-040"></a>

**建议难度：银牌。题意与用途：** 每个点独立均匀打乱孩子顺序，再做先序 DFS，求每点首次访问排名期望；用于随机遍历与线性期望。

**思路：** 对孩子 v，兄弟子树各有一半概率排在它之前。因此 E[v]=E[u]+1+(siz[u]−1−siz[v])/2。只需要期望线性性，不需要枚举顺序。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); expectedDfs()，根的排名为 1。

**复杂度与边界：** O(n) 时间、O(n) 空间；结果为整数或半整数，用 ld。这里不是随机游走到达时间。

```c++
vector<ld> expectedDfs() {
    vector<ld> a(n + 1);
    a[ord[0]] = 1;
    for (int i = 1; i < n; i++) {
        int u = ord[i], p = fa[u];
        a[u] = a[p] + 1 + (siz[p] - 1 - siz[u]) / 2.0L;
    }
    return a;
}
```

**例：** 根连三个叶子，根排名 1，每片叶子期望排名 3。

##### 树上题 041：子树内频次至少 K 的颜色数

<a id="tree100-041"></a>

**建议难度：银牌。题意与用途：** 多次查询子树 u 中至少出现 K 次的颜色数量；用于颜色频率的二维离线统计。

**思路：** DSU on tree 保留重儿子，轻儿子处理后清空。维护每色频次，并在频次 BIT 上记录有多少颜色处于该频次；后缀和回答 ≥K。显式事件栈避免长链递归。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); freqAtLeast(color,qs)，查询 pair<int,int>{u,K}，K≥1。

**复杂度与边界：** O(n log² n+q log n) 时间、O(n+q) 空间；颜色先离散化。

```c++
vector<int> freqAtLeast(const vector<ll> &col, const vector<pair<int, int>> &qs) {
    vector<ll> vals(col.begin() + 1, col.end());
    sort(vals.begin(), vals.end());
    vals.erase(unique(vals.begin(), vals.end()), vals.end());
    vector<int> c(n + 1), cnt(vals.size()), ans(qs.size());
    vector<ll> b(n + 2);
    vector<vector<pair<int, int>>> ask(n + 1);
    for (int u = 1; u <= n; u++)
        c[u] = lower_bound(vals.begin(), vals.end(), col[u]) - vals.begin();
    for (int i = 0; i < (int)qs.size(); i++)
        ask[qs[i].first].push_back({qs[i].second, i});
    auto change = [&](int u, int d) {
        int &x = cnt[c[u]];
        if (x) bitAdd(b, x, -1);
        x += d;
        if (x) bitAdd(b, x, 1);
    };
    vector<array<int, 3>> st{{ord[0], 1, 0}}; // u,保留,阶段
    while (!st.empty()) {
        auto [u, keep, stage] = st.back();
        st.pop_back();
        if (!stage) {
            st.push_back({u, keep, 1});
            if (son[u]) st.push_back({son[u], 1, 0});
            for (auto [v, w] : e[u])
                if (fa[v] == u && v != son[u]) st.push_back({v, 0, 0});
        } else {
            change(u, 1);
            for (auto [v, w] : e[u])
                if (fa[v] == u && v != son[u])
                    for (int i = id[v]; i < id[v] + siz[v]; i++)
                        change(rid[i], 1);
            for (auto [k, i] : ask[u])
                ans[i] = k > n ? 0 : bitSum(b, n) - bitSum(b, k - 1);
            if (!keep)
                for (int i = id[u]; i < id[u] + siz[u]; i++)
                    change(rid[i], -1);
        }
    }
    return ans;
}
```

**例：** 根连三个儿子，颜色 7、7、9、7，根中至少出现 2 次的颜色只有 7。

##### 树上题 042：子树某深度颜色能否重排成回文

<a id="tree100-042"></a>

**建议难度：银牌。题意与用途：** 颜色编号 0..25，询问子树 u 内绝对深度 d 的所有颜色能否重排成回文；用于奇偶频次压缩。

**思路：** 每种颜色只关心奇偶，异或单 bit。按深度将 id 排序并做异或前缀；区间掩码至多有一个 1 即可。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); buildPalLayers(color); layerPalindrome(u,d)。

**复杂度与边界：** O(n) 预处理、O(log n) 单次、O(n) 空间；空集合可形成空回文。

```c++
vector<vector<int>> pos;
vector<vector<ull>> mask;
void buildPalLayers(const vector<int> &c) {
    pos.assign(n, {});
    mask.assign(n, vector<ull>{0});
    for (int i = 1; i <= n; i++) {
        int u = rid[i], d = dep[u];
        pos[d].push_back(i);
        mask[d].push_back(mask[d].back() ^ (1ULL << c[u]));
    }
}
bool layerPalindrome(int u, int d) {
    if (d < 0 || d >= n) return true;
    int l = lower_bound(pos[d].begin(), pos[d].end(), id[u]) - pos[d].begin();
    int r = lower_bound(pos[d].begin(), pos[d].end(), id[u] + siz[u]) - pos[d].begin();
    ull x = mask[d][r] ^ mask[d][l];
    return (x & (x - 1)) == 0;
}
```

**例：** 根的三片叶子颜色 a、b、a，可以组成 aba；只有 a、b 时不行。

##### 树上题 043：每个子树的同色点对数

<a id="tree100-043"></a>

**建议难度：银牌。题意与用途：** 统计每个子树中颜色相同的不同顶点无序点对；用于小并大聚合及重复元素对计数。

**思路：** 每个子树维护颜色→频次。合并小表到大表时，相同色新增跨表点对 count1·count2；已有子树答案直接累加。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); sameColorPairs(color)。

**复杂度与边界：** O(n log² n) 时间、O(n) 活跃映射空间；小并大后清空被吸收的 map，答案为 ll。

```c++
vector<ll> sameColorPairs(const vector<ll> &c) {
    vector<map<ll, ll>> f(n + 1);
    vector<ll> ans(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u][c[u]] = 1;
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                ans[u] += ans[v];
                if (f[u].size() < f[v].size()) f[u].swap(f[v]);
                for (auto [x, k] : f[v]) {
                    ans[u] += f[u][x] * k;
                    f[u][x] += k;
                }
                f[v].clear();
            }
    }
    return ans;
}
```

**例：** 4 点树的全树颜色 1、1、2、1，同色无序对数 3。

##### 树上题 044：恰经过一个特殊点的路径数

<a id="tree100-044"></a>

**建议难度：银牌。题意与用途：** 给定特殊点集合，统计恰包含一个特殊点的简单路径，包含单点路径；用于颜色障碍下的路径计数。

**思路：** 删除特殊点后，普通点形成若干分量。对特殊点 u，合法路径可只含 u、从 u 进入一个相邻分量、或连接两个不同分量。按分量大小累加乘积即可。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 只需建 e；oneSpecial(mark)，mark 为 0/1，n≥1。

**复杂度与边界：** O(n) 时间、O(n) 空间。两个特殊点相邻的边不能参与合法路径。

```c++
ll oneSpecial(const vector<int> &mark) {
    vector<int> bel(n + 1, -1), s;
    for (int u = 1; u <= n; u++)
        if (!mark[u] && bel[u] < 0) {
            int k = s.size();
            vector<int> q{u};
            bel[u] = k;
            for (int i = 0; i < (int)q.size(); i++)
                for (auto [v, w] : e[q[i]])
                    if (!mark[v] && bel[v] < 0) bel[v] = k, q.push_back(v);
            s.push_back(q.size());
        }
    ll ans = 0;
    for (int u = 1; u <= n; u++)
        if (mark[u]) {
            ll pre = 0;
            ++ans;
            for (auto [v, w] : e[u])
                if (!mark[v]) {
                    ll x = s[bel[v]];
                    ans += x + pre * x;
                    pre += x;
                }
        }
    return ans;
}
```

**例：** 3 点链仅中间点特殊，四条合法路径是 {2}、1–2、2–3、1–3。

##### 树上题 045：每个子树的同色点对距离和

<a id="tree100-045"></a>

**建议难度：金牌。题意与用途：** 对每个子树统计同色不同点之间的距离总和；用于小并大中同时维护数量与一阶矩。

**思路：** 颜色表保存 {数量,根距离之和}。合并两块时 LCA 就是当前 u，跨块贡献为 cntA·sumB+cntB·sumA−2dis[u]cntA cntB。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); colorDistance(color)，边权允许有符号。

**复杂度与边界：** O(n log² n) 时间、O(n) 活跃映射空间；中间乘积须在 ll 内。

```c++
vector<ll> colorDistance(const vector<ll> &c) {
    vector<map<ll, array<ll, 2>>> f(n + 1);
    vector<ll> ans(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u][c[u]] = {1, dis[u]};
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                ans[u] += ans[v];
                if (f[u].size() < f[v].size()) f[u].swap(f[v]);
                for (auto [x, b] : f[v]) {
                    auto &a = f[u][x];
                    ans[u] += a[0] * b[1] + b[0] * a[1] - 2 * dis[u] * a[0] * b[0];
                    a[0] += b[0];
                    a[1] += b[1];
                }
                f[v].clear();
            }
    }
    return ans;
}
```

**例：** 3 点链全部同色，根子树距离和为 1+1+2=4，点 2 子树为 1。

##### 树上题 046：子树中点最多的深度

<a id="tree100-046"></a>

**建议难度：银牌。题意与用途：** 对每个 u 找子树内出现点数最多的绝对深度，平局取较浅者；用于 dominant depth 与层分布。

**思路：** 小并大维护深度→点数，并保存当前最大频次对应深度。只需在增加的深度处更新最优解；交换表时也交换最优深度。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); dominantDepth()；相对深度答案再减 dep[u]。

**复杂度与边界：** O(n log² n) 时间、O(n) 活跃映射空间。比长链剖分版本稍慢，但实现通用。

```c++
vector<int> dominantDepth() {
    vector<map<int, int>> f(n + 1);
    vector<int> best(n + 1), ans(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        f[u][dep[u]] = 1;
        best[u] = dep[u];
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                if (f[u].size() < f[v].size()) {
                    f[u].swap(f[v]);
                    swap(best[u], best[v]);
                }
                for (auto [d, k] : f[v]) {
                    int x = (f[u][d] += k), y = f[u][best[u]];
                    if (x > y || (x == y && d < best[u])) best[u] = d;
                }
                f[v].clear();
            }
        ans[u] = best[u];
    }
    return ans;
}
```

**例：** 4 点星形根 1：根子树深度 1 最多；每片叶子答案也是深度 1。

##### 树上题 047：边字母路径可重排成回文的点对

<a id="tree100-047"></a>

**建议难度：银牌。题意与用途：** 边标签来自 0..B−1，统计路径字母可重排成回文的不同顶点无序点对；用于树路径异或指纹。

**思路：** 根路径字母奇偶掩码为 mask[u]，两点路径掩码为 mask[u] xor mask[v]。只需查相同掩码和相差一位的历史顶点。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 1≤B≤20；将边标签存 e 的权字段，rootTree(r); palindromePairs(B)。

**复杂度与边界：** 使用 map 为 O(nB log n) 时间、O(n) 空间。这里权值是字母编号，不是距离。

```c++
ll palindromePairs(int B) {
    vector<ull> m(n + 1);
    map<ull, ll> cnt;
    ll ans = 0;
    for (int u : ord) {
        if (fa[u]) m[u] = m[fa[u]] ^ (1ULL << pw[u]);
        auto get = [&](ull x) {
            auto it = cnt.find(x);
            return it == cnt.end() ? 0LL : it->second;
        };
        ans += get(m[u]);
        for (int b = 0; b < B; b++)
            ans += get(m[u] ^ (1ULL << b));
        ++cnt[m[u]];
    }
    return ans;
}
```

**例：** 链的两个边标签分别为 a、b，只有两条单边路径合法，答案 2。

##### 树上题 048：相邻颜色不同的最长路径

<a id="tree100-048"></a>

**建议难度：铜牌。题意与用途：** 点有颜色，求路径上任意相邻点颜色不同的最长路径边数；用于局部限制下的直径 DP。

**思路：** 每点保留能延伸到孩子的最长两条合法向下链；颜色相同的父子边不能使用。两条链相接形成以 u 为最高点的候选。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); colorfulDiameter(color)，忽略边权。

**复杂度与边界：** O(n) 时间、O(n) 空间；单点合法，答案至少 0。

```c++
int colorfulDiameter(const vector<ll> &c) {
    vector<int> d(n + 1);
    int ans = 0;
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i], a = 0, b = 0;
        for (auto [v, w] : e[u])
            if (fa[v] == u && c[u] != c[v]) {
                int x = d[v] + 1;
                if (x > a) b = a, a = x;
                else b = max(b, x);
            }
        d[u] = a;
        ans = max(ans, a + b);
    }
    return ans;
}
```

**例：** 链颜色 a、b、b、c，最长合法路径为 1 条边。

##### 树上题 049：每个子树外的不同颜色数

<a id="tree100-049"></a>

**建议难度：银牌。题意与用途：** 统计每点子树的补集中有多少种颜色；用于删除一个区域后的颜色多样性。

**思路：** 一种颜色会从补集中消失，当且仅当该颜色最小、最大 id 都位于子树区间。按最大 id 扫描，BIT 标记其最小 id，得到完全包含在子树内的颜色数，再从全局种数扣除。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); outsideColors(color)。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；根的补集为空。

```c++
vector<int> outsideColors(const vector<ll> &c) {
    map<ll, array<int, 2>> rg;
    for (int i = 1; i <= n; i++) {
        auto &x = rg[c[rid[i]]];
        if (!x[0]) x[0] = i;
        x[1] = i;
    }
    vector<vector<int>> at(n + 1), qs(n + 1);
    vector<int> ans(n + 1);
    vector<ll> b(n + 2);
    for (auto [x, z] : rg)
        at[z[1]].push_back(z[0]);
    for (int u = 1; u <= n; u++)
        qs[id[u] + siz[u] - 1].push_back(u);
    for (int r = 1; r <= n; r++) {
        for (int l : at[r])
            bitAdd(b, l, 1);
        for (int u : qs[r])
            ans[u] = rg.size() - (bitSum(b, r) - bitSum(b, id[u] - 1));
    }
    return ans;
}
```

**例：** 根与两个孩子颜色 7、7、9，去掉颜色 9 的叶子后剩一种颜色，去掉颜色 7 的叶子后剩两种。

##### 树上题 050：同色点对的 LCA 深度和

<a id="tree100-050"></a>

**建议难度：金牌。题意与用途：** 求所有同色不同顶点无序点对的 LCA 深度之和；用于按颜色分组后压缩树形关系。

**思路：** 每种颜色单独建虚树，c[u] 为该虚子树关键点数。恰以 u 为 LCA 的点对数为 C(c[u],2)−Σ C(c[child],2)。用相邻层深度差累加可免建孩子表。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** rootTree(r); buildHld(); colorLcaSum(color)，根深度为 0。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；所有虚树的输入关键点总数为 n。

```c++
ll colorLcaSum(const vector<ll> &color) {
    map<ll, vector<int>> groups;
    for (int u = 1; u <= n; u++)
        groups[color[u]].push_back(u);
    ll ans = 0;
    for (auto &[col, keys] : groups) {
        auto t = virtualTree(keys);
        int m = t.nodes.size();
        vector<ll> c(m);
        for (int i = 0; i < m; i++)
            c[i] = t.marked[i];
        for (int i = m - 1; i >= 0; i--) {
            int p = t.fa[i];
            ll pairs = c[i] * (c[i] - 1) / 2;
            ans += pairs * (dep[t.nodes[i]] - (p < 0 ? 0 : dep[t.nodes[p]]));
            if (p >= 0) c[p] += c[i];
        }
    }
    return ans;
}
```

**例：** 3 点链根 1、全同色，三个点对 LCA 深度为 0、0、1，总和 1。

##### 树上题 051：关键点两两距离和

<a id="tree100-051"></a>

**建议难度：银牌。题意与用途：** 多组少量关键点，求不同关键点无序点对距离和；用于大树上的小集合统计。

**思路：** 虚树压缩非分叉路径。虚边一侧有 c 个关键点，总数 k，则经过它的点对为 c(k−c)，乘原树权长即可。虚树自带 len 是边数，带权必须用 dis 差。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** rootTree(r); buildHld(); keyPairSum(keys)，自动去重。

**复杂度与边界：** 单组 O(k log k+k log n) 时间、O(k) 空间；空集和单点为 0，边权可为有符号。

```c++
ll keyPairSum(const vector<int> &keys) {
    auto t = virtualTree(keys);
    int m = t.nodes.size();
    vector<ll> c(m);
    ll k = 0, ans = 0;
    for (int i = 0; i < m; i++)
        k += (c[i] = t.marked[i]);
    for (int i = m - 1; i > 0; i--) {
        int p = t.fa[i];
        ans += c[i] * (k - c[i]) * (dis[t.nodes[i]] - dis[t.nodes[p]]);
        c[p] += c[i];
    }
    return ans;
}
```

**例：** 星形三片叶子，每对距离 2，合计 6。

##### 树上题 052：切断根与所有关键点的最小费用

<a id="tree100-052"></a>

**建议难度：金牌。题意与用途：** 每条边有非负切割费用，多次给关键点集合，求使根与全部关键点断开的最小总费用；用于虚树最小割。

**思路：** 预处理根到每点的最小边费用 low[u]。虚树 DP：关键点必须在根路径上切，取 low[u]；非关键点可在上方统一切，或分别切断孩子，取两者最小。共享上方边只会让后续取 min 更优，不会被强制重复购买。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** rootTree(r); buildHld(); buildRootMin(); cutKeys(keys)。根为 ord[0]；若根本身关键返回 −1。

**复杂度与边界：** 预处理 O(n)，每组 O(k log k+k log n)，额外预处理空间 O(n)、单组 O(k)。费用和须远小于 2^60。

```c++
vector<ll> low;
void buildRootMin() {
    low.assign(n + 1, 1LL << 60);
    for (int u : ord)
        if (fa[u]) low[u] = min(low[fa[u]], pw[u]);
}
ll cutKeys(vector<int> keys) {
    int r = ord[0];
    if (find(keys.begin(), keys.end(), r) != keys.end()) return -1;
    keys.push_back(r);
    auto t = virtualTree(keys);
    int m = t.nodes.size();
    vector<ll> f(m);
    for (int i = m - 1; i > 0; i--) {
        f[i] = t.marked[i] ? low[t.nodes[i]] : min(low[t.nodes[i]], f[i]);
        f[t.fa[i]] += f[i];
    }
    return f[0];
}
```

**例：** 链边费用 5、2，关键点只有 3，切费用 2；若 2、3 都关键则需切费用 5。

##### 树上题 053：关键点最近与最远点对

<a id="tree100-053"></a>

**建议难度：银牌。题意与用途：** 多组关键点，求最小和最大两两距离；用于集合紧密程度与跨度。

**思路：** 虚树每点保存向下最近、最远关键点距离。合并一个孩子前，与已经合入的其他分支配对，从而每个点对只在其 LCA 统计。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); keyNearFar(keys) 返回 {最近,最远}；不足两不同点返回 {-1,-1}。

**复杂度与边界：** 单组 O(k log k+k log n) 时间、O(k) 空间；路径长度须小于 2^60。

```c++
array<ll, 2> keyNearFar(const vector<int> &keys) {
    auto t = virtualTree(keys);
    int m = t.nodes.size(), k = 0;
    const ll BIG = 1LL << 60;
    vector<ll> a(m, BIG), b(m, -BIG);
    ll near = BIG, far = -BIG;
    for (int i = 0; i < m; i++)
        if (t.marked[i]) a[i] = b[i] = 0, ++k;
    if (k < 2) return {-1, -1};
    for (int i = m - 1; i > 0; i--) {
        int p = t.fa[i];
        ll w = dis[t.nodes[i]] - dis[t.nodes[p]];
        if (a[p] != BIG) near = min(near, a[p] + a[i] + w);
        if (b[p] != -BIG) far = max(far, b[p] + b[i] + w);
        a[p] = min(a[p], a[i] + w);
        b[p] = max(b[p], b[i] + w);
    }
    return {near, far};
}
```

**例：** 链 1–2–3–4–5，关键点 {1,2,5}，最近距离 1、最远 4。

##### 树上题 054：被至少 T 对终端路径使用的边

<a id="tree100-054"></a>

**建议难度：银牌。题意与用途：** 给关键点集与 T≥1，求被至少 T 对不同关键点路径经过的边的权值和；用于核心道路负载统计。

**思路：** 虚边代表的整段原树路径有相同关键点两侧划分，负载均为 c(k−c)。满足阈值就把整个压缩段权长计入。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** rootTree(r); buildHld(); busyEdges(keys,T)，重复点去重。

**复杂度与边界：** O(k log k+k log n) 时间、O(k) 空间；T 必须≥1，否则虚树外的零负载边也要统计。

```c++
ll busyEdges(const vector<int> &keys, ll T) {
    auto t = virtualTree(keys);
    int m = t.nodes.size();
    vector<ll> c(m);
    ll k = 0, ans = 0;
    for (int i = 0; i < m; i++)
        k += (c[i] = t.marked[i]);
    for (int i = m - 1; i > 0; i--) {
        int p = t.fa[i];
        if (c[i] * (k - c[i]) >= T) ans += dis[t.nodes[i]] - dis[t.nodes[p]];
        c[p] += c[i];
    }
    return ans;
}
```

**例：** 星形 3 个叶子全关键，每条边负载 2，T=2 得 3，T=3 得 0。

##### 树上题 055：起终点自由的终端巡游

<a id="tree100-055"></a>

**建议难度：银牌。题意与用途：** 访问全部关键点，起终点可任选顶点，最小化总路程；用于最优开放式巡检。

**思路：** 必要 Steiner 子树每条边先计两次，再把起终点路径少走一次。应选择关键点直径，答案为 2W−D。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)、[第 053 题](#tree100-053)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); freeVisit(keys)。

**复杂度与边界：** O(k log k+k log n) 时间、O(k) 空间；空集、单点答案 0。

```c++
ll freeVisit(const vector<int> &keys) {
    auto t = virtualTree(keys);
    ll w = 0;
    for (int i = 1; i < (int)t.nodes.size(); i++)
        w += dis[t.nodes[i]] - dis[t.nodes[t.fa[i]]];
    ll d = keyNearFar(keys)[1];
    return 2 * w - max(0LL, d);
}
```

**例：** 星形三片叶子均须访问，Steiner 长度 3、直径 2，最短路程 4。

##### 树上题 056：红蓝关键点最近距离

<a id="tree100-056"></a>

**建议难度：银牌。题意与用途：** 给红点集合和蓝点集合，求一红一蓝的最小距离；用于两类终端的最近连接。

**思路：** 合并两色关键点建虚树，各点维护向下最近红、蓝距离。合并孩子前分别计算“孩子红＋已有蓝”和反向组合，同点两色给出 0。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); redBlue(red,blue)；任一集合为空返回 −1。

**复杂度与边界：** O(k log k+k log n) 时间、O(k) 空间，k 为两集合总大小；距离远小于 2^60。

```c++
ll redBlue(const vector<int> &red, const vector<int> &blue) {
    if (red.empty() || blue.empty()) return -1;
    vector<int> keys = red;
    keys.insert(keys.end(), blue.begin(), blue.end());
    auto t = virtualTree(keys);
    map<int, int> mark;
    for (int u : red)
        mark[u] |= 1;
    for (int u : blue)
        mark[u] |= 2;
    const ll BIG = 1LL << 60;
    int m = t.nodes.size();
    vector<array<ll, 2>> f(m, {BIG, BIG});
    ll ans = BIG;
    for (int i = 0; i < m; i++) {
        int c = mark[t.nodes[i]];
        if (c & 1) f[i][0] = 0;
        if (c & 2) f[i][1] = 0;
        if (c == 3) ans = 0;
    }
    for (int i = m - 1; i > 0; i--) {
        int p = t.fa[i];
        ll w = dis[t.nodes[i]] - dis[t.nodes[p]];
        for (int c = 0; c < 2; c++)
            if (f[i][c] != BIG && f[p][c ^ 1] != BIG) ans = min(ans, f[i][c] + w + f[p][c ^ 1]);
        for (int c = 0; c < 2; c++)
            if (f[i][c] != BIG) f[p][c] = min(f[p][c], f[i][c] + w);
    }
    return ans;
}
```

**例：** 5 点链红 {1,5}、蓝 {3,4}，最短距离 1。

##### 树上题 057：关键点中的祖先无关子集

<a id="tree100-057"></a>

**建议难度：银牌。题意与用途：** 从关键点中选一个子集，任意两个选中点都不能是祖先关系，求方案数（含空集）；用于树偏序反链计数。

**思路：** 虚树保留关键点之间全部祖先关系。不选当前点时各孩子独立相乘；当前是关键点时，还可只选它并强制整棵子树其他点不选，额外加 1。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** rootTree(r); buildHld(); antichains(keys)，MOD≥2，可合数。

**复杂度与边界：** O(k log k+k log n) 时间、O(k) 空间；空关键集只有空集一种方案。

```c++
ll antichains(const vector<int> &keys) {
    auto t = virtualTree(keys);
    int m = t.nodes.size();
    if (!m) return 1;
    vector<ll> f(m, 1);
    for (int i = m - 1; i >= 0; i--) {
        f[i] = (f[i] + t.marked[i]) % MOD;
        if (t.fa[i] >= 0) f[t.fa[i]] = (i128)f[t.fa[i]] * f[i] % MOD;
    }
    return f[0];
}
```

**例：** 链上 3 个点全关键，只能空选或单选，答案 4；3 片叶子全关键可任意选，答案 8。

##### 树上题 058：最少删点隔离所有关键点

<a id="tree100-058"></a>

**建议难度：金牌。题意与用途：** 只能删非关键顶点，使任意两个关键点不连通，求最少删点数；用于虚树多终端分割。

**思路：** 若原树中两个关键点直接相邻，无解。虚树 DP 记录是否有一个关键点仍向父亲连通：非关键点收到至少两路时删自身；关键点收到的每条子路必须各切一次，再向上保留自己。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[虚树](#virtual-tree)。

**初始化与接口：** rootTree(r); buildHld(); separateKeys(keys)，返回 −1 表示无解。

**复杂度与边界：** O(k log k+k log n) 时间、O(k) 空间。虚边跨多条原边时可在中间非关键点切断；不可把虚树相邻误认为原树相邻。

```c++
int separateKeys(vector<int> keys) {
    set<int> s(keys.begin(), keys.end());
    for (int u : s)
        if (s.count(fa[u])) return -1;
    auto t = virtualTree(keys);
    int m = t.nodes.size(), ans = 0;
    vector<int> open(m);
    for (int i = m - 1; i >= 0; i--) {
        if (t.marked[i]) {
            ans += open[i];
            open[i] = 1;
        } else if (open[i] >= 2) ++ans, open[i] = 0;
        if (t.fa[i] >= 0) open[t.fa[i]] += open[i];
    }
    return ans;
}
```

**例：** 星形三片叶子关键，删中心一个点即可；若中心和某叶子都关键，则无解。

##### 树上题 059：多源最近终端及归属

<a id="tree100-059"></a>

**建议难度：银牌。题意与用途：** 为每个顶点找最近关键点，距离相同取编号最小者；用于树上 Voronoi 分区和服务点分配。

**思路：** 把所有关键点放进 Dijkstra，优先级按 {距离,源编号,当前点}。松弛时同时比较距离和源编号，零权连通块也能统一归属。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 非负边权，只需建 e；nearestOwner(keys) 返回每点 {距离,源编号}；空集返回 {2^60,0}。

**复杂度与边界：** O(n log n+k log n) 时间、O(n+k) 空间；有效路径长度须小于 2^60。

```c++
vector<pair<ll, int>> nearestOwner(const vector<int> &keys) {
    const ll BIG = 1LL << 60;
    vector<pair<ll, int>> d(n + 1, {BIG, 0});
    priority_queue<tuple<ll, int, int>, vector<tuple<ll, int, int>>, greater<tuple<ll, int, int>>> q;
    for (int u : keys)
        if (d[u].first) {
            d[u] = {0, u};
            q.push({0, u, u});
        }
    while (!q.empty()) {
        auto [du, s, u] = q.top();
        q.pop();
        if (d[u] != make_pair(du, s)) continue;
        for (auto [v, w] : e[u]) {
            pair<ll, int> z{du + w, s};
            if (z < d[v]) d[v] = z, q.push({z.first, s, v});
        }
    }
    return d;
}
```

**例：** 5 点链，关键点 1、5：点 3 等距时归属 1，点 4 归属 5。

##### 树上题 060：包含全部关键点的连通子树数

<a id="tree100-060"></a>

**建议难度：金牌。题意与用途：** 统计包含所有给定关键点的连通顶点集数；用于强制骨架与可选分支计数。

**思路：** 以任一关键点为根。含关键点的孩子分支必须选，不含关键点的分支可选可不选；乘法 DP 即可。空关键集时统计全部非空连通集，以其唯一最高点分类求和。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** containKeys(keys)，MOD≥2；非空 keys 会调用 rootTree(keys[0]) 改公共根，之后如需 HLD 等必须重建。空 keys 使用现有 rootTree 状态。

**复杂度与边界：** O(n+k) 时间、O(n) 空间。空集约束不计空顶点集。

```c++
ll containKeys(const vector<int> &keys) {
    if (!keys.empty()) rootTree(keys[0]);
    vector<int> need(n + 1);
    vector<ll> f(n + 1, 1);
    for (int u : keys)
        need[u] = 1;
    ll all = 0;
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        all = (all + f[u]) % MOD;
        if (fa[u]) {
            f[fa[u]] = (i128)f[fa[u]] * (f[u] + !need[u]) % MOD;
            need[fa[u]] |= need[u];
        }
    }
    return keys.empty() ? all : f[ord[0]];
}
```

**例：** 3 点链强制两端时只有全树 1 种；强制中间点时有 4 种；无强制点时有 6 种。

##### 树上题 061：有符号边权下距离恰为 K 的点对

<a id="tree100-061"></a>

**建议难度：银牌。题意与用途：** 树边权可负，统计路径权和恰为 K 的不同点无序对；用于不能按距离剪枝的路径计数。

**思路：** 点分治枚举路径经过的最高分治重心。各分支距离先与此前分支的频次表配对，再合入，避免同分支路径重复统计。核心分治只按点数，仍可用于负权；不用原 exists 的非负剪枝。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)、[分支距离收集](#centroid-decomposition)。

**初始化与接口：** 建 e 后 exactPairs(K)，不要求 rootTree；调用会重置 dead。

**复杂度与边界：** O(n log² n) 时间、O(n) 空间，使用 map。所有路径长度、K−d 须在 ll 内。

```c++
ll exactPairs(ll K) {
    ll ans = 0;
    runCd([&](int c) {
        map<ll, ll> cnt{{0, 1}};
        for (auto [v, w] : e[c])
            if (!dead[v]) {
                auto a = distances(v, c, w);
                for (ll d : a) {
                    auto it = cnt.find(K - d);
                    if (it != cnt.end()) ans += it->second;
                }
                for (ll d : a)
                    ++cnt[d];
            }
    });
    return ans;
}
```

**例：** 链边权 −2、5，K=3 时只有两端这一对；单点不计。

##### 树上题 062：权和恰为 K 的最少边路径

<a id="tree100-062"></a>

**建议难度：金牌。题意与用途：** 在不同顶点间找权和为 K、边数最少的路径；用于 Race 类路径约束。

**思路：** 重心每分支收集 {距离,边数}，频次表改为每种距离对应的最少边数。先查询互补距离后合并，保留最小值。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)。

**初始化与接口：** 建 e 后 minEdgesK(K)，无解返回 −1；支持负边且不做距离剪枝。

**复杂度与边界：** O(n log² n) 时间、O(n) 空间；K=0 也要求至少一条边。

```c++
int minEdgesK(ll K) {
    int ans = n + 1;
    runCd([&](int c) {
        map<ll, int> best{{0, 0}};
        for (auto [v, w] : e[c])
            if (!dead[v]) {
                vector<tuple<int, int, ll, int>> q{{v, c, w, 1}};
                for (int i = 0; i < (int)q.size(); i++) {
                    auto [u, p, d, h] = q[i];
                    auto it = best.find(K - d);
                    if (it != best.end()) ans = min(ans, h + it->second);
                    for (auto [x, z] : e[u])
                        if (x != p && !dead[x]) q.push_back({x, u, d + z, h + 1});
                }
                for (auto [u, p, d, h] : q) {
                    auto it = best.find(d);
                    if (it == best.end()) best[d] = h;
                    else it->second = min(it->second, h);
                }
            }
    });
    return ans == n + 1 ? -1 : ans;
}
```

**例：** 链边权 2、3、5，K=5 时直接取最后一条边，答案 1。

##### 树上题 063：距离模 M 为零的点对数

<a id="tree100-063"></a>

**建议难度：银牌。题意与用途：** 统计路径权和可被 M 整除的不同点无序对；用于路径余数与概率题。

**思路：** 点分治维护已处理分支的距离余数频次，查询互补余数。只清空本次触碰的余数，避免每个重心都 O(M) 初始化。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)、[分支距离收集](#centroid-decomposition)。

**初始化与接口：** M≥1；建 e 后 divisiblePairs(M)。可有负边，余数归一化。

**复杂度与边界：** O(n log n+M) 时间、O(n+M) 空间；M 大于可用内存时改用 map，时间变 O(n log² n)。

```c++
ll divisiblePairs(int M) {
    vector<ll> cnt(M);
    ll ans = 0;
    runCd([&](int c) {
        vector<int> used{0};
        cnt[0] = 1;
        for (auto [v, w] : e[c])
            if (!dead[v]) {
                auto a = distances(v, c, w);
                for (ll d : a) {
                    int r = (d % M + M) % M;
                    ans += cnt[r ? M - r : 0];
                }
                for (ll d : a) {
                    int r = (d % M + M) % M;
                    if (!cnt[r]) used.push_back(r);
                    ++cnt[r];
                }
            }
        for (int r : used)
            cnt[r] = 0;
    });
    return ans;
}
```

**例：** 3 点单位边链，M=2 仅两端一对；M=1 时全部 3 对。

##### 树上题 064：静态半径内点数：分支容斥

<a id="tree100-064"></a>

**建议难度：金牌。题意与用途：** 对任意顶点 u 和半径 R，统计距离≤R 的顶点数，包含 u；用于树上球查询。

**思路：** 记录每点到各级重心的距离和所属分支。查询某重心时统计整个分量中距离≤R−d 的点，再减掉与 u 同分支的点。每对点只在分治 LCA 被保留一次。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)。

**初始化与接口：** 非负边权；建 e 后 buildRadius(); radiusCount(u,R)。ca[u] 的条目为 {重心,全局分支号,距离}，重心自身分支为 −1。

**复杂度与边界：** 预处理 O(n log² n)，每次 O(log² n)，空间 O(n log n)。R<0 返回 0。64–68 题共用此数据，无需重复构建。

```c++
vector<vector<tuple<int, int, ll>>> ca;
vector<vector<ll>> cdAll, cdSub;
void buildRadius() {
    ca.assign(n + 1, {});
    cdAll.assign(n + 1, {});
    cdSub.clear();
    runCd([&](int c) {
        ca[c].push_back({c, -1, 0});
        cdAll[c].push_back(0);
        for (auto [v, w] : e[c])
            if (!dead[v]) {
                int b = cdSub.size();
                cdSub.push_back({});
                vector<tuple<int, int, ll>> q{{v, c, w}};
                for (int i = 0; i < (int)q.size(); i++) {
                    auto [u, p, d] = q[i];
                    ca[u].push_back({c, b, d});
                    cdAll[c].push_back(d);
                    cdSub[b].push_back(d);
                    for (auto [x, z] : e[u])
                        if (x != p && !dead[x]) q.push_back({x, u, d + z});
                }
                sort(cdSub[b].begin(), cdSub[b].end());
            }
        sort(cdAll[c].begin(), cdAll[c].end());
    });
}
ll radiusCount(int u, ll R) {
    if (R < 0) return 0;
    ll ans = 0;
    for (auto [c, b, d] : ca[u])
        if (d <= R) {
            ans += upper_bound(cdAll[c].begin(), cdAll[c].end(), R - d) - cdAll[c].begin();
            if (b >= 0) ans -= upper_bound(cdSub[b].begin(), cdSub[b].end(), R - d) - cdSub[b].begin();
        }
    return ans;
}
```

**例：** 5 点链，点 3 半径 1 内有 3 个点，半径 0 内仅自己。

##### 树上题 065：动态标记点的半径计数

<a id="tree100-065"></a>

**建议难度：金牌。题意与用途：** 支持激活、取消标记，查询某点半径 R 内的标记数；用于动态服务范围。

**思路：** 把第 064 题重心及分支的静态距离数组当作离散坐标，分别配一棵 BIT。修改沿重心链增减频次，查询仍做整块减同分支容斥。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)、[百题共用 BIT](#tree100-bit)、[第 064 题](#tree100-064)。

**初始化与接口：** buildRadiusActive() 清空标记；radiusSet(u,on)；activeCount(u,R)。边权非负。

**复杂度与边界：** 预处理 O(n log² n)，修改/查询 O(log² n)，空间 O(n log n)。重复设置同状态无作用。

```c++
vector<vector<ll>> cbAll, cbSub;
vector<char> ron;
void buildRadiusActive() {
    buildRadius();
    cbAll.resize(n + 1);
    cbSub.resize(cdSub.size());
    ron.assign(n + 1, 0);
    for (int c = 1; c <= n; c++)
        cbAll[c].assign(cdAll[c].size() + 1, 0);
    for (int b = 0; b < (int)cdSub.size(); b++)
        cbSub[b].assign(cdSub[b].size() + 1, 0);
}
void radiusSet(int u, bool on) {
    if (ron[u] == on) return;
    int x = on ? 1 : -1;
    ron[u] = on;
    for (auto [c, b, d] : ca[u]) {
        bitAdd(cbAll[c], lower_bound(cdAll[c].begin(), cdAll[c].end(), d) - cdAll[c].begin() + 1, x);
        if (b >= 0) bitAdd(cbSub[b], lower_bound(cdSub[b].begin(), cdSub[b].end(), d) - cdSub[b].begin() + 1, x);
    }
}
ll activeCount(int u, ll R) {
    if (R < 0) return 0;
    ll ans = 0;
    for (auto [c, b, d] : ca[u])
        if (d <= R) {
            ans += bitSum(cbAll[c], upper_bound(cdAll[c].begin(), cdAll[c].end(), R - d) - cdAll[c].begin());
            if (b >= 0) ans -= bitSum(cbSub[b], upper_bound(cdSub[b].begin(), cdSub[b].end(), R - d) - cdSub[b].begin());
        }
    return ans;
}
```

**例：** 5 点链标记 1、3、5，点 3 半径 1 内有 1 个，半径 2 内有 3 个。

##### 树上题 066：动态标记点的距离和

<a id="tree100-066"></a>

**建议难度：金牌。题意与用途：** 在线增删标记点，查询 u 到所有标记点的距离和；用于树上动态中位目标函数。

**思路：** 每级重心维护标记数量与到重心的距离和；当前点贡献为 sum+cnt·d，再减同分支的相同量。无需 BIT，沿链常数工作。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)、[第 064 题](#tree100-064)。

**初始化与接口：** 非负边权；buildDistanceActive(); distanceSet(u,on); distanceActive(u)。

**复杂度与边界：** 采用第 064 题构建时预处理 O(n log² n)，修改/查询 O(log n)，空间 O(n log n)；只需本题时可省掉距离数组排序。

```c++
vector<ll> cntAll, sumAll, cntSub, sumSub;
vector<char> don;
void buildDistanceActive() {
    buildRadius();
    cntAll.assign(n + 1, 0);
    sumAll = cntAll;
    cntSub.assign(cdSub.size(), 0);
    sumSub = cntSub;
    don.assign(n + 1, 0);
}
void distanceSet(int u, bool on) {
    if (don[u] == on) return;
    int x = on ? 1 : -1;
    don[u] = on;
    for (auto [c, b, d] : ca[u]) {
        cntAll[c] += x;
        sumAll[c] += x * d;
        if (b >= 0) cntSub[b] += x, sumSub[b] += x * d;
    }
}
ll distanceActive(int u) {
    ll ans = 0;
    for (auto [c, b, d] : ca[u]) {
        ans += sumAll[c] + cntAll[c] * d;
        if (b >= 0) ans -= sumSub[b] + cntSub[b] * d;
    }
    return ans;
}
```

**例：** 5 点链标记 1、5，点 2 到它们的距离和为 1+3=4。

##### 树上题 067：动态第 K 近标记点

<a id="tree100-067"></a>

**建议难度：金牌。题意与用途：** 在线增删标记点，查询到 u 的第 K 小距离，重复距离按点数计；用于动态邻近排名。

**思路：** 半径计数对 R 单调。先检查标记总数，再在 [0,全树直径] 二分最小使计数≥K 的半径。复用半径计数而不额外引入复杂值域树。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)、[百题共用 BIT](#tree100-bit)、[树的度量](#tree-metrics)、[第 064 题](#tree100-064)、[第 065 题](#tree100-065)。

**初始化与接口：** rootTree(r); buildNearestOrder(); 用 radiusSet 修改；kthNearest(u,K)，不足 K 个或 K≤0 返回 −1。

**复杂度与边界：** 预处理 O(n log² n)，查询 O(log(D+1) log² n)，修改 O(log² n)，空间 O(n log n)；D 是整数非负直径。

```c++
ll radiusLimit;
void buildNearestOrder() {
    buildRadiusActive();
    radiusLimit = metrics().diam;
}
ll kthNearest(int u, ll k) {
    if (k <= 0 || activeCount(u, radiusLimit) < k) return -1;
    ll l = 0, r = radiusLimit;
    while (l < r) {
        ll m = l + (r - l) / 2;
        if (activeCount(u, m) >= k) r = m;
        else l = m + 1;
    }
    return l;
}
```

**例：** 5 点链标记 1、3、5，点 3 的第 1/2/3 近距离为 0/2/2。

##### 树上题 068：动态标记集合的点对距离和

<a id="tree100-068"></a>

**建议难度：金牌。题意与用途：** 在线增删标记点，每次求集合内不同点无序点对距离和；用于动态群体离散程度。

**思路：** 插入 u 时新增贡献恰为它到原集合的距离和；删除时减去它到当前集合的距离和（自身距离为 0）。先查询，再修改第 066 题状态。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)、[第 064 题](#tree100-064)、[第 066 题](#tree100-066)。

**初始化与接口：** buildPairActive()；pairSet(u,on) 返回当前总和；不要再绕过 pairSet 调 distanceSet，否则 pairTotal 会失同步。

**复杂度与边界：** 预处理 O(n log² n)，每次 O(log n)，空间 O(n log n)，边权非负。

```c++
ll pairTotal = 0;
void buildPairActive() {
    buildDistanceActive();
    pairTotal = 0;
}
ll pairSet(int u, bool on) {
    if (don[u] != on) {
        ll x = distanceActive(u);
        pairTotal += on ? x : -x;
        distanceSet(u, on);
    }
    return pairTotal;
}
```

**例：** 5 点链依次标记 1、3、5，总和为 0、2、8；取消 3 后为 4。

##### 树上题 069：动态设施费用加距离最小值

<a id="tree100-069"></a>

**建议难度：金牌。题意与用途：** 每个启用设施 v 有费用 cost[v]，支持启停与改费，查询 min(cost[v]+dist(u,v))；用于带固定服务费的最近点。

**思路：** 沿重心链维护 multiset(cost[v]+dist(v,c))，查询加 dist(u,c)。每项由三角不等式给出上界，分治 LCA 处恰相等，取最小即可；负费用不影响此论证。

**所需模板：** [公共全局与有根遍历](#tree-base)、[点分治核心](#centroid-decomposition)、[动态点分治](#dynamic-centroid-decomposition)。

**初始化与接口：** 非负边权；buildCost(); costSet(v,on,cost)；minCost(u)。费用可负，无设施返回 LLONG_MAX。

**复杂度与边界：** 预处理 O(n log n)，修改 O(log² n)，查询 O(log n)，空间 O(n log n)。合法 cost+路径距离及查询中间和必须不溢出且不等于 LLONG_MAX。

```c++
vector<multiset<ll>> costBag;
vector<ll> fee;
vector<char> con;
void buildCost() {
    buildDcd();
    costBag.assign(n + 1, {});
    fee.assign(n + 1, 0);
    con.assign(n + 1, 0);
}
void costSet(int u, bool on, ll x = 0) {
    for (auto [c, d] : anc[u]) {
        if (con[u]) costBag[c].erase(costBag[c].find(fee[u] + d));
        if (on) costBag[c].insert(x + d);
    }
    con[u] = on;
    fee[u] = x;
}
ll minCost(int u) {
    ll ans = LLONG_MAX;
    for (auto [c, d] : anc[u])
        if (!costBag[c].empty()) ans = min(ans, d + *costBag[c].begin());
    return ans;
}
```

**例：** 5 点链，设施 1 费用 7、设施 5 费用 −2，点 3 最优费用为 0。

##### 树上题 070：依次删点后的最大分量直径

<a id="tree100-070"></a>

**建议难度：金牌。题意与用途：** 给全部顶点的删除排列，每次删点及关联边后，求剩余各分量直径的最大值；用于离线动态连通与直径合并。

**思路：** 倒序激活点，用并查集合并相邻活跃分量。每个分量只保留一对直径端点，合并后直径必在原两对端点中，枚举跨组四对。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); deleteDiam(order)，order 为 0-based 全排列，返回每次删除后的答案，空森林为 0。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；距离始终在原树上查询，连通分量内唯一通路未变。

```c++
vector<ll> deleteDiam(const vector<int> &order) {
    vector<int> p(n + 1), s(n + 1, 1), a(n + 1), b(n + 1);
    iota(p.begin(), p.end(), 0);
    a = b = p;
    vector<char> on(n + 1);
    vector<ll> d(n + 1), ans(n);
    ll best = 0;
    auto find = [&](int u) {
        while (u != p[u])
            u = p[u] = p[p[u]];
        return u;
    };
    for (int i = n - 1; i >= 0; i--) {
        ans[i] = best;
        int u = order[i];
        on[u] = 1;
        for (auto [v, w] : e[u])
            if (on[v]) {
                int x = find(u), y = find(v);
                if (x == y) continue;
                if (s[x] < s[y]) swap(x, y);
                int A = a[x], B = b[x];
                ll D = d[x];
                if (d[y] > D) A = a[y], B = b[y], D = d[y];
                for (int z : {a[x], b[x]})
                    for (int t : {a[y], b[y]})
                        if (dist(z, t) > D) D = dist(z, t), A = z, B = t;
                p[y] = x;
                s[x] += s[y];
                a[x] = A;
                b[x] = B;
                d[x] = D;
                best = max(best, D);
            }
    }
    return ans;
}
```

**例：** 4 点链按 2、1、3、4 删除，最大直径依次为 1、1、0、0。

##### 树上题 071：静态路径第 K 小

<a id="tree100-071"></a>

**建议难度：银牌。题意与用途：** 点有静态权值，多次查询路径上的第 K 小值；用于树上的顺序统计。

**思路：** 每点版本从父亲版本插入自身权值，维护根路径可持久化权值线段树。路径多重集为 rt[u]+rt[v]−rt[lca]−rt[fa[lca]]，同时在四个根上下降。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); buildOrder(a); pathKth(u,v,K)，K 从 1 开始且不超过路径点数。

**复杂度与边界：** 预处理 O(n log n)，查询 O(log n)，空间 O(n log n)。节点带 sum 供下一题复用；点权可负，权和不溢出。

```c++
struct OrderNode {
    int l = 0, r = 0, c = 0;
    ll s = 0;
};
vector<OrderNode> ot;
vector<int> rt;
vector<ll> val;
int orderInsert(int old, int l, int r, int x) {
    int p = ot.size();
    ot.push_back(ot[old]);
    ++ot[p].c;
    ot[p].s += val[x];
    if (l < r) {
        int m = (l + r) / 2;
        if (x <= m) ot[p].l = orderInsert(ot[p].l, l, m, x);
        else ot[p].r = orderInsert(ot[p].r, m + 1, r, x);
    }
    return p;
}
void buildOrder(const vector<ll> &a) {
    val.assign(a.begin() + 1, a.end());
    sort(val.begin(), val.end());
    val.erase(unique(val.begin(), val.end()), val.end());
    ot.assign(1, {});
    rt.assign(n + 1, 0);
    for (int u : ord)
        rt[u] = orderInsert(rt[fa[u]], 0, (int)val.size() - 1, lower_bound(val.begin(), val.end(), a[u]) - val.begin());
}
array<int, 4> pathRoots(int u, int v) {
    int p = lca(u, v);
    return {rt[u], rt[v], rt[p], rt[fa[p]]};
}
ll pathKth(int u, int v, int k) {
    auto p = pathRoots(u, v);
    int l = 0, r = val.size() - 1;
    while (l < r) {
        int m = (l + r) / 2, c = 0;
        for (int i = 0; i < 4; i++)
            c += (i < 2 ? 1 : -1) * ot[ot[p[i]].l].c;
        bool left = k <= c;
        if (left) r = m;
        else l = m + 1, k -= c;
        for (int &x : p)
            x = left ? ot[x].l : ot[x].r;
    }
    return val[l];
}
```

**例：** 3 点链点权 5、2、5，路径第 1 小为 2，第 2 小为 5。

##### 树上题 072：路径最小 K 个权值之和

<a id="tree100-072"></a>

**建议难度：银牌。题意与用途：** 多次查询路径上最小 K 个点权之和，重复值按出现次数计算；用于预算分配与路径截断和。

**思路：** 沿第 071 题四根线段树下降。当 K 超过左子树计数时，把整个左侧权和计入并去右侧；最终叶子再取 K 份该权值。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[第 071 题](#tree100-071)。

**初始化与接口：** 按第 071 题 buildOrder(a)；pathSmallSum(u,v,K)，0≤K≤路径点数。

**复杂度与边界：** 查询 O(log n)，额外 O(1) 空间；与第 071 题共享 O(n log n) 预处理与节点。

```c++
ll pathSmallSum(int u, int v, int k) {
    auto p = pathRoots(u, v);
    int l = 0, r = val.size() - 1;
    ll ans = 0;
    while (l < r) {
        int m = (l + r) / 2, c = 0;
        ll s = 0;
        for (int i = 0; i < 4; i++) {
            auto t = ot[ot[p[i]].l];
            c += (i < 2 ? 1 : -1) * t.c;
            s += (i < 2 ? 1 : -1) * t.s;
        }
        bool left = k <= c;
        if (left) r = m;
        else l = m + 1, k -= c, ans += s;
        for (int &x : p)
            x = left ? ot[x].l : ot[x].r;
    }
    return ans + k * val[l];
}
```

**例：** 路径权值 −3、5、2，最小两个之和 −1，K=0 时为 0。

##### 树上题 073：路径上与 X 异或最大的点值

<a id="tree100-073"></a>

**建议难度：银牌。题意与用途：** 点值为非负整数，求路径上某一个点值与 X 异或的最大值；用于树上可持久化 Trie。

**思路：** 根路径建立可持久化 01 Trie，沿四根容斥判断某一分支有没有点，优先走与 X 当前位相反的分支。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); buildXorTrie(a,B)，1≤B≤63，所有点值和查询 X 均小于 2^B；pathXorMax(u,v,X)。

**复杂度与边界：** 预处理 O(nB)，查询 O(log n+B)，空间 O(nB)；返回异或结果，不是点号。

```c++
vector<array<int, 3>> xt; // 两个儿子、计数
vector<int> xr;
int xb;
void buildXorTrie(const vector<ull> &a, int B) {
    xb = B;
    xt.assign(1, {});
    xr.assign(n + 1, 0);
    for (int u : ord) {
        int old = xr[fa[u]], p = xt.size();
        xt.push_back(xt[old]);
        xr[u] = p;
        ++xt[p][2];
        for (int b = B - 1; b >= 0; b--) {
            int c = (a[u] >> b) & 1;
            old = xt[old][c];
            int q = xt.size();
            xt.push_back(xt[old]);
            xt[p][c] = q;
            p = q;
            ++xt[p][2];
        }
    }
}
ull pathXorMax(int u, int v, ull x) {
    int w = lca(u, v);
    array<int, 4> p{xr[u], xr[v], xr[w], xr[fa[w]]};
    ull ans = 0;
    for (int b = xb - 1; b >= 0; b--) {
        int c = ((x >> b) & 1) ^ 1, k = 0;
        for (int i = 0; i < 4; i++)
            k += (i < 2 ? 1 : -1) * xt[xt[p[i]][c]][2];
        if (k) ans |= 1ULL << b;
        else c ^= 1;
        for (int &r : p)
            r = xt[r][c];
    }
    return ans;
}
```

**例：** 路径值 1、2、7，X=3 时最大异或为 7 xor 3=4。

##### 树上题 074：路径点值任意子集最大异或

<a id="tree100-074"></a>

**建议难度：金牌。题意与用途：** 可从路径点值中任选一些数异或，求最大结果；用于带位置线性基。

**思路：** 根路径线性基每个向量保存最深来源位置，插入时优先保留更深位置。查询过滤深度小于 LCA 的向量，将 u、v 两个前缀基合并；重复 LCA 不影响线性张成。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); buildPathBasis(a); pathBasisMax(u,v)。a 为 ull；允许空子集。

**复杂度与边界：** B=64 时预处理 O(nB)、查询 O(log n+B²)、空间 O(nB)；普通 int 下约 768n 字节主体，int 宏下约 1024n 字节，可按值域减 B。

```c++
constexpr int BB = 64;
vector<array<ull, BB>> basis;
vector<array<int, BB>> where;
void buildPathBasis(const vector<ull> &a) {
    basis.assign(n + 1, {});
    where.assign(n + 1, {});
    where[0].fill(-1);
    for (int u : ord) {
        basis[u] = basis[fa[u]];
        where[u] = where[fa[u]];
        ull x = a[u];
        int d = dep[u];
        for (int b = BB - 1; b >= 0; b--)
            if ((x >> b) & 1) {
                if (!basis[u][b]) {
                    basis[u][b] = x;
                    where[u][b] = d;
                    break;
                }
                if (where[u][b] < d) swap(where[u][b], d), swap(basis[u][b], x);
                x ^= basis[u][b];
            }
    }
}
ull pathBasisMax(int u, int v) {
    int d = dep[lca(u, v)];
    array<ull, BB> b{};
    for (int t : {u, v})
        for (int i = BB - 1; i >= 0; i--)
            if (where[t][i] >= d) {
                ull x = basis[t][i];
                for (int j = BB - 1; j >= 0; j--)
                    if ((x >> j) & 1) {
                        if (!b[j]) {
                            b[j] = x;
                            break;
                        }
                        x ^= b[j];
                    }
            }
    ull ans = 0;
    for (int i = BB - 1; i >= 0; i--)
        ans = max(ans, ans ^ b[i]);
    return ans;
}
```

**例：** 路径值 1、2、4，可选全部得到 7；只查点 2 得 2。

##### 树上题 075：有向路径矩阵乘积与单点赋值

<a id="tree100-075"></a>

**建议难度：金牌。题意与用途：** 每点有 2×2 矩阵，在线赋值并查询沿 u→v 的矩阵连乘；用于路径状态转移，矩阵不可交换。

**思路：** 线段树同时存正向和反向乘积。用共用有向路径分段按实际 u→v 次序合并，段内方向决定选哪份乘积。迭代线段树查询也分别维护左右累加器。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[有向路径分段](#tree100-direction)。

**初始化与接口：** rootTree(r); buildHld(); buildMatrix(a)；matrixSet(u,A)；matrixPath(u,v)。矩阵为 array<ll,4>，按行存放；元素先归一化到 [0,MOD)。

**复杂度与边界：** 预处理 O(n)，赋值 O(log n)，查询 O(log² n)，空间 O(n)；MOD≥2，可合数，乘法 i128。

```c++
using Mat = array<ll, 4>;
Mat unitMat() {
    return {1, 0, 0, 1};
}
Mat mulMat(const Mat &a, const Mat &b) {
    Mat c{};
    for (int i = 0; i < 2; i++)
        for (int j = 0; j < 2; j++)
            for (int k = 0; k < 2; k++)
                c[i * 2 + j] = (c[i * 2 + j] + (i128)a[i * 2 + k] * b[k * 2 + j]) % MOD;
    return c;
}
using BothMat = array<Mat, 2>;
BothMat joinMat(const BothMat &a, const BothMat &b) {
    return {mulMat(a[0], b[0]), mulMat(b[1], a[1])};
}
vector<BothMat> ms;
int mb;
void buildMatrix(const vector<Mat> &a) {
    mb = 1;
    while (mb < n)
        mb *= 2;
    ms.assign(2 * mb, {unitMat(), unitMat()});
    for (int u = 1; u <= n; u++)
        ms[mb + id[u] - 1] = {a[u], a[u]};
    for (int p = mb - 1; p; p--)
        ms[p] = joinMat(ms[p * 2], ms[p * 2 + 1]);
}
void matrixSet(int u, Mat a) {
    int p = mb + id[u] - 1;
    ms[p] = {a, a};
    for (p /= 2; p; p /= 2)
        ms[p] = joinMat(ms[p * 2], ms[p * 2 + 1]);
}
BothMat matrixRange(int l, int r) {
    BothMat a{unitMat(), unitMat()}, b = a;
    for (l += mb - 1, r += mb; l < r; l /= 2, r /= 2) {
        if (l & 1) a = joinMat(a, ms[l++]);
        if (r & 1) b = joinMat(ms[--r], b);
    }
    return joinMat(a, b);
}
Mat matrixPath(int u, int v) {
    Mat a = unitMat();
    for (auto [l, r, rev] : directedPath(u, v))
        a = mulMat(a, matrixRange(l, r)[rev]);
    return a;
}
```

**例：** 两点矩阵 A=[[1,1],[0,1]]、B=[[1,0],[1,1]]，A·B=[[2,1],[1,1]]，反向 B·A=[[1,1],[1,2]]。

##### 树上题 076：路径非空最大连续子段和

<a id="tree100-076"></a>

**建议难度：金牌。题意与用途：** 点权可负，支持单点赋值，查询一条路径上连续非空子段的最大点权和；用于路径收益最优区间。

**思路：** 维护 sum、最大前缀、最大后缀、最大子段。反转只交换前后缀；按有向分段合并。空信息专门用 len=0 表示，避免全负值被错误取成 0。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[有向路径分段](#tree100-direction)。

**初始化与接口：** rootTree(r); buildHld(); buildBest(a); bestSet(u,x); pathBest(u,v)。

**复杂度与边界：** 预处理 O(n)，修改 O(log n)，查询 O(log² n)，空间 O(n)。所有合并和须在 ll 内。

```c++
struct BestInfo {
    ll sum = 0, pre = 0, suf = 0, best = 0;
    int len = 0;
};
BestInfo joinBest(BestInfo a, BestInfo b) {
    if (!a.len) return b;
    if (!b.len) return a;
    return {a.sum + b.sum, max(a.pre, a.sum + b.pre), max(b.suf, b.sum + a.suf), max({a.best, b.best, a.suf + b.pre}), a.len + b.len};
}
vector<BestInfo> bs;
int bn;
void buildBest(const vector<ll> &a) {
    bn = 1;
    while (bn < n)
        bn *= 2;
    bs.assign(2 * bn, {});
    for (int u = 1; u <= n; u++) {
        ll x = a[u];
        bs[bn + id[u] - 1] = {x, x, x, x, 1};
    }
    for (int p = bn - 1; p; p--)
        bs[p] = joinBest(bs[p * 2], bs[p * 2 + 1]);
}
void bestSet(int u, ll x) {
    int p = bn + id[u] - 1;
    bs[p] = {x, x, x, x, 1};
    for (p /= 2; p; p /= 2)
        bs[p] = joinBest(bs[p * 2], bs[p * 2 + 1]);
}
BestInfo bestRange(int l, int r) {
    BestInfo a, b;
    for (l += bn - 1, r += bn; l < r; l /= 2, r /= 2) {
        if (l & 1) a = joinBest(a, bs[l++]);
        if (r & 1) b = joinBest(bs[--r], b);
    }
    return joinBest(a, b);
}
ll pathBest(int u, int v) {
    BestInfo a;
    for (auto [l, r, rev] : directedPath(u, v)) {
        auto b = bestRange(l, r);
        if (rev) swap(b.pre, b.suf);
        a = joinBest(a, b);
    }
    return a.best;
}
```

**例：** 链点权 −3、5、−2、4，最大子段和为 7；全负链应返回最大的单个值。

##### 树上题 077：路径染色与颜色段数量

<a id="tree100-077"></a>

**建议难度：金牌。题意与用途：** 支持把整条路径染成一种颜色，并查询路径包含多少个连续同色段；用于方向敏感的懒标记维护。

**思路：** 线段树保存左端颜色、右端颜色和段数。相接颜色相等时段数减一；整段染色后段数为 1。查询反向交换左右色，再按有向分段合并。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[有向路径分段](#tree100-direction)。

**初始化与接口：** rootTree(r); buildHld(); buildPaint(color); paintPath(u,v,c); colorRuns(u,v)。颜色可为任意 ll，单独 has 标记避免哨兵冲突。

**复杂度与边界：** 预处理 O(n)，每次修改/查询 O(log² n)，空间 O(n)。

```c++
struct ColorInfo {
    ll l = 0, r = 0;
    int cnt = 0;
};
ColorInfo joinColor(ColorInfo a, ColorInfo b) {
    if (!a.cnt) return b;
    if (!b.cnt) return a;
    return {a.l, b.r, a.cnt + b.cnt - (a.r == b.l)};
}
vector<ColorInfo> cs;
vector<ll> tagColor;
vector<char> hasColor;
void putColor(int p, ll c) {
    cs[p] = {c, c, 1};
    tagColor[p] = c;
    hasColor[p] = 1;
}
void pushColor(int p) {
    if (hasColor[p]) {
        putColor(p * 2, tagColor[p]);
        putColor(p * 2 + 1, tagColor[p]);
        hasColor[p] = 0;
    }
}
void paintBuild(int p, int l, int r, const vector<ll> &a) {
    if (l == r) {
        cs[p] = {a[rid[l]], a[rid[l]], 1};
        return;
    }
    int m = (l + r) / 2;
    paintBuild(p * 2, l, m, a);
    paintBuild(p * 2 + 1, m + 1, r, a);
    cs[p] = joinColor(cs[p * 2], cs[p * 2 + 1]);
}
void buildPaint(const vector<ll> &a) {
    cs.assign(4 * n + 4, {});
    tagColor.assign(4 * n + 4, 0);
    hasColor.assign(4 * n + 4, 0);
    paintBuild(1, 1, n, a);
}
void paintRange(int p, int l, int r, int L, int R, ll c) {
    if (L <= l && r <= R) {
        putColor(p, c);
        return;
    }
    pushColor(p);
    int m = (l + r) / 2;
    if (L <= m) paintRange(p * 2, l, m, L, R, c);
    if (R > m) paintRange(p * 2 + 1, m + 1, r, L, R, c);
    cs[p] = joinColor(cs[p * 2], cs[p * 2 + 1]);
}
ColorInfo queryColor(int p, int l, int r, int L, int R) {
    if (L <= l && r <= R) return cs[p];
    pushColor(p);
    int m = (l + r) / 2;
    ColorInfo a, b;
    if (L <= m) a = queryColor(p * 2, l, m, L, R);
    if (R > m) b = queryColor(p * 2 + 1, m + 1, r, L, R);
    return joinColor(a, b);
}
void paintPath(int u, int v, ll c) {
    path(u, v, [&](int l, int r) {
        paintRange(1, 1, n, l, r, c);
    });
}
int colorRuns(int u, int v) {
    ColorInfo a;
    for (auto [l, r, rev] : directedPath(u, v)) {
        auto b = queryColor(1, 1, n, l, r);
        if (rev) swap(b.l, b.r);
        a = joinColor(a, b);
    }
    return a.cnt;
}
```

**例：** 链颜色 1、2、2、3 原有 3 段，把 2–4 染成 1 后整条链只剩 1 段。

##### 树上题 078：改边权后的全树点对距离和

<a id="tree100-078"></a>

**建议难度：银牌。题意与用途：** 固定树拓扑，单次赋值某条边权后，立即报告全树不同顶点无序点对距离和；用于边贡献动态维护。

**思路：** 边贡献系数恒为 `siz[u] * (n-siz[u])`，只与拓扑有关。每次赋值按差值乘系数修正总答案，不需要更新每点距离。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); buildEdgeTotal(); edgeTotalSet(u,w)，u 指父边的孩子且 fa[u]≠0。维护副本 ew；不改变 e/pw/dis，其他距离模板仍对应原权。

**复杂度与边界：** 预处理 O(n)，修改 O(1)，空间 O(n)；可负边，乘积不溢出。

```c++
vector<ll> ew;
ll edgeTotal;
void buildEdgeTotal() {
    ew = pw;
    edgeTotal = 0;
    for (int u = 1; u <= n; u++)
        if (fa[u]) edgeTotal += ew[u] * siz[u] * (n - siz[u]);
}
ll edgeTotalSet(int u, ll w) {
    edgeTotal += (w - ew[u]) * siz[u] * (n - siz[u]);
    ew[u] = w;
    return edgeTotal;
}
```

**例：** 3 点单位链初始点对距离和 4，将 1–2 改为 3 后变为 8。

##### 树上题 079：点赋值与路径 GCD

<a id="tree100-079"></a>

**建议难度：银牌。题意与用途：** 支持修改非负点权，查询路径全部点权的最大公约数；用于路径整除约束。

**思路：** GCD 为可交换结合运算、单位元为 0，因此普通 HLD path 分段已经足够，无需有向分段。段树存区间 GCD。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)。

**初始化与接口：** rootTree(r); buildHld(); buildGcd(a); gcdSet(u,x); pathGcd(u,v)，a,x≥0。

**复杂度与边界：** 预处理 O(n log V)，修改 O(log n log V)，查询 O(log² n log V)，空间 O(n)；把机器字 GCD 视作常数时可省 log V。

```c++
vector<ll> gs;
int gn;
void buildGcd(const vector<ll> &a) {
    gn = 1;
    while (gn < n)
        gn *= 2;
    gs.assign(2 * gn, 0);
    for (int u = 1; u <= n; u++)
        gs[gn + id[u] - 1] = a[u];
    for (int p = gn - 1; p; p--)
        gs[p] = gcd(gs[p * 2], gs[p * 2 + 1]);
}
void gcdSet(int u, ll x) {
    int p = gn + id[u] - 1;
    gs[p] = x;
    for (p /= 2; p; p /= 2)
        gs[p] = gcd(gs[p * 2], gs[p * 2 + 1]);
}
ll pathGcd(int u, int v) {
    ll ans = 0;
    path(u, v, [&](int l, int r) {
        for (l += gn - 1, r += gn; l < r; l /= 2, r /= 2) {
            if (l & 1) ans = gcd(ans, gs[l++]);
            if (r & 1) ans = gcd(ans, gs[--r]);
        }
    });
    return ans;
}
```

**例：** 链点权 12、18、24 的 GCD 为 6；把中间点改为 5 后为 1。

##### 树上题 080：边权阈值下的可达点数

<a id="tree100-080"></a>

**建议难度：铜牌。题意与用途：** 仅保留权值≤T 的边，多次询问 u 所在连通块点数；用于阈值连通与离线并查集。

**思路：** 将树边和询问分别按阈值排序，边逐条加入并查集。当前集合大小就是答案，查询不需要实际删边重建。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); thresholdReach(qs)，qs 为 pair<int,ll>{u,T}，输出按原顺序。

**复杂度与边界：** O((n+q) log(n+q)) 时间、O(n+q) 空间；允许负权和相等阈值。

```c++
vector<int> thresholdReach(const vector<pair<int, ll>> &qs) {
    vector<int> edges, idx(qs.size()), p(n + 1), s(n + 1, 1), ans(qs.size());
    for (int u = 1; u <= n; u++)
        if (fa[u]) edges.push_back(u);
    iota(p.begin(), p.end(), 0);
    iota(idx.begin(), idx.end(), 0);
    sort(edges.begin(), edges.end(), [](int u, int v) {
        return pw[u] < pw[v];
    });
    sort(idx.begin(), idx.end(), [&](int i, int j) {
        return qs[i].second < qs[j].second;
    });
    auto find = [&](int u) {
        while (u != p[u])
            u = p[u] = p[p[u]];
        return u;
    };
    int j = 0;
    for (int i : idx) {
        while (j < (int)edges.size() && pw[edges[j]] <= qs[i].second) {
            int u = edges[j++], a = find(u), b = find(fa[u]);
            if (s[a] < s[b]) swap(a, b);
            p[b] = a;
            s[a] += s[b];
        }
        ans[i] = s[find(qs[i].first)];
    }
    return ans;
}
```

**例：** 链边权 2、5，询问点 1：阈值 1/2/5 时可达点数为 1/2/3。

##### 树上题 081：带标签的确定性有根树同构

<a id="tree100-081"></a>

**建议难度：银牌。题意与用途：** 每点带标签，判断两棵有根树能否在保留标签和父子关系的情况下重编号相同；用于结构去重。

**思路：** AHU 的键从孩子类型多重集扩充为 {本点标签,排序后的孩子类型}。同一批比较共用字典，编号才能跨树比较。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); labeledIso(label)；多树间保留 labelTypes，只在开始新批次时 clear。忽略边权。

**复杂度与边界：** 累计 N 个点 O(N log(N+1)) 时间、O(N) 字典空间；确定性，不存在哈希碰撞。

```c++
map<pair<ll, vector<int>>, int> labelTypes;
int labeledIso(const vector<ll> &label) {
    vector<int> t(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        vector<int> c;
        for (auto [v, w] : e[u])
            if (fa[v] == u) c.push_back(t[v]);
        sort(c.begin(), c.end());
        t[u] = labelTypes.emplace(make_pair(label[u], c), (int)labelTypes.size() + 1).first->second;
    }
    return t[ord[0]];
}
```

**例：** 根标签 a、两孩子标签 b,c，交换两个孩子编号后仍同构；把 c 改成 b 则不同构。

##### 树上题 082：有根树自同构数

<a id="tree100-082"></a>

**建议难度：银牌。题意与用途：** 统计保持根不动、保持邻接关系的顶点置换数量；用于重复子树的对称性计数。

**思路：** 每个孩子内部有自己的自同构；相同 AHU 类型的孩子之间可任意交换，额外乘该类型孩子数的阶乘。

**所需模板：** [公共全局与有根遍历](#tree-base)、[AHU](#tree-isomorphism)。

**初始化与接口：** rootTree(r); rootedAuto()；MOD≥2，可合数，忽略点标签和边权。iso 可在新批次前清空。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；从空字典起算，沿用旧字典时复杂度与累计规模有关。

```c++
ll rootedAuto() {
    rootedIso();
    vector<ll> f(n + 1, 1), fac(n + 1, 1);
    for (int i = 1; i <= n; i++)
        fac[i] = (i128)fac[i - 1] * i % MOD;
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        vector<int> a;
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                f[u] = (i128)f[u] * f[v] % MOD;
                a.push_back(typ[v]);
            }
        sort(a.begin(), a.end());
        for (int l = 0, r; l < (int)a.size(); l = r) {
            for (r = l; r < (int)a.size() && a[r] == a[l]; r++)
                ;
            f[u] = (i128)f[u] * fac[r - l] % MOD;
        }
    }
    return f[ord[0]];
}
```

**例：** 根连 3 片叶子，自同构数 3!=6；根在 4 点链端点时为 1。

##### 树上题 083：无根树自同构数

<a id="tree100-083"></a>

**建议难度：金牌。题意与用途：** 统计无根树全部保持邻接关系的顶点置换；用于树的整体对称群大小。

**思路：** 自同构必须保留重心集合。一个重心时固定该点；两个重心时分别计算删除中央边后的半树自同构，若半树同构，还可交换两半，乘 2。

**所需模板：** [公共全局与有根遍历](#tree-base)、[AHU](#tree-isomorphism)。

**初始化与接口：** rootTree(r); unrootedAuto()，MOD≥2，忽略标签和边权。半树扫描不改变公共根，typeId 字典共用。

**复杂度与边界：** O(n log n) 时间、O(n) 空间，从空字典起算；单点答案 1。

```c++
pair<int, ll> halfAuto(int root, int ban) {
    vector<pair<int, int>> q{{root, ban}};
    vector<int> t(n + 1);
    vector<ll> f(n + 1, 1);
    for (int i = 0; i < (int)q.size(); i++) {
        auto [u, p] = q[i];
        for (auto [v, w] : e[u])
            if (v != p) q.push_back({v, u});
    }
    for (int i = (int)q.size() - 1; i >= 0; i--) {
        auto [u, p] = q[i];
        vector<int> a;
        for (auto [v, w] : e[u])
            if (v != p) {
                a.push_back(t[v]);
                f[u] = (i128)f[u] * f[v] % MOD;
            }
        sort(a.begin(), a.end());
        t[u] = typeId(a);
        int cnt = 0, last = -1;
        for (int x : a) {
            cnt = x == last ? cnt + 1 : 1;
            last = x;
            f[u] = (i128)f[u] * cnt % MOD;
        }
    }
    return {t[root], f[root]};
}
ll unrootedAuto() {
    vector<int> c;
    for (int u = 1; u <= n; u++) {
        int m = n - siz[u];
        for (auto [v, w] : e[u])
            if (fa[v] == u) m = max(m, siz[v]);
        if (m <= n / 2) c.push_back(u);
    }
    if (c.size() == 1) return halfAuto(c[0], 0).second;
    auto [x, a] = halfAuto(c[0], c[1]);
    auto [y, b] = halfAuto(c[1], c[0]);
    return (i128)a * b % MOD * (x == y ? 2 : 1) % MOD;
}
```

**例：** 4 点链可整体翻转，自同构数 2；4 点星形为 6。

##### 树上题 084：指定全部度数的标号树数

<a id="tree100-084"></a>

**建议难度：银牌。题意与用途：** 给 1..N 每个顶点的度数，统计满足条件的标号树；用于 Prüfer 多重集计数。

**思路：** Prüfer 序列中顶点 i 出现 d[i]−1 次，因此答案 (N−2)!/∏(d[i]−1)!。先检查度数合法性；N=1 单独处理。

**所需模板：** [公共模运算](<05 - 数论.md#default-mod>)、[公共阶乘与组合](<05 - 数论.md#default-comb>)。

**初始化与接口：** MOD 为质数且 N<MOD；先 initComb(N)；degreeCount(d)，d 长度 N+1。

**复杂度与边界：** 阶乘预处理 O(N+log MOD)，单次 O(N)，空间 O(N)；非法度数返回 0。

```c++
ll degreeCount(const vector<int> &d) {
    int N = (int)d.size() - 1;
    if (N == 1) return d[1] == 0;
    ll s = 0;
    for (int i = 1; i <= N; i++) {
        if (d[i] < 1 || d[i] >= N) return 0;
        s += d[i];
    }
    if (s != 2LL * N - 2) return 0;
    ll ans = fac[N - 2];
    for (int i = 1; i <= N; i++)
        ans = (i128)ans * ifac[d[i] - 1] % MOD;
    return ans;
}
```

**例：** N=4，度数 {2,2,1,1}，Prüfer 为两个内部点的两种排列，答案 2。

##### 树上题 085：指定根集合的森林计数

<a id="tree100-085"></a>

**建议难度：银牌。题意与用途：** 给 N 个标号点及固定的 K 个根，统计每个连通分量恰有一个指定根的无向森林；用于广义 Cayley 计数。

**思路：** 固定根集合的森林数为 K·N^(N−K−1)。它可由广义 Prüfer 编码或完全图的根森林矩阵树定理得到；根集合是固定的，不再乘 C(N,K)。

**所需模板：** [公共模运算](<05 - 数论.md#default-mod>)。

**初始化与接口：** 1≤K≤N；rootForest(N,K)，MOD≥2 可合数；K=N 时全孤立点唯一。

**复杂度与边界：** O(log N) 时间、O(1) 空间；N≥1，不对负指数调用 qpow。

```c++
ll rootForest(int N, int K) {
    if (K == N) return 1;
    return (i128)(K % MOD) * qpow(N, N - K - 1) % MOD;
}
```

**例：** N=3、固定两个根，第三点可接任一根，答案 2。

##### 树上题 086：顶点权加权 Cayley 求和

<a id="tree100-086"></a>

**建议难度：银牌。题意与用途：** 完全图中边 (i,j) 的权为 w[i]w[j]，对全部生成树求“树内边权乘积”之和；用于生成函数和度数加权树计数。

**思路：** 树的权为 ∏w[i]^deg[i]。Prüfer 中每出现一次 i 多带一个 w[i]，所以总和为 (∏w[i])·(Σw[i])^(N−2)。

**所需模板：** [公共模运算](<05 - 数论.md#default-mod>)。

**初始化与接口：** weightedCayley(w)，w 长度 N+1，N≥1，先用 mod 归一化；MOD≥2 可合数。

**复杂度与边界：** O(N+log N) 时间、O(1) 空间；N=1 空边乘积为 1。

```c++
ll weightedCayley(const vector<ll> &w) {
    int N = (int)w.size() - 1;
    if (N == 1) return 1;
    ll p = 1, s = 0;
    for (int i = 1; i <= N; i++) {
        ll x = mod(w[i]);
        p = (i128)p * x % MOD;
        s = ((i128)s + x) % MOD;
    }
    return (i128)p * qpow(s, N - 2) % MOD;
}
```

**例：** 3 个点权 1、2、3，三棵树权积总和 6·6=36。

##### 树上题 087：均匀生成指定度数的标号树

<a id="tree100-087"></a>

**建议难度：银牌。题意与用途：** 给合法度数序列，随机生成满足该度数的标号树，要求在该集合中均匀；用于对拍和特定结构数据生成。

**思路：** 构造每个编号出现 d[i]−1 次的 Prüfer 多重集，均匀打乱再解码。每种不同序列对应相同数量的重复元素排列，因此随机分布均匀。

**所需模板：** [公共全局与有根遍历](#tree-base)、[Prüfer](#tree-counting)。

**初始化与接口：** randomDegreeTree(d,rng)，N=d.size()−1，不读取全局 n；输入须满足第 084 题的度数合法条件。rng 为 mt19937_64 引用。

**复杂度与边界：** O(N log N) 时间、O(N) 空间。均匀性以 RNG/标准 shuffle 的均匀随机模型为前提；不宣称密码学随机性。

```c++
vector<pair<int, int>> randomDegreeTree(const vector<int> &d, mt19937_64 &rng) {
    int N = (int)d.size() - 1;
    vector<int> a;
    for (int i = 1; i <= N; i++)
        for (int j = 1; j < d[i]; j++)
            a.push_back(i);
    shuffle(a.begin(), a.end(), rng);
    return pruferDecode(N, a);
}
```

**例：** 度数 {3,1,1,1} 只能生成以点 1 为中心的星形树。

##### 树上题 088：恰有指定叶子集合的标号树数

<a id="tree100-088"></a>

**建议难度：金牌。题意与用途：** 给 N 个点和固定叶子集合 S，要求度为 1 的顶点恰好是 S，统计标号树；用于满射与 Prüfer 容斥。

**思路：** 叶子不出现在 Prüfer 序列，非叶子必须至少出现一次。长度 N−2 的序列向 N−|S| 个内部点满射，按未出现内部点容斥。

**所需模板：** [公共模运算](<05 - 数论.md#default-mod>)、[公共阶乘与组合](<05 - 数论.md#default-comb>)。

**初始化与接口：** MOD 为质数、N<MOD；initComb(N); exactLeaves(N,L)，L=|S|，集合已固定。N=1 按度数为 1 定义叶子，故叶子集合为空。

**复杂度与边界：** O(N log N+log MOD) 时间、O(N) 空间；N=2 时两点都是叶子；不乘 C(N,L)。

```c++
ll exactLeaves(int N, int L) {
    if (N == 1) return L == 0;
    if (N == 2) return L == 2;
    if (L < 2 || L >= N) return 0;
    int m = N - L;
    ll ans = 0;
    for (int i = 0; i <= m; i++) {
        ll t = (i128)C(m, i) * qpow(m - i, N - 2) % MOD;
        ans = mod(ans + (i & 1 ? -t : t));
    }
    return ans;
}
```

**例：** N=4，指定两个叶子，另两个内部点各出现一次，答案 2。

##### 树上题 089：包含指定森林边的标号树数

<a id="tree100-089"></a>

**建议难度：银牌。题意与用途：** 在 N 点完全图的标号生成树中，要求包含给定森林的全部边，求数量；用于连通块缩点计数。

**思路：** 将森林分量缩成 K 个点、大小 s[i]。缩点树每条连接有 s[i]s[j] 种端点选择，加权 Cayley 得 N^(K−2)·∏s[i]。K=1 时已经是一棵树。

**所需模板：** [公共模运算](<05 - 数论.md#default-mod>)。

**初始化与接口：** containingForest(N,edges)，N≥1；若输入存在环（含重复边、自环）返回 0，合法顶点 1..N。MOD≥2 可合数。

**复杂度与边界：** O(N+m α(N)+log N) 时间、O(N) 空间，m 为给定边数。

```c++
ll containingForest(int N, const vector<pair<int, int>> &edges) {
    vector<int> p(N + 1), s(N + 1, 1);
    iota(p.begin(), p.end(), 0);
    int k = N;
    auto find = [&](int u) {
        while (u != p[u])
            u = p[u] = p[p[u]];
        return u;
    };
    for (auto [u, v] : edges) {
        int a = find(u), b = find(v);
        if (a == b) return 0;
        if (s[a] < s[b]) swap(a, b);
        p[b] = a;
        s[a] += s[b];
        --k;
    }
    if (k == 1) return 1;
    ll ans = qpow(N, k - 2);
    for (int u = 1; u <= N; u++)
        if (find(u) == u) ans = (i128)ans * s[u] % MOD;
    return ans;
}
```

**例：** N=4、固定边 1–2，分量大小为 2、1、1，答案 4·2=8。

##### 树上题 090：构造有根同构树的点号映射

<a id="tree100-090"></a>

**建议难度：金牌。题意与用途：** 不仅判断两棵有根树同构，还构造第一棵到第二棵的顶点对应；用于树结构对齐。

**思路：** 先共享 AHU 字典求类型并保存两棵树的孩子表。根类型相等后，按孩子类型排序，同类孩子任意一一配对，再迭代向下。

**所需模板：** [公共全局与有根遍历](#tree-base)、[AHU](#tree-isomorphism)。

**初始化与接口：** 建第一棵树并 rootTree 后 auto a=saveIso()；再建第二棵保存 b；isoMapping(a,b) 返回 1-based 映射，无解返回空 vector。两次之间不清 iso，忽略标签和边权。

**复杂度与边界：** 累计 O(n log n) 时间、O(n) 空间；必须比较同一字典下的类型。

```c++
struct IsoView {
    int root;
    vector<vector<int>> child;
    vector<int> type;
};
IsoView saveIso() {
    rootedIso();
    IsoView a{ord[0], vector<vector<int>>(n + 1), typ};
    for (int u = 1; u <= n; u++)
        if (fa[u]) a.child[fa[u]].push_back(u);
    for (auto &v : a.child)
        sort(v.begin(), v.end(), [&](int x, int y) {
            return a.type[x] < a.type[y];
        });
    return a;
}
vector<int> isoMapping(const IsoView &a, const IsoView &b) {
    if (a.type.size() != b.type.size() || a.type[a.root] != b.type[b.root]) return {};
    vector<int> ans(a.type.size());
    vector<pair<int, int>> q{{a.root, b.root}};
    for (int i = 0; i < (int)q.size(); i++) {
        auto [u, v] = q[i];
        ans[u] = v;
        for (int j = 0; j < (int)a.child[u].size(); j++)
            q.push_back({a.child[u][j], b.child[v][j]});
    }
    return ans;
}
```

**例：** 三点星形第一棵根为 1、第二棵根为 2，映射必须将 1 对到 2，两片叶子可任意配对。

##### 树上题 091：子树预算内最多选点

<a id="tree100-091"></a>

**建议难度：金牌。题意与用途：** 每点有非负成本，每个子树内可任意选一些点，预算均为 B，求最多能选几个；用于可并堆与局部淘汰。

**思路：** 每个子树维护已选成本最大堆；合并孩子并加入自身后，超预算就删最大成本。被较便宜点淘汰的点在任何祖先使用相同预算时都不会更优。用左偏最小堆存负成本。

**所需模板：** [公共全局与有根遍历](#tree-base)、[左偏堆](<08 - 数据结构.md#leftist-heap>)。

**初始化与接口：** B≥0；rootTree(r); budgetNodes(cost,B)。不要求所选点连通或含根；cost 不得为负。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；堆只合并不同根，子树答案在堆被祖先吸收前保存。

```c++
vector<int> budgetNodes(const vector<ll> &cost, ll B) {
    LeftistHeap h;
    vector<int> rt(n + 1), ans(n + 1);
    vector<ll> sum(n + 1);
    for (int i = n - 1; i >= 0; i--) {
        int u = ord[i];
        h.insert(rt[u], -cost[u]);
        sum[u] = cost[u];
        for (auto [v, w] : e[u])
            if (fa[v] == u) {
                h.merge(rt[u], rt[v]);
                sum[u] += sum[v];
            }
        while (sum[u] > B)
            sum[u] += h.pop(rt[u]);
        ans[u] = h.size(rt[u]);
    }
    return ans;
}
```

**例：** 根连两个孩子，成本 8、2、3，预算 5：根子树可选两个孩子，答案 2。

##### 树上题 092：树距离完全图的最大生成树

<a id="tree100-092"></a>

**建议难度：金牌。题意与用途：** 原树非负边权，把任意两点间树距离作为完全图边权，求最大生成树并构造边；用于度量结构与直径端点。

**思路：** 设直径端点 s,t。连接 s–t，再把其他每点连接到更远的端点，得到双星。权和为 Σecc[u]−diam。任意生成树以 s 为根，每条父边≤孩子离心率，故该值也是上界。

**所需模板：** [公共全局与有根遍历](#tree-base)、[树的度量](#tree-metrics)。

**初始化与接口：** rootTree(r); metricMst() 返回 {最大权和,边对列表}；单点无边。全零边权时任选两个不同端点构造。

**复杂度与边界：** O(n) 时间、O(n) 空间；完全图无需显式建立。

```c++
pair<ll, vector<pair<int, int>>> metricMst() {
    auto z = metrics();
    vector<pair<int, int>> edges;
    if (n == 1) return {0, edges};
    int s = z.st, t = z.ed;
    if (s == t) t = s == 1 ? 2 : 1;
    auto scan = [&](int r) {
        vector<ll> d(n + 1);
        vector<pair<int, int>> q{{r, 0}};
        for (int i = 0; i < (int)q.size(); i++) {
            auto [u, p] = q[i];
            for (auto [v, w] : e[u])
                if (v != p) d[v] = d[u] + w, q.push_back({v, u});
        }
        return d;
    };
    auto a = scan(s), b = scan(t);
    ll ans = a[t];
    edges.push_back({s, t});
    for (int u = 1; u <= n; u++)
        if (u != s && u != t) {
            int v = a[u] >= b[u] ? s : t;
            edges.push_back({u, v});
            ans += max(a[u], b[u]);
        }
    return {ans, edges};
}
```

**例：** 3 点链的完全图边权 1、1、2，最大生成树权为 3。

##### 树上题 093：全部路径的最大点权减最小点权之和

<a id="tree100-093"></a>

**建议难度：金牌。题意与用途：** 统计所有不同顶点无序对路径上的 max(a)−min(a) 总和；用于路径极值的激活贡献。

**思路：** 按点权升序激活，加入 u 并连接已激活相邻块时，每个新连通点对的路径最大值就是 a[u]；降序同理统计最小值。两次相减。相同权值任意顺序即可。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 只需建 e；pathRanges(a)，点权可负；单点路径贡献 0，计不计不影响结果。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；答案和各次极值和须在 ll 内。

```c++
ll pathRanges(const vector<ll> &a) {
    auto scan = [&](bool descending) {
        vector<int> ord(n), p(n + 1), s(n + 1, 1);
        vector<char> on(n + 1);
        iota(ord.begin(), ord.end(), 1);
        iota(p.begin(), p.end(), 0);
        sort(ord.begin(), ord.end(), [&](int u, int v) {
            return descending ? a[u] > a[v] : a[u] < a[v];
        });
        auto find = [&](int u) {
            while (u != p[u])
                u = p[u] = p[p[u]];
            return u;
        };
        ll ans = 0;
        for (int u : ord) {
            on[u] = 1;
            for (auto [v, w] : e[u])
                if (on[v]) {
                    int x = find(u), y = find(v);
                    ans += a[u] * s[x] * s[y];
                    if (s[x] < s[y]) swap(x, y);
                    p[y] = x;
                    s[x] += s[y];
                }
        }
        return ans;
    };
    return scan(false) - scan(true);
}
```

**例：** 链点权 1、3、2，三条非单点路径的极差为 2、1、2，总和 5。

##### 树上题 094：树形前置约束的最小加权完成时间

<a id="tree100-094"></a>

**建议难度：金牌。题意与用途：** 单机依次完成所有任务，父任务必须先于子任务；任务耗时 t[u]>0、权重 w[u]≥0，最小化 Σw[u]·完成时刻。用于密度贪心与块合并。

**思路：** 把任务看成连续执行块，密度为总权重/总耗时。选除根块外密度最大的块，合并到其父任务所在块的末尾；交换论证保证最高密度块可紧跟其前置块。并查集找当前父块，优先队列用版本号丢弃旧密度。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); weightedSchedule(t,w)，返回 i128；只求最小值。所有耗时和、权重和须在 ll 内，目标值在 i128 内。

**复杂度与边界：** O(n log n) 时间、O(n) 空间；不使用浮点比较比值。此结论依赖每点仅有一个父前置，不能推广到一般 DAG。

```c++
struct ScheduleBlock {
    ll w, t;
    int u, ver;
    bool operator<(const ScheduleBlock &b) const {
        i128 x = (i128)w * b.t, y = (i128)b.w * t;
        return x != y ? x < y : u < b.u;
    }
};
i128 weightedSchedule(vector<ll> t, vector<ll> w) {
    vector<int> p(n + 1), ver(n + 1);
    iota(p.begin(), p.end(), 0);
    int root = ord[0];
    auto find = [&](int u) {
        while (u != p[u])
            u = p[u] = p[p[u]];
        return u;
    };
    priority_queue<ScheduleBlock> q;
    i128 ans = 0;
    for (int u = 1; u <= n; u++) {
        ans += (i128)t[u] * w[u];
        if (u != root) q.push({w[u], t[u], u, 0});
    }
    while (!q.empty()) {
        auto z = q.top();
        q.pop();
        int u = z.u;
        if (p[u] != u || ver[u] != z.ver) continue;
        int v = find(fa[u]);
        ans += (i128)t[v] * w[u];
        t[v] += t[u];
        w[v] += w[u];
        p[u] = v;
        ++ver[v];
        if (v != root) q.push({w[v], t[v], v, ver[v]});
    }
    return ans;
}
```

**例：** 根与两孩子耗时均 1，权重 1、2、10，顺序根→权10→权2，代价 1+20+6=27。

##### 树上题 095：每种根下的最少反向边数

<a id="tree100-095"></a>

**建议难度：银牌。题意与用途：** 原树每条边有方向，选择根后允许反转边，使根能沿有向边到达所有点；求每种根所需反转数。用于 0/1 换根贡献。

**思路：** 固定根时，向父亲的边都需反转。把根从父亲移到孩子，仅跨越这条边的方向要求改变：原父→子时加 1，原子→父时减 1。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** 先用无向边建 e 并 rootTree(r)；reverseRoots(arcs)，arcs 的每对为原始方向 u→v，恰好对应原树全部边。

**复杂度与边界：** O(n) 时间、O(n) 空间；不修改 e 的权值或公共根。

```c++
vector<int> reverseRoots(const vector<pair<int, int>> &arcs) {
    vector<int> up(n + 1), ans(n + 1);
    int r = ord[0];
    for (auto [u, v] : arcs)
        if (fa[u] == v) up[u] = 1, ++ans[r];
    for (int i = 1; i < n; i++) {
        int u = ord[i];
        ans[u] = ans[fa[u]] + 1 - 2 * up[u];
    }
    return ans;
}
```

**例：** 方向 1→2、3→2，根为 1/2/3 时分别需要反转 1/2/1 条。

##### 树上题 096：严格祖先线性转移：可持久化李超树

<a id="tree100-096"></a>

**建议难度：金牌。题意与用途：** dp[root]=0，其他点 dp[u]=min(dp[v]+a[v]b[u])，v 枚举严格祖先；用于树上的斜率优化。

**思路：** 祖先 v 对应直线 a[v]x+dp[v]。每点从父版本查询 b[u]，再插入自己的直线，得到独立版本，兄弟分支不会污染。将所有 b 离散化；无需单调斜率或单调查询。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** rootTree(r); ancestorLines(a,b)，返回 vector<i128>，点数组 1-based。每次调用重建节点池。

**复杂度与边界：** O(n log n) 时间、O(n log n) 空间；树遍历非递归、李超递归深度 O(log n)。所有直线值绝对值须小于 2^118，系数与坐标为 ll。

```c++
vector<array<int, 3>> lc; // 左、右儿子，直线所在原树点号；0 表示空线
vector<ll> lx, la;
vector<i128> ldval;
i128 lineValue(int u, ll x) {
    return u ? (i128)la[u] * x + ldval[u] : ((i128)1 << 120);
}
int lineInsert(int old, int l, int r, int u) {
    int p = lc.size();
    lc.push_back(lc[old]);
    if (!lc[p][2]) {
        lc[p][2] = u;
        return p;
    }
    int m = (l + r) / 2;
    if (lineValue(u, lx[m]) < lineValue(lc[p][2], lx[m])) swap(u, lc[p][2]);
    if (l == r) return p;
    if (lineValue(u, lx[l]) < lineValue(lc[p][2], lx[l])) lc[p][0] = lineInsert(lc[p][0], l, m, u);
    else if (lineValue(u, lx[r]) < lineValue(lc[p][2], lx[r])) lc[p][1] = lineInsert(lc[p][1], m + 1, r, u);
    return p;
}
i128 lineQuery(int p, int l, int r, int x) {
    i128 ans = lineValue(lc[p][2], lx[x]);
    if (l == r || !p) return ans;
    int m = (l + r) / 2;
    return min(ans, x <= m ? lineQuery(lc[p][0], l, m, x) : lineQuery(lc[p][1], m + 1, r, x));
}
vector<i128> ancestorLines(const vector<ll> &a, const vector<ll> &b) {
    la = a;
    lx.assign(b.begin() + 1, b.end());
    sort(lx.begin(), lx.end());
    lx.erase(unique(lx.begin(), lx.end()), lx.end());
    lc.assign(1, {});
    ldval.assign(n + 1, 0);
    vector<int> rt(n + 1);
    int m = lx.size();
    for (int u : ord) {
        if (fa[u]) ldval[u] = lineQuery(rt[fa[u]], 0, m - 1, lower_bound(lx.begin(), lx.end(), b[u]) - lx.begin());
        rt[u] = lineInsert(rt[fa[u]], 0, m - 1, u);
    }
    return ldval;
}
```

**例：** 链 a={5,1,0}、b={0,2,3}，dp 为 0、10、13：点 3 选择祖先 2 更优。

##### 树上题 097：固定树边断开恢复与连通查询

<a id="tree100-097"></a>

**建议难度：银牌。题意与用途：** 只允许删除或恢复原树中的边，查询两点当前是否连通；用于利用原树唯一通路简化动态连通。

**思路：** 把断边存到较深端点，对其子树差分加 1。BIT 单点得到根路径断边数，u–v 断边数用 LCA 容斥，等于 0 即连通。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[百题共用 BIT](#tree100-bit)。

**初始化与接口：** rootTree(r); buildHld(); buildCuts(); cutSet(u,broken) 操作 u 的父边（fa[u]≠0）；stillConnected(u,v)。

**复杂度与边界：** 预处理 O(n)，修改/查询 O(log n)，空间 O(n)；仅支持原树边，不能加入其他边。

```c++
vector<ll> cutBit;
vector<char> broken;
void buildCuts() {
    cutBit.assign(n + 2, 0);
    broken.assign(n + 1, 0);
}
void cutSet(int u, bool on) {
    if (broken[u] == on) return;
    int x = on ? 1 : -1;
    broken[u] = on;
    bitAdd(cutBit, id[u], x);
    bitAdd(cutBit, id[u] + siz[u], -x);
}
bool stillConnected(int u, int v) {
    int p = lca(u, v);
    return bitSum(cutBit, id[u]) + bitSum(cutBit, id[v]) - 2 * bitSum(cutBit, id[p]) == 0;
}
```

**例：** 链 1–2–3 断开点 2 的父边后，1 与 3 不连通，2 与 3 仍连通。

##### 树上题 098：完全动态森林的路径加与和

<a id="tree100-098"></a>

**建议难度：金牌。题意与用途：** 支持连接两棵树、删除一条已有直接边、路径点权加、路径点权和、单点赋值；用于拓扑真正变化的森林。

**思路：** 使用第 08 章 LCT 动态暴露路径。连边先保证不成环；断边由 cut 验证是否直接相连；加与和必须先判断连通，避免对不存在路径操作。

**所需模板：** [LCT](<08 - 数据结构.md#link-cut-tree>)。

**初始化与接口：** dynamicForest(a,ops)，初始各点孤立，a 为 1-based 点权。操作 tuple{type,u,v,x}：1 连边、2 断边、3 路径加 x、4 路径和、5 点 u 赋 x；v 在 type=5 时忽略。返回每操作 {是否成功,查询值或0}。

**复杂度与边界：** 总计 O((n+q) log n) 均摊时间、O(n+q) 空间（含返回结果）；LCT 不复用静态 fa，它维护的是辅助树父指针，不能与公共 fa 混用。

```c++
vector<pair<bool, ll>> dynamicForest(const vector<ll> &a, const vector<tuple<int, int, int, ll>> &ops) {
    LCT t(a);
    vector<pair<bool, ll>> ans;
    for (auto [type, u, v, x] : ops) {
        bool ok = true;
        ll value = 0;
        if (type == 1) ok = t.link(u, v);
        else if (type == 2) ok = t.cut(u, v);
        else if (type == 5) t.set(u, x);
        else if (!(ok = t.same(u, v))) {
        } else if (type == 3) t.add(u, v, x);
        else value = t.sum(u, v);
        ans.push_back({ok, value});
    }
    return ans;
}
```

**例：** 点权 1、2、3，连 1–2、2–3 后路径和 6；全路径加 2 后和 12；断 1–2 后查询 1–3 返回失败。

##### 树上题 099：严格次小生成树

<a id="tree100-099"></a>

**建议难度：金牌。题意与用途：** 给带权无向图（允许重边、负权），求权值严格大于最小生成树的最小生成树权值；用于 MST 与树路径前两大值。

**思路：** 先 Kruskal 得 MST。枚举非树边 w，加入形成环：若 w 大于路径最大边，删最大边；若等于最大边，则删路径严格次大边，保证总权严格增加。倍增同时维护两个不同最大值。

**所需模板：** [公共全局与有根遍历](#tree-base)。

**初始化与接口：** strictSecond(N,edges)，边为 tuple<int,int,ll>；返回 {是否存在,权值}。调用会覆盖全局 n/e，成功建出 MST 后再 rootTree(1)，旧 HLD 等失效。断图或没有严格次小返回 false。

**复杂度与边界：** O(m log m+(n+m) log n) 时间、O(m+n log n) 空间；权值须大于 LLONG_MIN，MST 和与替换值须在 ll 范围且小于 LLONG_MAX。

```c++
pair<bool, ll> strictSecond(int N, const vector<tuple<int, int, ll>> &edges) {
    initTree(N);
    int m = edges.size();
    vector<int> p(n + 1), s(n + 1, 1), idx(m);
    vector<char> used(m);
    iota(p.begin(), p.end(), 0);
    iota(idx.begin(), idx.end(), 0);
    auto find = [&](int u) {
        while (u != p[u])
            u = p[u] = p[p[u]];
        return u;
    };
    sort(idx.begin(), idx.end(), [&](int i, int j) {
        return get<2>(edges[i]) < get<2>(edges[j]);
    });
    ll total = 0;
    int cnt = 0;
    for (int i : idx) {
        auto [u, v, w] = edges[i];
        int a = find(u), b = find(v);
        if (a == b) continue;
        if (s[a] < s[b]) swap(a, b);
        p[b] = a;
        s[a] += s[b];
        used[i] = 1;
        total += w;
        ++cnt;
        add(u, v, w);
    }
    if (cnt != n - 1) return {false, 0};
    rootTree();
    auto join = [](array<ll, 2> a, array<ll, 2> b) {
        for (ll x : b)
            if (x > a[0]) a[1] = a[0], a[0] = x;
            else if (x < a[0] && x > a[1]) a[1] = x;
        return a;
    };
    int L = 1;
    while ((1LL << L) <= n)
        ++L;
    vector<vector<int>> up(L, fa);
    vector<vector<array<ll, 2>>> mx(L, vector<array<ll, 2>>(n + 1, {LLONG_MIN, LLONG_MIN}));
    for (int u = 1; u <= n; u++)
        if (fa[u]) mx[0][u][0] = pw[u];
    for (int j = 1; j < L; j++)
        for (int u = 1; u <= n; u++) {
            up[j][u] = up[j - 1][up[j - 1][u]];
            mx[j][u] = join(mx[j - 1][u], mx[j - 1][up[j - 1][u]]);
        }
    auto query = [&](int u, int v) {
        array<ll, 2> a{LLONG_MIN, LLONG_MIN};
        if (dep[u] < dep[v]) swap(u, v);
        int d = dep[u] - dep[v];
        for (int j = 0; j < L; j++)
            if ((d >> j) & 1) a = join(a, mx[j][u]), u = up[j][u];
        if (u == v) return a;
        for (int j = L - 1; j >= 0; j--)
            if (up[j][u] != up[j][v]) {
                a = join(a, join(mx[j][u], mx[j][v]));
                u = up[j][u];
                v = up[j][v];
            }
        return join(a, join(mx[0][u], mx[0][v]));
    };
    ll ans = LLONG_MAX;
    for (int i = 0; i < m; i++)
        if (!used[i]) {
            auto [u, v, w] = edges[i];
            if (u == v) continue;
            auto z = query(u, v);
            ll remove = w > z[0] ? z[0] : z[1];
            if (remove != LLONG_MIN) ans = min(ans, total + w - remove);
        }
    return ans == LLONG_MAX ? make_pair(false, 0LL) : make_pair(true, ans);
}
```

**例：** 三角形边权 1、2、2，MST 为 3，严格次小为 4；三边全 1 时没有严格次小。

##### 树上题 100：把一条边清零后的运输瓶颈最小值

<a id="tree100-100"></a>

**建议难度：金牌。题意与用途：** 给多条运输路径，可将至多一条边权改为 0，最小化这些路径中的最大长度；用于二分答案与公共边差分。

**思路：** 二分上限 X，只考虑原长度>X 的路径。所选边必须被所有超长路径经过，且其权值至少为 maxLen−X。用边差分统计每条边被多少条超长路径覆盖，检查是否存在足够重的公共边。

**所需模板：** [公共全局与有根遍历](#tree-base)、[HLD](#lca)、[共用路径工具](#lca)。

**初始化与接口：** 非负边权；rootTree(r); buildHld(); transportLimit(routes)，routes 为 pair<int,int>，不实际修改原树。

**复杂度与边界：** O(q log n+(n+q) log(W+1)) 时间、O(n+q) 空间；W 为原最长运输路径。空路径集合返回 0。

```c++
ll transportLimit(const vector<pair<int, int>> &routes) {
    vector<array<int, 3>> qs;
    vector<ll> len;
    ll hi = 0;
    for (auto [u, v] : routes) {
        int p = lca(u, v);
        qs.push_back({u, v, p});
        ll d = dis[u] + dis[v] - 2 * dis[p];
        len.push_back(d);
        hi = max(hi, d);
    }
    auto ok = [&](ll X) {
        vector<int> c(n + 1);
        int bad = 0;
        ll need = 0;
        for (int i = 0; i < (int)qs.size(); i++)
            if (len[i] > X) {
                auto [u, v, p] = qs[i];
                ++c[u];
                ++c[v];
                c[p] -= 2;
                ++bad;
                need = max(need, len[i] - X);
            }
        if (!bad) return true;
        ll best = 0;
        for (int i = n - 1; i > 0; i--) {
            int u = ord[i];
            if (c[u] == bad) best = max(best, pw[u]);
            c[fa[u]] += c[u];
        }
        return best >= need;
    };
    ll lo = 0;
    while (lo < hi) {
        ll m = lo + (hi - lo) / 2;
        if (ok(m)) hi = m;
        else lo = m + 1;
    }
    return lo;
}
```

**例：** 链边权 4、7，运输路线为 1–3、1–2；清零权 7 后最大长度为 4，最优答案 4。
