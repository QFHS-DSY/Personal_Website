### 巴什博奕

<a id="sec-1"></a>

> 有 $N$ 个石子，两名玩家轮流行动，按以下规则取石子：
> 
> 规定：每人每次可以取走 $X(1 \le X \le M)$ 个石子，拿到最后一颗石子的一方获胜。
> 
> 双方均采用最优策略，询问谁会获胜。

> 两名玩家轮流报数。
> 
> 规定：第一个报数的人可以报 $X(1 \le X \le M)$ ，后报数的人需要比前者所报数大 $Y(1 \le Y \le M)$ ，率先报到 $N$ 的人获胜。
> 
> 双方均采用最优策略，询问谁会获胜。

- $N=K\cdot(M+1)$ （其中 $K \in \mathbb{N}_{\ge0}$ ），后手必胜（后手可以控制每一回合结束时双方恰好取走 $M+1$ 个，重复 $K$ 轮后即胜利）；
- $N=K\cdot(M+1)+R$ （其中 $K \in \mathbb{N}_{\ge0},0 < R < M + 1$ ），先手必胜（先手先取走 $R$ 个，之后控制每一回合结束时双方恰好取走 $M+1$ 个，重复 $K$ 轮后即胜利）。

### 扩展巴什博弈

<a id="sec-2"></a>

> 有 $N$ 颗石子，两名玩家轮流行动，按以下规则取石子：。
> 
> 规定：每人每次可以取走 $X(a \le X \le b)$ 个石子，如果最后剩余物品的数量小于 $a$ 个，则不能再取，不能行动的一方输（剩余不足 a 也算不能行动）。
> 
> 双方均采用最优策略，询问谁会获胜。

- $N = K\cdot(a+b)$ 时，后手必胜；
- $N = K\cdot(a+b)+R_1$ （其中 $K \in \mathbb{N}_{\ge0},0 < R_1 < a$ ） 时，后手必胜（这些数量不够再取一次，先手无法逆转局面）；
- $N = K\cdot(a+b)+R_2$ （其中 $K \in \mathbb{N}_{\ge0},a \le R_2 \le b$ ） 时，先手必胜；
- $N = K\cdot(a+b)+R_3$ （其中 $K \in \mathbb{N}_{\ge0},b < R_3 < a + b$ ） 时，先手必胜（这些数量不够再取一次，后手无法逆转局面）；

### Nim 博弈

<a id="sec-3"></a>

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
> 
> 规定：每人每次任选一堆，取走正整数颗石子，拿到最后一颗石子的一方获胜（注：几个特点是**不能跨堆**、**不能不拿**）。
> 
> 双方均采用最优策略，询问谁会获胜。

记初始时各堆石子的数量 $(A_1,A_2,\dots,A_n)$ ，定义尼姆和 $Sum_N = A_1 \oplus A_2 \oplus \dots \oplus A_n$ 。

**当** $\pmb{ Sum_N = 0 }$ **时先手必败，反之先手必胜。**

### Nim 游戏具体取法

<a id="sec-4"></a>

先计算出尼姆和，再对每一堆石子计算 $A_i \oplus Sum_N$ ，记为 $X_i$ 。

若得到的值 $X_i<A_i$ ，$X_i$ 即为一个可行解，即**剩下** $\pmb X_i$ **颗石头，取走** $\pmb {A_i - X_i}$ **颗石头**（这里取小于号是因为至少要取走 $1$ 颗石子）。

### Moore’s Nim 游戏（Nim-K 游戏）

<a id="sec-5"></a>

每回合选择 1..K 个非空堆，各堆独立取走正数个石子，取的数量允许相同；不能行动者输。把每堆二进制第 b 位的 1 的总数记为 One[b]。

先手必败当且仅当所有位都有 One[b]%(K+1)==0；只要存在一位不满足就是必胜。这个判据判断胜负，不能把各位余数直接当作通用 SG 值与其他游戏异或。

```c++
bool mooreWin(const vector<ll> &heaps, int k) {
    /* assert(k>=1) */;
    for (ll x : heaps) /* assert(x>=0) */;
    for (int bit = 0; bit < 63; ++bit) {
        ll ones = 0;
        for (ll x : heaps) ones += (x >> bit) & 1;
        if (ones % (ll(k) + 1)) return true;
    }
    return false;
}
```

例如 K=1、(1,3) 为必胜态，虽然最低位的 1 个数是 2。

### Anti-Nim 游戏（反 Nim 游戏）

<a id="sec-6"></a>

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，按以下规则取石子：
> 
> 规定：每人每次任选一堆，取走正整数颗石子，拿到最后一颗石子的一方**出局**。
> 
> 双方均采用最优策略，询问谁会获胜。

以下两类局面先手必胜（空局面按不能行动者获胜约定处理）：

- 所有堆的石头数量均不超过 $1$ ，且 $\pmb {Sum_N=0}$ （即大小为 1 的非空堆有偶数个，不能把空堆计入）；
- 至少有一堆的石头数量大于 $1$ ，且 $\pmb{Sum_N \neq 0}$ 。

### 阶梯 - Nim 博弈

<a id="sec-7"></a>

> 有 $N$ 级台阶，每一级台阶上均有一定数量的石子，给出每一级石子的数量，两名玩家轮流行动，按以下规则操作石子：
> 
> 规定：每人每次任选一级台阶，拿走正整数颗石子放到下一级台阶中，已经拿到地面上的石子不能再拿，拿到最后一颗石子的一方获胜。
> 
> 双方均采用最优策略，询问谁会获胜。

**对奇数台阶做传统** $\pmb{\tt{}Nim}$ **博弈，当** $\pmb{Sum_N=0}$** 时先手必败，反之先手必胜。**

### SG 游戏（有向图游戏）

<a id="sec-8"></a>

适用条件：有限无环状态图、双方合法操作相同、不能行动者输。终态 SG=0，其他状态 SG 为后继 SG 集合的 mex；非零表示在双方最优策略下先手必胜。

若每回合只改变一个独立子游戏，总 SG 为各子游戏 SG 的异或。反常规则、同时改变多个子游戏或含环状态不能直接套用。

下列 DAG 接口接收 0..n-1 编号的邻接表，按逆拓扑序计算，不使用递归栈。时间 $\mathcal{O}(n+m)$，空间 $\mathcal{O}(n+m)$；有环抛 invalid_argument。

```c++
vector<int> dagSG(const vector<vector<int>> &adj) {
    int n = adj.size();
    vector<int> degree(n), order, sg(n), seen(n + 1, -1);
    for (auto &edges : adj)
        for (int v : edges) {
            /* assert(0<=v&&v<n) */;
            ++degree[v];
        }
    for (int u = 0; u < n; ++u)
        if (!degree[u]) order.push_back(u);
    for (int i = 0; i < order.size(); ++i)
        for (int v : adj[order[i]])
            if (--degree[v] == 0) order.push_back(v);
    if (order.size() != n) throw invalid_argument("SG requires a DAG");
    for (int i = n - 1; i >= 0; --i) {
        int u = order[i];
        for (int v : adj[u]) seen[sg[v]] = u;
        while (seen[sg[u]] == u) ++sg[u];
    }
    return sg;
}
```

取子游戏：每步从一堆取 moves 中某个正整数。预处理 0..maxStone，$\mathcal{O}(\mathrm{maxStone}\cdot \lvert \mathrm{moves}\rvert)$ 时间，$\mathcal{O}(\mathrm{maxStone}+\lvert \mathrm{moves}\rvert)$ 空间；不是 $\mathcal{O}(\text{堆数}+\text{取法数})$。

```c++
// subSG：预处理减法游戏 SG 值
vector<int> subSG(int maxStone, vector<int> moves) {
    /* assert(maxStone>=0) */;
    for (int x : moves) /* assert(x>0) */;
    sort(moves.begin(), moves.end());
    moves.erase(unique(moves.begin(), moves.end()), moves.end());
    vector<int> sg(maxStone + 1), seen(moves.size() + 1, -1);
    for (int x = 1; x <= maxStone; ++x) {
        for (int step : moves) {
            if (step > x) break;
            seen[sg[x - step]] = x;
        }
        while (seen[sg[x]] == x) ++sg[x];
    }
    return sg;
}
```

调用：`auto sg=subSG(maxHeap,{1,3,4}); int answer=0; for(int x:heaps) answer^=sg[x];`。

### Anti-SG 游戏（反 SG 游戏）

<a id="sec-9"></a>


反常规则：轮到某人时若不能行动，该玩家获胜。普通 SG 值不足以判定任意无环游戏的反常胜负；Anti-Nim 的结论只可用于已证明满足对应条件的游戏，不能直接套到任意 SG 和。

通用的小规模方法是对**完整局面**记忆化胜负：终态 `win=true`；非终态 `win(s)=存在后继 t 使 !win(t)`。多局游戏要把各局当前位置合成一个状态，每次只改变规则允许的一局；状态数可能是各局状态数的乘积。

反例：T 为终点，A→T，B→T 或 A，R→B。普通 SG(T,A,B,R)=(0,1,2,0)，但反常规则下胜负依次为胜、败、胜、败，所以 SG(R)=0 不能据 Anti-Nim 规则判为必胜。

### Lasker’s-Nim 游戏（ Multi-SG 游戏）

<a id="sec-10"></a>

> 有 $N$ 堆石子，给出每一堆的石子数量，两名玩家轮流行动，每人每次任选以下规定的一种操作石子：
> 
> - 任选一堆，取走正整数颗石子；
> - 任选数量至少为 $2$ 的一堆，分成两堆非空石子。
> 
> 拿到最后一颗石子的一方获胜。双方均采用最优策略，询问谁会获胜。

**SG(0)=0；对 x>=1，SG 值定义为：**

$$\pmb{ SG(x) = 
\begin{cases}
x-1 & \text{ , } x\mod 4= 0\\ 
x & \text{ , } x \mod 4 = 1\\ 
x & \text{ , } x \mod 4 = 2\\ 
x+1 & \text{ , } x \mod 4 = 3
\end{cases}}$$

### Every-SG 游戏

<a id="sec-11"></a>


给定有向无环图上的 K 个石子。每回合必须移动所有仍可移动的石子，每个石子沿一条出边移动；终点上的石子保持不动。所有石子都不能移动时，轮到行动的一方输。

不能按最长路径长度的奇偶判断胜负。例如 B 可以直接走到终点 T，也可以经 A 再到 T，最长路径有两步，但单个石子在 B 时可以直接获胜。

通用的小规模方法：用各石子位置组成状态 s，枚举各可动石子的一条出边组合为后继状态 t，做记忆化胜负 DP。终态 `win(s)=false`；非终态 `win(s)=存在后继 t 使 !win(t)`。图无环保证递推终止；状态数与出边组合可能呈指数增长，适合小规模或验证，较大题目需要根据游戏结构证明更强的递推，不能用普通最长路代替最优策略。

### 威佐夫博弈

<a id="sec-12"></a>

两堆石子，每回合从一堆取任意正数，或从两堆取走相同的正数；不能行动者输。令 a<=b、k=b-a，必败当且仅当 a=floor(k·(1+sqrt(5))/2)，包括 (0,0)。

用整数平方根精确判断，支持 0..LLONG_MAX。若 a<k，直接必胜；否则 k<=LLONG_MAX/2，$5k^{2}$ 可放入 u128。多写 double 常量的小数位无法提高其实际精度。

```c++
ull isqrt128(u128 n) {
    ull lo = 0, hi = ULLONG_MAX;
    while (lo < hi) {
        ull mid = ull((u128(lo) + hi + 1) / 2);
        if (u128(mid) * mid <= n) lo = mid;
        else hi = mid - 1;
    }
    return lo;
}
bool wythoffWin(ll a, ll b) {
    /* assert(a>=0&&b>=0) */;
    if (a > b) swap(a, b);
    ull k = ull(b - a);
    if (ull(a) < k) return true;
    ull first = ull((u128(k) + isqrt128(u128(5) * k * k)) / 2);
    return ull(a) != first;
}
```

反例回归：wythoffWin(165580140,267914295) 必须返回 false。判断只需常数次（64 轮）整数操作。

### 斐波那契博弈

<a id="sec-13"></a>

初始 N>=1。先手第一次取正数且不能取完，以后每次最多取上次的两倍；不能行动者输。当且仅当 N 为 1,2,3,5,8,... 时先手必败。

支持 N<=LLONG_MAX，以 i128 检查下一项，避免固定 int 数组溢出或预处理项数不足。$\mathcal{O}(\log N)$ 时间、$\mathcal{O}(1)$ 空间，无跨测试状态。

```c++
// fibWin：判断斐波那契取石子游戏胜负
bool fibWin(ll n) {
    /* assert(n>=1) */;
    if (n == 1 || n == 2) return false;
    ll a = 1, b = 2;
    while (b < n) {
        i128 next = i128(a) + b;
        if (next > n) return true;
        a = b;
        b = ll(next);
    }
    return false;
}
```

### 约瑟夫环递推

<a id="josephus"></a>

$n$ 个人编号为 $0,1,\ldots,n-1$，循环报数，每次数到 $m$ 的人出列。令 $f_{i,m}$ 为只剩 $i$ 个人时最终胜者在当前编号中的位置，则

$$f_{1,m}=0,\qquad f_{i,m}=(f_{i-1,m}+m)\bmod i.$$

最终答案为 $f_{n,m}$。完整模拟与多种编号约定见[第 14 章约瑟夫环](<14 - 模拟、构造与杂题.md>)；使用前先统一“从谁开始报”和编号是否从 0 开始。

### 无向图点不重复路径博弈

<a id="undirected-vertex-geography"></a>

给定无向图和起点，两人轮流走到相邻且未访问的顶点，无法移动者输。求图的任意一个最大匹配：若存在一个不覆盖起点的最大匹配，则起点是必败态；否则先手必胜。等价地，先手必胜当且仅当删除起点后图的最大匹配大小严格小于原图最大匹配大小。

这是无向图“顶点不可重复访问”博弈的专用结论；有向图、允许重复访问或删边博弈不能套用。一般图最大匹配实现见[图论章一般图带权带花树](<03 - 图论.md>)；无权时只需比较最大匹配基数。

### 二人零和矩阵博弈

<a id="zero-sum-game"></a>

设行玩家的收益矩阵为 $w_{i,j}$。行玩家选择混合策略 $\mathbf p$ 时，其保底收益是对所有列纯策略的最小期望收益，因此博弈值可写成线性规划

$$\max_{\mathbf p}\min_i\sum_jp_jw_{i,j},\qquad
p_j\ge0,\quad\sum_jp_j=1.$$

有限二人零和博弈满足最大最小定理：行玩家的最大保底收益等于列玩家的最小封顶收益，并存在混合策略纳什均衡。一般情形应用线性规划或专用算法求解，不能用“不断增加当前最小收益对应策略的概率”作为通用算法。

### 树上删边游戏

<a id="sec-14"></a>

给出有根树，每步删去一条边，不再连接根的部分同时删除。根不能删除，无边可删者输。叶子 SG=0，其他节点 SG 为各孩子 (SG+1) 的异或；根 SG 非零即先手必胜。

顶点编号 0..n-1，默认 root=0。用迭代遍历避免长链递归栈溢出；时间、空间 $\mathcal{O}(n)$。输入必须是无向树。

```c++
// treeSG：求树删边游戏 SG 值
int treeSG(const vector<vector<int>> &adj, int root = 0) {
    int n = adj.size(); /* assert(0<=root&&root<n) */;
    vector<int> parent(n, -1), order{root}, sg(n);
    parent[root] = root;
    for (int i = 0; i < order.size(); ++i) {
        int u = order[i];
        for (int v : adj[u]) {
            /* assert(0<=v&&v<n) */;
            if (v == parent[u]) continue; /* assert(parent[v]==-1) */;
            parent[v] = u;
            order.push_back(v);
        }
    }
    /* assert(order.size()==n) */;
    for (int i = n - 1; i > 0; --i) {
        int u = order[i];
        sg[parent[u]] ^= sg[u] + 1;
    }
    return sg[root];
}
```

调用：`cout<<(treeSG(adj)!=0?"Alice":"Bob")<<'\n';`。

### 无向图删边游戏（Fusion Principle 定理）

<a id="sec-15"></a>

无向连通图有指定根。每次删一条边，不与根相连的部分随之删除；不能行动者输。这是正常规则的无向图删边游戏。

融合原理允许将同一环上的顶点融合，内部边变成自环；自环可视作独立的一条叶边，两个这样的分量异或抵消。对于仙人掌，可直接将偶环缩成一个点，奇环缩成一个点并附一条叶边，保留环外连接，最后使用树删边递推。

一般图可能有相交环，不能把各个简单环当作独立组件逐个套奇偶结论。需要按融合原理处理完整连通结构；本节没有提供通用图实现。比赛时先确认图的限制，避免把仙人掌的直接实现误用于任意图。

### 有环状态图的胜负与平局

<a id="cyclic-game"></a>

有限有向状态图，双方轮流沿一条出边移动，不能行动者输，无限对局算平局；双方偏好“胜 > 平 > 负”。返回的是轮到当前玩家时各状态的 Win/Lose/Draw，不是 SG 值，不能直接异或合并游戏。若合法操作与玩家有关，应把“轮到谁”编码进状态。

调用 `solveGame(adj)`，顶点 0..n-1，允许自环和重边。state 保存结果，move 在 Win 状态给出通向 Lose 的一步，在 Draw 状态给出通向 Draw 的一步，在 Lose 状态为 -1。以终点 Lose 为起点反向传播：存在 Lose 后继则 Win，全部后继 Win 则 Lose，剩余状态 Draw。时间、空间均 $\mathcal{O}(n+m)$，使用队列避免递归。

```c++
enum class GameState {
    Draw,
    Win,
    Lose
};
struct GameResult {
    vector<GameState> state;
    vector<int> move;
};
GameResult solveGame(const vector<vector<int>> &adj) {
    int n = adj.size();
    vector<vector<int>> reverse(n);
    vector<int> remaining(n);
    queue<int> q;
    GameResult result{vector<GameState>(n, GameState::Draw), vector<int>(n, -1)};
    for (int u = 0; u < n; ++u) {
        remaining[u] = adj[u].size();
        for (int v : adj[u]) {
            /* assert(0<=v&&v<n) */;
            reverse[v].push_back(u);
        }
        if (remaining[u] == 0) {
            result.state[u] = GameState::Lose;
            q.push(u);
        }
    }
    while (!q.empty()) {
        int v = q.front();
        q.pop();
        for (int u : reverse[v]) {
            if (result.state[u] != GameState::Draw) continue;
            if (result.state[v] == GameState::Lose) {
                result.state[u] = GameState::Win;
                result.move[u] = v;
                q.push(u);
            } else if (--remaining[u] == 0) {
                result.state[u] = GameState::Lose;
                q.push(u);
            }
        }
    }
    for (int u = 0; u < n; ++u)
        if (result.state[u] == GameState::Draw)
            for (int v : adj[u])
                if (result.state[v] == GameState::Draw) {
                    result.move[u] = v;
                    break;
                }
    return result;
}
```

例：`solveGame({{1},{},{2}})` 的三个状态依次为 Win、Lose、Draw；第三个点只有自环，可以无限进行。
