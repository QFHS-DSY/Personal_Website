## 第十三章：竞赛工具与调试

### 对拍流程（Linux / Windows）

<a id="stress-testing"></a>

用途：用小规模随机数据和暴力答案检查正式解，遇到答案不同或运行失败立即停止，保留当前输入和输出。`main.cpp` 使用自己在赛场上编写的解题程序，正常使用标准输入输出；`dp.cpp` 负责生成数据、计算暴力答案、运行正式解和比较输出。

每轮时间为 $O(G+B+S+L)$，其中 $G$ 为生成输入的耗时，$B$ 为暴力求解耗时，$S$ 为正式解耗时，$L$ 为两份输出的总长度；另有启动进程和文件读写的开销。下方生成器每轮至多 $T=4$ 组、每组 $n\le 20$，暴力为 $O(Tn^2)$，使用 $O(n)$ 数组空间。比较器只保留当前两个 token，空间取决于最长 token；输入输出文件另占磁盘空间。

#### 文件分工与使用顺序

每个版本放在独立目录中，准备两个 C++ 源文件和一个启动脚本；同一目录不要同时运行多份对拍，否则会互相覆盖数据。

| 文件 | 用途 |
|---|---|
| `main.cpp` | 待测解，只读标准输入、写标准输出，不需要添加 `freopen` |
| `dp.cpp` | `gen(seed)` 生成输入及暴力答案，`same()` 比较输出，主循环控制轮数 |
| `run.sh` / `run.bat` | 分别用于 Linux / Windows，先编译两个程序，再开始对拍 |
| `data.in` | 本轮输入，由 `gen()` 写入 |
| `ans.out` | 本轮暴力答案，由 `gen()` 写入 |
| `main.out` | 本轮正式解输出，由运行命令重定向写入 |

1. 同一目录保存 `main.cpp`、`dp.cpp` 和对应平台的脚本，确保终端能执行 `g++`。
2. 将赛场解题程序保存为 `main.cpp`，按题意修改 `gen()`；生成的数据必须合法，暴力答案应独立计算。
3. 运行脚本。默认使用种子 `1..1000`，每通过 100 轮输出一次 `OK`，全部通过输出 `PASS`。
4. 失败后先另存 `data.in`、`ans.out`、`main.out`，再修改或重跑；新一轮会覆盖这三个文件。

#### 公共对拍程序：dp.cpp

两份原稿仅启动命令不同，下面用 `_WIN32` 自动选择，Linux 和 Windows 可复制同一份代码。其余流程保持一致：固定种子造数据，同时枚举子段求暴力答案，再运行 `main` / `main.exe`。

这里的 `gen()` 以**最大非空连续子段和**为例：输入最前面是组数 `T`，每组为 `n` 和 `n` 个整数，参考输出为每组的最大非空连续子段和。`dp.cpp` 是完整程序，入口使用 `signed main()`，兼容需要时在头文件后启用 `#define int long long`。

`seed%4` 轮换全负、全零、小值随机、大值随机四种模式；大值模式用于暴露 32 位整数溢出。改题时主要替换 `gen()`，按暴力复杂度控制规模，同时检查多组数据的状态清空。

```c++
#include <bits/stdc++.h>
using namespace std;
using ll = long long;

void gen(int seed) {
    mt19937 rng(seed); // 同一种子复现同一轮数据
    ofstream in("data.in"), out("ans.out");
    int T = rng() % 4 + 1;
    in << T << '\n';
    while (T--) {
        int n = rng() % 20 + 1;
        ll a[20], ans = -(1LL << 60); // 本例答案不会低于此初值
        in << n << '\n';
        for (int i = 0; i < n; i++) {
            a[i] = (int)(rng() % 21) - 10;
            if (seed % 4 == 0) a[i] = -1 - (int)(rng() % 10);
            if (seed % 4 == 1) a[i] = 0;
            if (seed % 4 == 3) a[i] *= 1000000000LL;
            in << a[i] << " \n"[i == n - 1];
        }
        // 独立暴力：枚举非空子段的左右端点，时间 O(n^2)
        for (int l = 0; l < n; l++) {
            ll s = 0;
            for (int r = l; r < n; r++) ans = max(ans, s += a[r]);
        }
        out << ans << '\n';
    }
    in.close();
    out.close(); // 先关闭文件，再启动待测程序
    if (!in || !out) exit(2); // 生成文件失败或写入失败
}

bool same() {
    ifstream a("main.out"), b("ans.out");
    string x, y;
    if (!a || !b) return false;
    while (a >> x)
        if (!(b >> y) || x != y) return false;
    return !(b >> y); // 正式解不能少输出 token
}

signed main() {
    for (int t = 1; t <= 1000; t++) { // t 同时是轮次和随机种子
        gen(t);
#ifdef _WIN32
        int ret = system("main.exe < data.in > main.out");
#else
        int ret = system("./main < data.in > main.out");
#endif
        if (ret) return cout << "RE " << t << endl, 1;
        if (!same()) return cout << "WA " << t << endl, 1;
        if (t % 100 == 0) cout << "OK " << t << endl;
    }
    cout << "PASS\n";
}
```

#### Linux：run.sh

依赖 Bash 和支持 GNU C++17 的 `g++`。脚本使用 LF 换行；自动切到脚本所在目录，任一编译失败即停止。

```bash
#!/usr/bin/env bash
set -e
cd "$(dirname "$0")"
g++ -std=c++17 -O2 main.cpp -o main
g++ -std=c++17 -O2 dp.cpp -o dp
./dp
```

在脚本所在目录运行，使用 `bash` 时无需给脚本添加执行权限：

```bash
bash run.sh
```

#### Windows：run.bat

依赖 MinGW-w64 / MSYS2 等提供的 `g++`，需要加入 `PATH`；本例 `dp.cpp` 使用 `bits/stdc++.h`。脚本自动切换盘符及工作目录，任一编译失败即停止。

```bat
@echo off
cd /d "%~dp0"
g++ -std=c++17 -O2 main.cpp -o main.exe || exit /b 1
g++ -std=c++17 -O2 dp.cpp -o dp.exe || exit /b 1
dp.exe
```

在脚本所在目录的 PowerShell 中运行：

```powershell
.\run.bat
```

CMD 中直接运行 `run.bat`。推荐从终端启动，方便查看停止原因。

#### 结果判断、反例复现与限制

| 结果 | 含义与处理 |
|---|---|
| `OK t` | 已通过第 `t` 轮，继续测试 |
| `PASS` | 本次全部种子通过，不代表已证明算法正确 |
| `WA t` | 第 `t` 轮输出不同，或无法打开输出文件；查看当前三份数据文件 |
| `RE t` | 第 `t` 轮启动命令或正式解返回非零状态；查看终端错误信息和输入 |
| 退出码 `2` | `gen()` 创建或写入文件失败；检查目录权限、磁盘空间等 |
| 编译错误 | 脚本停止，修复编译错误后再运行 |

- **比较规则**：`same()` 按空白分隔后逐个比较字符串，忽略空格、换行及末尾空白，能发现多输出、少输出和内容不同；`1` 与 `01`、`1.0` 与 `1.00` 仍视为不同。浮点题需改为误差比较；多解题需检查答案合法性，不能直接与一份标准答案判等。
- **复现种子**：例如输出 `WA 317`，把循环改为 `for (int t=317; t<=317; t++)` 即可只测该种子。生成逻辑或调用随机数的顺序一旦改变，同一种子也可能生成不同数据，因此应先保存反例文件。
- **直接复跑反例**：在原工作目录保留当前 `data.in`，Linux 使用 `./main < data.in > main.out`，Windows 的 CMD 使用 `main.exe < data.in > main.out`。PowerShell 不支持同样的 `<` 输入重定向，可执行 `cmd /c "main.exe < data.in > main.out"`；修改了正式解时先重新编译。
- **超时与性能**：本短版没有超时或内存限制，死循环会一直等待，需要手动中断。它主要检查正确性；逐轮启动进程的耗时不能直接当作正式解在 OJ 上的运行时间。
- **数据覆盖**：当前 `%` 取随机数的写法存在轻微取模偏差，适合本例的小规模对拍，不保证均匀抽样。换题后应主动补入最小规模、极值、重复值和特殊结构等合法数据，不能只依赖普通随机样例。

#### 随机数生成与样例构造

<a id="random"></a>

适用于 `linux/dp.cpp` 和 `windows/dp.cpp`。所有代码均为 C++17，不需要 Python；按题目需要复制，不必把整份手册都塞进对拍程序。

`main.cpp` 仍然只是你的解题程序。这里的函数放在 `dp.cpp` 中，用于 `gen()` 生成输入；暴力答案仍需按题目单独计算。

##### 1. 统一随机数接口

把下面代码放在 `dp.cpp` 文件开头，替换已有的头文件、类型别名部分。每种生成方法都依赖这里的定义。

```cpp
#include <bits/stdc++.h>
using namespace std;
using ll = long long;
using PII = pair<int, int>;
using E = vector<PII>;
mt19937 rng;

ll rd(ll l, ll r) {
    return uniform_int_distribution<ll>(l, r)(rng);
}
```

- `rd(l,r)` 返回闭区间 `[l,r]` 内的随机整数，要求 `l<=r`。
- `rd(1,10)`：1 到 10；`rd(-10,10)`：-10 到 10；`rd(0,1)`：随机二选一。
- `E` 是边表，每个元素为一对端点 `(u,v)`。
- 各个数组和字符串的下标从 0 开始；树和图的顶点编号从 1 开始。

**每次进入 `gen(seed)` 时执行 `rng.seed(seed);`。原版 `gen()` 中的 `mt19937 rng(seed);` 要删除，避免局部随机引擎遮蔽这里的全局 `rng`。** 不要每生成一个数就重新设种子。

在同一代码和标准库环境中，同一个种子可以复现同一输入。跨标准库的分布和 shuffle 实现可能不同，发现反例后仍应保存 `data.in`。

##### 2. 随机数组

长度为 n，每个元素在 `[l,r]`，允许重复，要求 `n>=0`。

```cpp
vector<ll> arr(int n, ll l, ll r) {
    vector<ll> a(n);
    for (ll &x : a) x = rd(l, r);
    return a;
}
```

常用写法：

| 目标 | 写法 |
|---|---|
| 小值域、很多重复 | `auto a=arr(n,-2,2);` |
| 全正 | `auto a=arr(n,1,10);` |
| 全负 | `auto a=arr(n,-10,-1);` |
| 大值随机 | `auto a=arr(n,-1000000000LL,1000000000LL);` |
| 全零 | `vector<ll> a(n,0);` |
| 全部相同 | `vector<ll> a(n,rd(-10,10));` |
| 非递减 | 生成后执行 `sort(a.begin(),a.end());` |
| 非递增 | 生成后执行 `sort(a.rbegin(),a.rend());` |

先生成小值域通常比只生成大整数更容易触发相等、重复、零值相关的错误。排序可能产生相等元素；需要严格递增时先生成互异整数。

##### 3. 一个 n 的排列

生成 `1..n` 的随机排列，要求 `n>=0`。

```cpp
vector<int> perm(int n) {
    vector<int> p(n);
    iota(p.begin(), p.end(), 1);
    shuffle(p.begin(), p.end(), rng);
    return p;
}
```

使用 `auto p=perm(n);`。如果要 `0..n-1` 的排列，把 `iota` 的最后一个参数改成 `0`。

不要用“随机交换几次”代替完整 shuffle；那样可能覆盖不到足够多的排列。逆序、恒等排列、只交换相邻两个元素也应作为单独的特殊数据测试。

##### 4. 区间中选 n 个互不相同的整数

先列出整个候选区间，再打乱并取前 n 个。要求 `l<=r`、`0<=n<=r-l+1`；区间长度须能放进内存和 int。

```cpp
vector<int> pick(int n, int l, int r) {
    assert(l <= r && 0 <= n && n <= 1LL * r - l + 1);
    vector<int> a(r - l + 1);
    iota(a.begin(), a.end(), l);
    shuffle(a.begin(), a.end(), rng);
    a.resize(n);
    return a;
}
```

例如 `pick(5,1,20)`。需要有序结果时再排序。

这个方法适合小范围对拍，时间和空间都是 `O(r-l+1)`。不要用它在 `[1,10^9]` 中只选几个数。范围很大、选择很稀疏时可以用 set 去重，但接近选满时拒绝采样会很慢。

##### 5. 随机字符串

长度 n，字符来自非空字符集 c。字符集中的字符应互不重复，否则重复字符会有更高的抽中概率。

```cpp
string str(int n, string c = "abc") {
    assert(n >= 0 && !c.empty());
    string s(n, ' ');
    for (char &x : s) x = c[rd(0, (int)c.size() - 1)];
    return s;
}
```

常用写法：`str(n)`、`str(n,"01")`、`str(n,"0123456789")`、`str(n,"abcdefghijklmnopqrstuvwxyz")`。

对拍字符串算法时，先使用 `"ab"` 或 `"abc"` 等小字符集，让重复子串更容易出现。n=0 虽然能生成空串，但题目若用 `cin>>s` 读入，空串通常不能这样表示，必须遵守输入协议。

##### 6. 回文串与周期串

回文串依赖上面的 `str()`，n 可以为 0。

```cpp
string pal(int n, string c = "abc") {
    string s = str(n, c);
    for (int i = 0; i < n / 2; i++) s[n - 1 - i] = s[i];
    return s;
}

string periodic(int n, string t = "ab") {
    assert(n >= 0 && !t.empty());
    string s;
    for (int i = 0; i < n; i++) s += t[i % t.size()];
    return s;
}
```

例如 `pal(7)`、`periodic(10,"abc")`。`periodic(10,"a")` 就是全相同字符串。周期串的长度不必是周期长度的整数倍。

想测试“差一点是回文/周期串”，先生成，再修改一个位置；注意替换成不同字符。

##### 7. 合法括号序列

参数 n 是括号对数，输出长度是 `2*n`，要求 `n>=0`。

```cpp
string brackets(int n) {
    string s;
    int l = 0, r = 0;
    while (r < n)
        if (l < n && (l == r || rd(0, 1))) s += '(', l++;
        else s += ')', r++;
    return s;
}
```

任意前缀中左括号都不少于右括号，总数量相等。这个方法保证合法，**不保证所有合法括号序列等概率**。

还应单独测试完全嵌套的 `((...))` 和重复的 `()()...`。

##### 8. 随机树、链、菊花图、二叉树形状

参数 n 是顶点数，要求 `n>=1`；返回 n-1 条无向边，不重边、不自环，保证连通。

```cpp
E tree(int n, int type = 0) {
    assert(n >= 1 && 0 <= type && type <= 3);
    E e;
    auto p = perm(n);
    for (int i = 2; i <= n; i++) {
        int f = type == 1 ? i - 1 : type == 2 ? 1 : type == 3 ? i / 2 : rd(1, i - 1);
        int u = p[i - 1], v = p[f - 1];
        if (rd(0, 1)) swap(u, v);
        e.push_back({u, v});
    }
    shuffle(e.begin(), e.end(), rng);
    return e;
}
```

| 写法 | 形状 |
|---|---|
| `tree(n)` | 每个新点连接一个之前的点 |
| `tree(n,1)` | 链，测试深递归和路径情况 |
| `tree(n,2)` | 菊花图，测试高出度顶点 |
| `tree(n,3)` | 按 `i/2` 连接父节点的二叉树形状 |

依赖 `perm()`。代码会随机重编号、打乱边顺序并交换边两端，避免程序只在“父节点编号小、输入有序”时正确。

`tree(n)` **不是对所有 n 点标号树均匀采样**，但适合简短对拍。链和菊花图仍需单独覆盖。这里返回的是无向边；如果题目要求父亲数组，应先从指定根遍历建父亲关系，不能直接把边的第二个端点当作父亲。

n=1 时返回空边表，属于合法树。

##### 9. 随机简单图：无向 / 有向

“简单”表示没有自环、没有重复边。默认是无向图；`dir=true` 时生成有向图，有向图允许同时存在 `u→v` 与 `v→u`。

```cpp
E graph(int n, int m, bool dir = false) {
    assert(n >= 1 && m >= 0 && m <= 1LL * n * (n - 1) / (dir ? 1 : 2));
    E e;
    for (int u = 1; u <= n; u++)
        for (int v = 1; v <= n; v++)
            if (dir ? u != v : u < v) e.push_back({u, v});
    shuffle(e.begin(), e.end(), rng);
    e.resize(m);
    return e;
}
```

- `graph(n,m)`：m 条边的无向简单图，要求 `0<=m<=n*(n-1)/2`。
- `graph(n,m,true)`：m 条边的有向简单图，要求 `0<=m<=n*(n-1)`。
- **不保证连通，也不保证有向图无环。**

该方法枚举所有候选边后抽取，时间和空间为 `O(n²)`，适合小图对拍。它不会因图太稠密而反复抽到已有边，但不适合 n 很大的稀疏图。

##### 10. 保证连通的无向简单图

先造树，再从尚未使用的边中选取额外边。要求 `n-1<=m<=n*(n-1)/2`，依赖 `tree()` 和 `perm()`。

```cpp
E connected(int n, int m) {
    assert(n >= 1 && n - 1 <= m && m <= 1LL * n * (n - 1) / 2);
    E e = tree(n), more;
    set<PII> s;
    for (auto [u, v] : e) s.insert({min(u, v), max(u, v)});
    for (int u = 1; u <= n; u++)
        for (int v = u + 1; v <= n; v++)
            if (!s.count({u, v})) more.push_back({u, v});
    shuffle(more.begin(), more.end(), rng);
    int k = m - (n - 1);
    e.insert(e.end(), more.begin(), more.begin() + k);
    shuffle(e.begin(), e.end(), rng);
    return e;
}
```

保证连通、无自环、无重边，边数恰好为 m。n=1、m=0 也合法。

时间 `O(n² log n)`、空间 `O(n²)`，仅用于小图。它并非对所有连通图均匀采样。大规模稀疏连通图可以先造树，再用 set 去重加边；不要在接近完全图时使用反复随机尝试的方法。

##### 11. DAG：有向无环图

先随机一个拓扑序，只允许从序列中靠前的点连向靠后的点。要求 `0<=m<=n*(n-1)/2`，依赖 `graph()` 和 `perm()`。

```cpp
E dag(int n, int m) {
    auto p = perm(n);
    E e = graph(n, m);
    for (auto &[u, v] : e) u = p[u - 1], v = p[v - 1];
    return e;
}
```

`graph(n,m)` 中每条边原本满足 `u<v`，重编号后便遵守随机拓扑顺序。因此不会出现有向环，也不会强迫“编号小的点一定在前”。不保证弱连通。

这不是对所有 DAG 的均匀采样，且沿用 `O(n²)` 的候选边空间。

##### 12. 二分图

左侧 l 个点编号为 `1..l`，右侧 r 个点编号为 `l+1..l+r`。要求 `l,r>=0`、`0<=m<=l*r`。

```cpp
E bipartite(int l, int r, int m) {
    assert(l >= 0 && r >= 0 && m >= 0 && m <= 1LL * l * r);
    E e;
    for (int u = 1; u <= l; u++)
        for (int v = 1; v <= r; v++) e.push_back({u, l + v});
    shuffle(e.begin(), e.end(), rng);
    e.resize(m);
    return e;
}
```

无重边，所有边都跨越左右集合，不保证连通或存在完美匹配。用于要求右侧单独编号 `1..r` 的题目时，输出右端点应减去 l。

候选边空间 `O(l*r)`。如果要保证有完美匹配，需先加入一个覆盖所需顶点的匹配，再补其他边，不能直接假设随机图一定满足。

##### 13. 给树或图加随机边权

每条边附加一个 `[l,r]` 内的权值。依赖任意返回 E 的生成器。

```cpp
vector<tuple<int, int, ll>> weighted(const E &e, ll l, ll r) {
    vector<tuple<int, int, ll>> a;
    for (auto [u, v] : e) a.push_back({u, v, rd(l, r)});
    return a;
}
```

例如 `weighted(tree(n),1,10)` 或 `weighted(connected(n,m),0,100)`。

最短路、最小生成树等题目对边权可能有不同要求。只有题目允许时才生成零权或负权；普通图随机加入负权并不能保证没有负环。需要负权但无环时可结合 DAG，但仍须符合题目约束。

##### 14. 随机区间

产生 `[1,n]` 内的合法闭区间，要求 `n>=1`。

```cpp
PII interval(int n) {
    assert(n >= 1);
    int l = rd(1, n), r = rd(1, n);
    if (l > r) swap(l, r);
    return {l, r};
}
```

该方法不保证每个区间等概率。还应主动测试 `[1,1]`、`[n,n]`、`[1,n]`，以及连续重复操作同一区间。

如果题目采用半开区间 `[l,r)`，或要求 `l<r`，需要修改这里的范围与规则。

##### 15. 随机矩阵与网格

生成 n 行 m 列矩阵，元素在 `[l,r]`，要求 `n,m>=0`。

```cpp
vector<vector<ll>> matrix(int n, int m, ll l, ll r) {
    vector<vector<ll>> a(n, vector<ll>(m));
    for (auto &row : a)
        for (ll &x : row) x = rd(l, r);
    return a;
}
```

`matrix(n,m,0,1)` 可表示 01 网格。字符串网格可以逐行调用 `str(m,".#")`；这种直接生成的网格**不保证起点和终点之间有路**。若题目要求一定可达，应先铺出合法路径，再随机设置其余位置。

##### 16. 正整数拆分：n 个数的和固定为 s

要求 `1<=n<=s`。从 `1..s-1` 中选 n-1 个切分点，得到 n 个正整数，依赖 `pick()`。

```cpp
vector<int> split(int n, int s) {
    assert(1 <= n && n <= s);
    if (n == 1) return {s};
    auto p = pick(n - 1, 1, s - 1);
    p.push_back(0);
    p.push_back(s);
    sort(p.begin(), p.end());
    vector<int> a;
    for (int i = 1; i <= n; i++) a.push_back(p[i] - p[i - 1]);
    return a;
}
```

例如 `split(4,10)`。生成候选数需要 `O(s)`，排序切分点需要 `O(n log n)`，总时间为 `O(s+n log n)`、空间为 `O(s)`，适合总和较小的对拍。

若要 n 个非负数、和为 s，可在 `s+n` 不溢出的前提下生成 `split(n,s+n)`，再把每个元素减 1。

##### 17. 怎么接进现有 gen()

下面仍以最大非空连续子段和为例。复制第 1 节公共定义和第 2 节 `arr()`，然后用下面的函数替换原来的 `gen()`；`same()`、主循环和脚本保持原用法。

```cpp
void gen(int seed) {
    rng.seed(seed);
    ofstream in("data.in"), out("ans.out");
    int T = rd(1, 4);
    in << T << '\n';
    while (T--) {
        int n = rd(1, 20);
        auto a = arr(n, -10, 10);
        in << n << '\n';
        for (int i = 0; i < n; i++) in << a[i] << " \n"[i == n - 1];
        ll ans = LLONG_MIN;
        for (int l = 0; l < n; l++) {
            ll s = 0;
            for (int r = l; r < n; r++) ans = max(ans, s += a[r]);
        }
        out << ans << '\n';
    }
    in.close();
    out.close();
    if (!in || !out) exit(2);
}
```

换成树或图题时，先用相应函数拿到边表，再按题目格式输出：图通常写 n、m，然后逐条写 u、v；树通常只写 n，然后写 n-1 条边。**是否有 T、是否有边权、顶点编号从几开始，都以题面为准。**

生成图不等于计算参考答案。暴力解必须针对题目目标另写，不能只换生成方法而继续输出本例的子段和。

##### 18. 比随机更值得主动加入的数据

| 类型 | 建议固定覆盖 |
|---|---|
| 数组 | n=1、全相同、全负、全零、单调、正负交替、数值上界 |
| 排列 | 恒等、逆序、只交换相邻两项 |
| 字符串 | 长度 1、全相同、交替串、长公共前缀、回文、短周期 |
| 树 | 单点、链、菊花、二叉树形状、随机重编号 |
| 无向图 | 无边、树、简单环、完全图、多个连通分量；必须符合题意 |
| 有向图 | 单向链、DAG、含环、双向边；必须符合题意 |
| 区间操作 | 单点、全区间、相邻区间、连续重复修改 |
| 多组数据 | 大组后接小组、相同输入连续出现，检查状态清空 |

可以按 `seed%k` 轮换这些模式。特别注意：

1. 规模服从暴力复杂度，先小后大。
2. 不要随机出题目不允许的数据，再把正式解的行为当成错误。
3. 动态删除、撤销等操作必须先维护当前状态，再从合法候选中选择；不能无条件随机删除不存在的元素。
4. 先检查生成器的范围、边数、连通性和字符集，再相信对拍结果。
5. 这些片段优先保证简短和合法；除明确的均匀整数、shuffle 抽样外，不应默认复杂结构在全部可能对象上均匀分布。
