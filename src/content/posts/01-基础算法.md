### 快读

<a id="fast-input"></a>

用途：读取以空白分隔的合法 32/64 位整数；总时间 $\mathcal{O}(\text{输入字符数})$，缓冲区占用 $\mathcal{O}(1)$。这是 fread/Cin 替代输入方案，若采用本节，入口读取 T 也应改为 Cin(T)，不要与 cin 混用；输出仍可使用 cout。

支持有符号最小值、无符号最大值、EOF 和 `#define int long long`。为缩短赛场模板并减少热循环开销，不检查非法 token 或数值溢出，输入必须合法且处于 T 的范围内；普通题目可继续使用缺省源的 cin/cout。

```c++
char buf[1 << 21], *p = buf, *q = buf;
inline int32_t gc() {
    if (p == q) q = (p = buf) + fread(buf, 1, SZ, stdin);
    return p == q ? EOF : (unsigned char)*p++;
}
template <class T> bool Cin(T &x) {
    int32_t c = gc();
    bool neg = false;
    while (c != '-' && (c < '0' || c > '9')) {
        if (c == EOF) return false;
        c = gc();
    }
    if (c == '-') neg = true, c = gc();
    make_unsigned_t<T> v = 0;
    while ('0' <= c && c <= '9') v = v * 10 + c - '0', c = gc();
    x = neg && v ? -T(v - 1) - 1 : T(v);
    return true;
}
template <class T, class U, class... A> bool Cin(T &x, U &y, A &...a) {
    return Cin(x) && Cin(y, a...);
}
```

ll mysqrt(ll n) { // n >= 0；返回 floor(sqrt(n))，支持 LLONG_MAX
    ll ans = sqrtl(static_cast<ld>(n));
    while ((i128)(ans + 1) * (ans + 1) <= n) ans++;
    while ((i128)ans * ans > n) ans--;
    return ans;
}
ll mylcm(ll x, ll y) { // 非负最小公倍数；超出 ll 时抛异常
    if (x == 0 || y == 0) return 0;
    auto mag = [](ll a) -> ull {
        return a < 0 ? 0ULL - (ull)a : (ull)a;
    };
    auto a = mag(x), b = mag(y);
    u128 z = u128(a / gcd64(x, y)) * b;
    if (z > LLONG_MAX) throw overflow_error("lcm overflow");
    return (ll)z;
}

template <class T> T sign(const T &a) {
    return a == 0 ? 0 : (a < 0 ? -1 : 1);
}
// 32/64 位整数除法；除零或结果超出 T 时抛出异常。
template <class T> T floor(const T &a, const T &b) {
    if (b == 0) throw invalid_argument("division by zero");
    if (is_signed<T>::value)
        if (a == numeric_limits<T>::min() && b == -1) throw overflow_error("integer division overflow");
    T q = a / b, r = a % b;
    if (r != 0 && ((r < 0) != (b < 0))) --q;
    return q;
}
template <class T> T ceil(const T &a, const T &b) {
    if (b == 0) throw invalid_argument("division by zero");
    if (is_signed<T>::value)
        if (a == numeric_limits<T>::min() && b == -1) throw overflow_error("integer division overflow");
    T q = a / b, r = a % b;
    if (r != 0 && ((r < 0) == (b < 0))) ++q;
    return q;
}

### 整数域二分

#### 旧版（闭区间写法）

要求 l、r 是合法下标，搜索区间非空且答案存在；l+r（上取整版本为 l+r+1）不能溢出。数组元素可以为负数。

- 在递增序列 $a$ 中查找 $\geq x$ 数中最小的一个（即 $x$ 或 $x$ 的后继）

```c++
while (l < r) {
    int mid = l + r >> 1;
    if (a[mid] >= x) r = mid;
    else l = mid + 1;
}
return a[l];
```

- 在递增序列 $a$ 中查找 $\leq x$ 数中最大的一个（即 $x$ 或 $x$ 的前驱）

```c++
while (l < r) {
    int mid = l + r + 1 >> 1;
    if (a[mid] <= x) l = mid;
    else r = mid - 1;
}
return a[l];
```

#### 新版

下面假设搜索区间非空且一定存在满足 judge 的位置；否则应另设 found 标志。judge 必须单调，mid 与边界加减不能溢出。

- $x$ 或 $x$ 的后继

```c++
int l = 0, r = 1E8, ans = r;
while (l <= r) {
    int mid = (l + r) / 2;
    if (judge(mid)) {
        r = mid - 1;
        ans = mid;
    } else l = mid + 1;
}
return ans;
```

- $x$ 或 $x$ 的前驱

```c++
int l = 0, r = 1E8, ans = l;
while (l <= r) {
    int mid = (l + r) / 2;
    if (judge(mid)) {
        l = mid + 1;
        ans = mid;
    } else r = mid - 1;
}
return ans;
```

要求离散凸函数，或比较相邻值能区分两侧的严格单峰函数；任意带平台的单峰函数不能直接套用。区间端点及 l+r 必须不溢出。

### 枚举与位运算

<a id="enumeration"></a>

#### 选数（DFS 解）

从 $N$ 个整数中任选 $K$ 个整数相加。使用 $\tt{}DFS$ 求解。

```c++
int n, k;
cin >> n >> k;
vector<int> in(n), now(n);
for (auto &it : in) {
    cin >> it;
}
auto dfs = [&](auto self, int k, int bit, int idx) -> void {
    for (int i = idx; i < n; i++) {
        now[bit] = in[i];
        if (bit < k - 1) {
            self(self, k, bit + 1, i + 1);
        }
        if (bit == k - 1) {
            int add = 0;
            for (int j = 0; j < k; j++) add += now[j];
            cout << add << endl;
        }
    }
};
if (k == 0) cout << 0 << "\n"; // 空集恰好一种
else if (0 < k && k <= n) dfs(dfs, k, 0, 0);
```

#### 固定大小子集枚举（Gosper’s hack）

```c++
int n, k;
cin >> n >> k;
if (n < 0 || n > 63 || k < 0 || k > n) throw invalid_argument("require 0 <= k <= n <= 63");
vector<ll> in(n);
for (auto &it : in) cin >> it;
if (k == 0) cout << 0 << "\n"; // 空集恰有一种，元素和为 0
else {
    ull comb = (ull(1) << k) - 1, U = ull(1) << n;
    while (comb < U) {
        ll add = 0; // 要求所枚举子集的元素和不溢出
        for (int i = 0; i < n; i++) {
            if ((ull(1) << i) & comb) add += in[i];
        }
        cout << add << "\n";
        ull x = comb & (ull(0) - comb);
        ull y = comb + x;
        comb = (((comb ^ y) >> 2) / x) | y;
    }
}
```

#### 与、或、异或

<a id="bit-operations"></a>

| 运算 |     运算符、数学符号表示     |  解释  |
| :--: | :---------------------------: | :-----: |
|  与  |        `&`、`and`        | 同1出1 |
|  或  |         `\|`、`or`         | 有1出1 |
| 异或 | `^`、$\bigoplus$、`xor` | 不同出1 |

一些结论：

> 按位分配律：$(X\&a_1)\mid\cdots\mid(X\&a_n)=X\&(a_1\mid\cdots\mid a_n)$。结果等于 $X$ 的充要条件是：$X$ 的每个置位都被至少一个 $a_i$ 覆盖。
> 原理是 $and$ 意味着取交集，$or$ 意味着取并集。[来源 - 牛客小白月赛49C](https://ac.nowcoder.com/acm/contest/11226/C)

#### 求解连续按位异或

以 $\mathcal O(1)$ 复杂度计算 $0\oplus1\oplus\dots\oplus n$ 。

```c++
unsigned xor_n(unsigned n) {
    unsigned t = n & 3;
    if (t & 1) return t / 2u ^ 1;
    return t / 2u ^ n;
}
```

```c++
ll xor_n(ll n) {
    if (n % 4 == 1) return 1;
    else if (n % 4 == 2) return n + 1;
    else if (n % 4 == 3) return 0;
    else return n;
}
```

### 随机化哈希

<a id="randomized-hashing"></a>

随机化哈希把较大的离散状态压成短指纹，用于快速排除不相等状态或进行概率性判等。以下模板使用两个 `ull`，所有溢出均为模 $2^{64}$ 的预期行为；仍存在碰撞，不能用于必须零误判的场景，也不是密码学哈希。

待比较的数据必须使用同一个哈希对象，或使用相同参数和 `seed`。默认种子随运行时间变化，结果不能跨运行持久化比较；调试时可显式传固定种子复现。

#### 通用随机化哈希

<a id="random-hash"></a>

用途：为整数标签生成随机指纹，再维护与顺序无关的集合或多重集哈希。其他离散对象应先无冲突地映射成整数编号。

- 多重集使用加减：插入 `h += rh(x)`，删除 `h -= rh(x)`；相同元素的出现次数会保留。数组前缀哈希可在 $\mathcal{O}(1)$ 时间比较两个区间的元素多重集。
- 集合切换或对称差使用异或：`h ^= rh(x)`。同一元素异或两次会消失，因此不能用它表示一般多重集。

单次生成、插入、删除和比较均为 $\mathcal{O}(1)$，维护 $n$ 个前缀的时间、空间均为 $\mathcal{O}(n)$；哈希对象本身为 $\mathcal{O}(1)$ 空间。

```c++
struct H2 {
    ull x = 0, y = 0;
    H2 &operator+=(const H2 &o) {
        x += o.x;
        y += o.y;
        return *this;
    }
    H2 &operator-=(const H2 &o) {
        x -= o.x;
        y -= o.y;
        return *this;
    }
    H2 &operator^=(const H2 &o) {
        x ^= o.x;
        y ^= o.y;
        return *this;
    }
    friend H2 operator+(H2 a, const H2 &b) {
        return a += b;
    }
    friend H2 operator-(H2 a, const H2 &b) {
        return a -= b;
    }
    friend H2 operator^(H2 a, const H2 &b) {
        return a ^= b;
    }
    friend bool operator==(const H2 &a, const H2 &b) {
        return a.x == b.x && a.y == b.y;
    }
    friend bool operator!=(const H2 &a, const H2 &b) {
        return !(a == b);
    }
    friend bool operator<(const H2 &a, const H2 &b) {
        return tie(a.x, a.y) < tie(b.x, b.y);
    }
};

const ull RANDOM_SEED = chrono::steady_clock::now().time_since_epoch().count();
ull mix64(ull x) {
    x += 0x9e3779b97f4a7c15ULL;
    x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9ULL;
    x = (x ^ (x >> 27)) * 0x94d049bb133111ebULL;
    return x ^ (x >> 31);
}
u128 getHash(int x, int c) {
    ull key = (ull(x) << 32) | ull(c);
    ull lo = mix64(key ^ RANDOM_SEED);
    ull hi = mix64(key ^ (RANDOM_SEED + 0x9e3779b97f4a7c15ULL));
    return (u128(hi) << 64) | lo;
}
u128 getVal(int x, int c, int k) {
    return getHash(x, (c + 1) % k) - getHash(x, c);
}

struct RHash {
    ull s1, s2;
    RHash(ull seed = chrono::steady_clock::now().time_since_epoch().count())
        : s1(mix64(seed)),
          s2(mix64(seed ^ 0xd1b54a32d192ed03ULL)) {}
    H2 operator()(ull x) const {
        return {mix64(x + s1), mix64(x + s2)};
    }
};
```

调用示例（依赖上段）：

```c++
vector<ll> a{1, 2, 2, 2, 1, 2};
RHash rh;
vector<H2> pre(a.size() + 1);
for (int i = 0; i < (int)a.size(); ++i) pre[i + 1] = pre[i] + rh((ull)a[i]);
auto get = [&](int l, int r) {
    return pre[r + 1] - pre[l];
}; // 闭区间多重集
cout << (get(0, 2) == get(3, 5)) << endl; // 1：都是 {1,2,2}

H2 active;
active ^= rh(5);
active ^= rh(7);
active ^= rh(5); // 5 被切换两次，仅留下 7
```

#### Zobrist Hash

<a id="zobrist-hash"></a>

用途：哈希棋盘、搜索局面等由多个位置状态组成的对象。位置 `i` 有 `cnt[i]` 种状态，编号为 $[0,cnt[i])$；为每个 `(位置,状态)` 分配随机指纹，整个状态的哈希为当前各位置指纹的异或。

构造时间和空间均为 $\mathcal{O}(\sum_i\mathrm{cnt}_i)$，计算初始哈希为 $\mathcal{O}(n)$，单点修改、撤销和比较均为 $\mathcal{O}(1)$。要求 `cnt[i]>0`；`init` 为空时所有位置初始化为状态 0，否则它必须包含 n 个合法状态。两个对象之间比较哈希时，`cnt` 和 `seed` 必须完全相同。

以下代码依赖上节的 `H2`；`set(p,v)` 把 0-based 位置 `p` 改成状态 `v`。搜索时记录旧状态，调用 `set` 改回即可 $\mathcal{O}(1)$ 撤销。

```c++
struct Zobrist {
    vector<vector<H2>> z;
    vector<int> a;
    H2 h;
    Zobrist(const vector<int> &cnt, const vector<int> &init = {},
            ull seed = chrono::steady_clock::now().time_since_epoch().count()) {
        mt19937_64 rng(seed);
        int n = cnt.size();
        z.resize(n);
        for (int i = 0; i < n; ++i) {
            z[i].resize(cnt[i]);
            for (auto &x : z[i]) x = {rng(), rng()};
        }
        a = init.empty() ? vector<int>(n) : init;
        for (int i = 0; i < n; ++i) {
            h ^= z[i][a[i]];
        }
    }
    void set(int p, int v) {
        h ^= z[p][a[p]];
        a[p] = v;
        h ^= z[p][a[p]];
    }
    H2 get() const {
        return h;
    }
};
```

调用示例（依赖 `H2` 和上段）：

```c++
vector<int> cnt(9, 3), init(9); // 3*3 棋盘，每格有 0/1/2 三种状态
Zobrist zh(cnt, init);
H2 empty = zh.get();
zh.set(4, 1); // 中心放入棋子 1
H2 center = zh.get();
zh.set(4, 0); // 撤销
cout << (zh.get() == empty) << ' ' << (center != empty) << endl; // 1 1
```
